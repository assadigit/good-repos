# puter

> **TL;DR:** Self-hostable web OS providing cloud computing with file storage, apps, and desktop environment.

**`HeyPuter/puter`** · ⭐ 42,711 · 🔧 TypeScript

## What is it?
Puter is an open-source, self-hostable internet computer designed to serve as a comprehensive digital workspace accessible from any device. It combines the functionality of traditional operating systems with web-based accessibility, offering a suite of built-in applications including Notepad, Voice Recorder, Spreadsheet, Camera, and more. The project aims to consolidate all common productivity tools under one unified platform while maintaining full control over your data through self-hosting capabilities.

## How does it work?
Puter operates as a web-based operating system that runs primarily in the browser but can also be self-hosted on servers or local infrastructure. It leverages JavaScript for its core functionality and likely employs WebAssembly or other modern web technologies to deliver near-native performance. The architecture appears to use a cloud-first approach with optional self-hosting modes, allowing users to either run Puter on public cloud infrastructure or deploy it entirely within their own environment (e.g., using Docker, Kubernetes, or bare metal). Storage is handled through a combination of local filesystem operations and remote storage integration, supporting protocols like SFTP for file access.

## Difference from Others
Unlike traditional self-hosting projects that focus on single-purpose tools (e.g., Syncthing for sync, Nextcloud for storage), Puter provides a unified web OS experience. It also differs from cloud platforms like AWS or Google Cloud by being purpose-built for user-facing applications rather than infrastructure-as-a-service. Compared to desktop virtualization solutions, Puter runs entirely in the browser with optional self-hosting, making it more accessible and privacy-focused. The combination of full OS features with web accessibility is its distinguishing factor.
