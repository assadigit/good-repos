# knowledge-catalog

**`GoogleCloudPlatform/knowledge-catalog`** · ⭐ 6,336 · 🔧 HTML

## What is it?
Knowledge Catalog (formerly Dataplex) is Google Cloud's AI-powered metadata management platform that builds a dynamic knowledge graph across structured and unstructured data sources. This repository provides official tools, agents, and sample implementations demonstrating core features like context enrichment, metadata pipelines, and semantic retrieval. All solutions are open-source under Apache 2.0 licensing and designed for integration with GCP services.

## How does it work?
The platform ingests metadata from GCP data stores (BigQuery, Cloud Storage) via API-driven pipelines that construct a graph-based knowledge model. Agents leverage this graph to enrich raw metadata with business context, while retrieval samples query the catalog using semantic search and policy-aware filtering. Documentation includes Cloud Shell setup instructions and contributor guidelines for extending functionality.

## Why is it important? (Core Value)
As a software engineer focused on AI agents and developer tools, this repository offers reference implementations of how GCP structures metadata management at scale. It demonstrates practical patterns for building context-aware systems and integrating with cloud-native services—valuable if you're evaluating self-hostable alternatives or studying enterprise data catalog architectures from a major provider. The open-source samples could inform your own metadata pipelines or agent tooling.

## Difference from Others
Unlike open-source alternatives like OpenMetadata or DataHub, this repository is tied to GCP's proprietary APIs and services, offering seamless integration with Google Cloud ecosystem components (BigQuery, Vertex AI). It also includes official agent implementations and samples directly from Google engineers, whereas other projects typically provide generic metadata frameworks without cloud-specific hooks.
