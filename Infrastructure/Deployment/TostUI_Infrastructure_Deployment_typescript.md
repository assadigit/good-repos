# TostUI

> **TL;DR:** Docker-based web UIs that simplify running generative AI models locally.

**`camenduru/TostUI`** · ⭐ 478 · 🔧 TypeScript

## What is it?
TostUI is a collection of Docker-based web user interfaces designed to easily run various state-of-the-art generative AI models locally. It simplifies the deployment of these AI tools by packaging them into ready-to-use containers with accessible front-end controls. The project supports multiple models including Trellis 2 for Unreal Engine-compatible 3D generation, Song Generation for audio creation, and Flux.2 for high-quality image generation.

## How does it work?
TostUI packages generative AI models into Docker containers that can run locally or on cloud platforms like RunPod. Each container includes the model weights, dependencies, and a lightweight web server serving an HTML/JavaScript interface for interacting with the model. Users deploy via Docker Compose files that spin up both the model backend and the UI frontend in separate containers. The project provides cloud service access at ui.tost.ai for those preferring SaaS usage rather than self-hosting.

## Why is it important? (Core Value)
This project directly addresses your interest in self-hosted alternatives to SaaS products by providing Docker-based deployment solutions for various generative AI tools. For homelab infrastructure enthusiasts, it enables running models like Flux.2, Trellis 2, or custom audio generation locally with GPU acceleration on hardware you control. The clear documentation of VRAM requirements per model helps you plan your local AI setup efficiently.

## Key Features & Technologies
- Docker-based packaging of generative AI models
- Web UI interface for model interaction
- Support for multiple models including Trellis 2, Song Generation, Flux.2
- Cloud service at ui.tost.ai
- RunPod templates for cloud deployment
- Minimum VRAM requirements documented per model
- Local deployment options with Docker Compose

## Difference from Others
Unlike other self-hosted AI model runners that focus primarily on image generation (like Stable Diffusion WebUI) or text generation (like KoboldAI), TostUI provides a unified interface for multiple generative AI domains including 3D model generation, audio synthesis, and high-quality image creation. It also emphasizes Docker-based deployment with clear documentation of VRAM requirements, making it easier for users to determine hardware compatibility upfront.
