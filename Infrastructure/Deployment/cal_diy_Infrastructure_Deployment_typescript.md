# cal.diy

**`calcom/cal.diy`** · ⭐ 46,194 · 🔧 TypeScript

## What is it?
Cal.diy is an open-source, self-hosted scheduling platform built on the Cal.com codebase. It provides infrastructure for creating booking pages, managing appointment calendars, and handling meeting links. The project is designed primarily for personal, non-production use, with a strong emphasis on community-driven development rather than commercial deployment.

## How does it work?
The platform runs as a self-hosted Next.js application using TypeScript throughout. It leverages PostgreSQL as its database backend with Prisma for type-safe ORM operations. Authentication is handled via NextAuth, while tRPC provides strongly-typed RPC communication between frontend and backend components. The stack includes TailwindCSS for styling, Zod for schema validation, and Turborepo as the monorepo tooling framework to manage multiple packages.

## Why is it important? (Core Value)
This project directly aligns with your interest in self-hostable alternatives to SaaS products and homelab infrastructure. Cal.diy gives you full control over scheduling infrastructure without paying SaaS fees, making it ideal for personal use or as part of a larger workflow orchestration system. As an open-source project from Cal.com (a major tech entity), it's credible enough to adopt for replacing paid scheduling tools in your development workflow. The MIT license ensures you can freely modify and deploy it alongside other self-hosted services.

## Difference from Others
Unlike Cal.com (the hosted commercial SaaS), this is strictly the community edition intended for personal use with no enterprise support. Compared to other open-source scheduling alternatives, it benefits from the well-established Cal.com codebase and active community contributions, making it more robust than typical indie projects. It's positioned as a free alternative to paid booking platforms rather than an enterprise solution.
