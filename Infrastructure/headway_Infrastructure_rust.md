# headway

**`headwaymaps/headway`** · ⭐ 2,897 · 🔧 Rust

## What is it?
Headway is a self-hostable maps stack that brings the full power of OpenStreetMap data into your own infrastructure. It provides a frontend interface, basemap tiles, geocoding search, and routing engine in one cohesive package. The project lets you choose from over 200 predefined city extracts or provide your own OSM extract covering any area—from a neighborhood to the entire planet.

## How does it work?
Headway packages the necessary components into a single deployable stack that can be spun up with simple commands. It uses OpenStreetMap extracts as its data source, serving map tiles through a tile server. The geocoder integrates with OSM data to search for points of interest and addresses within your chosen extract, while the routing engine calculates driving, cycling, and walking directions between locations in the same extract. Transit routing is noted as work-in-progress.

## Why is it important? (Core Value)
This project directly serves your objectives around self-hosted alternatives to SaaS products and infrastructure. Headway gives you ownership over your location data without relying on commercial map APIs like Google Maps or Mapbox. For a software engineer focused on AI agents, developer tools, and automation, having a local maps stack means you can integrate geospatial features into your own workflows—whether that's building agent navigation capabilities, creating location-aware tools, or simply replacing paid services with open-source alternatives. The self-hosted nature aligns perfectly with homelab infrastructure interests.

## Key Features & Technologies
- Self-hostable maps stack in a box
- Includes frontend interface
- Serves OSM basemap tiles
- Geocoding search functionality
- Routing engine for driving/cycling/walking
- 200+ predefined city extracts available
- Supports custom OSM extract uploads

## Difference from Others
Unlike commercial map services that require API keys and incur ongoing costs, Headway runs entirely on your infrastructure using only OpenStreetMap data. It's comparable to other self-hosted map solutions but notably includes a complete frontend in the stack rather than just backend APIs. The project also emphasizes ease of deployment with predefined city extracts, making it more accessible than setting up raw OSM tile servers from scratch.
