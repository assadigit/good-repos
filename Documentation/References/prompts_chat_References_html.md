# prompts.chat

> **TL;DR:** The world's largest open-source prompt library for AI models like ChatGPT, Claude, Gemini, and more.

**`f/prompts.chat`** · ⭐ 166,158 · 🔧 HTML

## What is it?
prompts.chat is a curated collection of AI prompts that can be shared, discovered, and collected from the community. It serves as an open-source alternative to proprietary prompt libraries, allowing users to self-host their own instance with complete privacy control over their prompts. The project works with a wide range of language models including ChatGPT, Claude, Gemini, Llama, Mistral, and more.

## How does it work?
The project is implemented as a static website built with Next.js, serving prompt data through HTTP requests. Prompts are stored in a structured repository format that can be self-hosted locally or deployed to any web server. The architecture relies on simple file-based storage rather than complex databases, making it lightweight and easy to maintain. Privacy is maintained by not depending on external services for prompt delivery.

## Why is it important? (Core Value)
This project directly serves your interest in AI/LLM tooling and prompt engineering by providing a massive library of community-curated prompts you can use or adapt. The self-hosted option aligns with your goal of finding self-hostable alternatives to SaaS products—unlike commercial prompt libraries that charge subscriptions, this is completely free and open-source. As a researcher building a personal knowledge base, the repository can serve as reference material for prompt patterns and techniques across different models.

## Difference from Others
Unlike many other prompt repositories that are static markdown collections or GitHub README files, prompts.chat is actively maintained with a dedicated website and structured data format. It stands out for its scale (166k stars) and community engagement. The self-hosted capability distinguishes it from cloud-based prompt libraries that require subscriptions. It also differs from prompt engineering tools by focusing on curated prompt examples rather than providing generation or optimization functionality.
