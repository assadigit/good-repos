# Legendary_OSINT

> **TL;DR:** Curated OSINT tool directory for fraud, KYC/AML, CTI, and threat investigation workflows.

**`K2SOsint/Legendary_OSINT`** · ⭐ 1,692 · 🔧 N/A

## What is it?
Legendary_OSINT is a curated collection of open-source intelligence (OSINT) tools and resources for fraud investigators, cyber threat intelligence analysts, KYC/AML professionals, and related security work. It organizes third-party tools, databases, search engines, and monitoring resources into practical investigation domains.

The repository is organized as Markdown documentation with a table of contents linking to domain-specific files. It covers people/social media, aviation, maritime, rail, domains/IPs, phishing/email, malware/CTI, dark web leaks, search engines, document search, archiving, geospatial mapping, news/media, image reverse search, communications/SIGINT, video OSINT, business intelligence, government/legal records, and academic databases.

It is not a single executable tool; it is a reference index. The README warns that most tools are third-party and should be vetted and used responsibly.

## How does it work?
The project operates as a static, human-curated Markdown knowledge base. Each section in the table of contents points to a dedicated doc file that lists tools and resources for a specific OSINT domain. The value comes from curation, categorization, and source discovery rather than runtime code.

It relies on public collections, newsletters, Telegram groups, GitHub repositories, and other public sources to compile tools. Users can browse or search the docs to identify relevant OSINT capabilities, then evaluate and deploy the listed tools in their own investigations.

## Why is it important? (Core Value)
For a software engineer and researcher building an Obsidian knowledge base, this repository is a high-density reference for OSINT tool discovery across investigative, threat intelligence, and data-extraction workflows. It can help identify candidate tools for scraping, monitoring, reverse search, geospatial analysis, and threat intelligence that could be integrated into AI-agent pipelines, automation workflows, or self-hosted investigative stacks.

It is especially useful for discovering non-obvious tools in niche domains such as aviation, maritime, rail, SIGINT, dark-web leaks, and document search. Because it emphasizes fraud, KYC/AML, and CTI use cases, it supports building agent skills or research workflows that need credible, domain-specific data sources while reminding users to vet third-party tools before adoption.

## Difference from Others
Compared with generic OSINT lists, Legendary_OSINT is structured around investigative and threat-intelligence use cases rather than a flat tool dump. It separates capabilities into practical operational domains such as aviation, maritime, rail, SIGINT, dark web leaks, and document search, making it easier to map tools to specific investigation workflows.

Its emphasis on fraud, KYC/AML, and CTI analysts gives it a more targeted professional focus than broad OSINT collections, while still covering general OSINT capabilities like search engines, archiving, image reverse search, and media monitoring.
