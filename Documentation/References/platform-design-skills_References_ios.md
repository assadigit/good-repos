# platform-design-skills

**`ehmo/platform-design-skills`** · ⭐ 431 · 🔧 N/A

## What is it?
platform-design-skills is an open-source repository that aggregates design guidelines from Apple HIG, Material Design 3, and WCAG 2.2 into platform-specific skill modules. It was built by scraping the official Apple Human Interface Guidelines PDF (included in the repo) and distilling the content into succinct rule files for iOS, iPadOS, macOS, watchOS, visionOS, tvOS, Android, and Web. The goal is to provide designers and developers with a consolidated reference for evaluating, improving, or creating designs that comply with official platform standards.

## How does it work?
The project uses a scraping workflow to extract rules from the Apple Human Interface Guidelines PDF and the Material Design 3 documentation, then organizes them into markdown files grouped by platform (ios, ipados, macos, etc.). Each skill file contains concise statements of the rule, its scope, and relevant examples. The repo is structured as a static collection with no runtime dependencies; all content is pre-processed and stored locally. This makes it easy to host anywhere and query via simple file navigation or optional CLI tools if provided.

## Why is it important? (Core Value)
This repository serves as a self-hosted design guideline reference that directly supports the user's objectives of discovering developer productivity tools and learning about scraping. By consolidating Apple HIG, Material Design 3, and WCAG 2.2 into one place, it saves time searching across multiple official docs. For the user's Obsidian vault, each skill module can be imported as a note, enabling quick lookup when evaluating UI/UX decisions in their own projects. The open-source nature aligns with the interest in open-source projects from major tech companies (Apple), and the scraping methodology provides a practical example of how to extract and curate documentation programmatically.

## Key Features & Technologies
- Scrapes Apple Human Interface Guidelines PDF
- Includes Material Design 3 rules
- WCAG 2.2 compliance checks
- Platform-specific skill modules (iOS, iPadOS, macOS, etc.)
- Self-hosted static repository
- Open source

## Difference from Others
Unlike Apple HIG or Material Design 3 alone, this project combines three major design systems into a single repository, eliminating the need to cross-reference separate documentation sources. It also provides platform-specific skill files rather than generic guidelines, making it more actionable for developers targeting specific OSes. Other aggregations often miss WCAG 2.2 or lack offline PDF of Apple HIG, which this repo includes.
