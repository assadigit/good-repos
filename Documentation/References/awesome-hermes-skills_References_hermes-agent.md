# awesome-hermes-skills

> **TL;DR:** Curated install-ready skills directory for Hermes Agent — 72 built-in + 186 community skills vetted for quality.

**`ZeroPointRepo/awesome-hermes-skills`** · ⭐ 320 · 🔧 N/A

## What is it?
Awesome Hermes Skills is a curated, install-ready directory of skills specifically designed for Hermes Agent (v0.17.0) from Nous Research — the self-improving AI agent that writes its own skills from your workflows and searches its own past conversations. The collection includes 72 built-in skills that ship with Hermes, 101 optional catalog skills, and 85 community-contributed skills, plugins, and tools that have been vetted for quality.

The project positions itself as 'the shortcut' for users who want to quickly enhance their agent's capabilities without having to discover and validate every skill individually. Each entry in the list provides install instructions, making it immediately actionable. The README also features a 'Skill of the Week' highlight system to draw attention to particularly useful additions, with entries like youtube-full that can extract transcripts, search videos, and browse channels.

## How does it work?
The project is structured as a static Markdown repository organized by skill category, following the 'Awesome' list format conventions. Each skill entry includes install instructions, usage examples, and links to the underlying code or documentation. The skills are designed to be cross-compatible with Hermes Agent itself, as well as Claude Code, OpenClaw, Cursor, and Windsurf — allowing users to transfer their enhanced agent configurations across different platforms.

There's no complex runtime or backend infrastructure; the value lies entirely in the curated collection itself. Users simply clone or reference the repository, then install individual skills into their Hermes environment using the provided instructions for each category.
