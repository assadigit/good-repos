# awesome-python

> **TL;DR:** Curated directory of Python frameworks, libraries, and tools organized by category with a searchable website.

**`vinta/awesome-python`** · ⭐ 321,016 · 🔧 Python

## What is it?
Awesome Python is a community-curated list (the #10 most-starred repo on GitHub) that catalogs the best Python frameworks, libraries, and tools across dozens of categories. It answers the question "I want to do X in Python, which tool should I use?" by grouping projects into sections like AI & ML (Agents, Deep Learning, NLP, Computer Vision), Web Development (Frameworks, APIs, Servers), HTTP & Scraping, Database & Storage, Data & Science, and more. Each entry links to the project's repository with a brief description of its purpose.

The list is maintained as a single Markdown file in the repo and is also published at awesome-python.com, which adds search and filter capabilities on top of the raw list. It has accumulated over 321,000 stars and nearly 29,000 forks, making it one of the most widely referenced Python resource directories on GitHub.

## How does it work?
The project is primarily a manually curated Markdown document maintained by the owner (vinta) and community contributors. Each category section lists tools with a one-line description and a link to the project's repository or website. The list is opinionated, meaning it highlights what the maintainer considers the best options rather than exhaustively listing every possible tool.

A companion website (awesome-python.com) renders the same content with search and filter UI, making it easier to find specific tools by keyword or category. The repo itself is static—there is no runtime code, API, or build system; it is purely a reference document.

## Why is it important? (Core Value)
For a software engineer and researcher focused on AI agents, developer tools, and automation, this list serves as a single-entry-point for discovering Python-based tools across every domain of interest. The AI & ML section (including an "AI and Agents" subsection) directly supports the user's goal of finding agent frameworks, MCP servers, and LLM tooling in Python. The Web Scraping, Automation, and Data & Science sections align with the user's interests in scraping, workflow orchestration, and infrastructure.

Because the list is opinionated and maintained by a community that has iterated on it for years, it filters out lower-quality or abandoned projects, saving the curator significant time compared to searching GitHub from scratch. It also complements the user's Obsidian vault workflow: each entry can be quickly evaluated and tagged into the appropriate domain folder (AI-Domain, Tools, Frameworks, Infrastructure) without needing to re-derive what each tool does.

## Difference from Others
Unlike a simple tag-based GitHub search or a per-framework documentation site, Awesome Python provides a single, opinionated cross-cutting directory that spans every major domain of the Python ecosystem in one place. It is not tied to any specific framework or company (unlike, say, Django's package index or FastAPI's docs), and it does not attempt to be exhaustive—instead it highlights what the maintainer considers the best option for each category. This makes it a faster onboarding and discovery tool than browsing individual project READMEs or niche package registries. Its main limitation is that it is a list, not an interactive dependency resolver; it tells you which tools exist but does not evaluate compatibility or manage installation.
