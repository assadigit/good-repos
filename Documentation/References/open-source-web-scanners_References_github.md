# open-source-web-scanners

**`psiinon/open-source-web-scanners`** · ⭐ 1,547 · 🔧 N/A

## What is it?
Curated list of open source web security scanners on GitHub and GitLab, ordered by stars.

## How does it work?
A markdown-based curation page that aggregates web security scanner repositories from GitHub and GitLab, ordered by star count, with related repos indented and metadata badges via shields.io.

## Why is it important? (Core Value)
Provides a curated starting point for discovering self-hostable web security scanners, aiding the user's interest in self-hosted alternatives and infrastructure research.

## Key Features & Technologies
- Curated list of tools
- Ordered by stars
- Includes related repos (extensions)
- Metadata badges via shields.io
- Direct links to scanner repositories

## Difference from Others
Unlike generic tool lists, this project specifically curates web security scanners and orders them by popularity (stars) rather than alphabetically or by date. It also includes related repository extensions as indented entries, offering deeper context for each main tool.
