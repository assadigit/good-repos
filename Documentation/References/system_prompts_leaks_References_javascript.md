# system_prompts_leaks

> **TL;DR:** Centralized collection of system prompts from Claude, ChatGPT, Gemini, Grok, Copilot and more. Updated regularly.

**`asgeirtj/system_prompts_leaks`** · ⭐ 57,092 · 🔧 JavaScript

## What is it?
The System Prompts Leaks repository is a centralized collection of publicly disclosed system prompt instructions from leading AI chatbot models, including Claude, ChatGPT, Gemini, Grok, and Copilot. It documents the hidden rules and guidelines that govern these models' behavior, making them accessible to researchers, developers, and anyone interested in prompt engineering. The repo updates regularly as new model versions are released, capturing system prompts from Anthropic, OpenAI, Google, and xAI providers. Each model's prompt is stored in a dedicated markdown file, often accompanied by metadata about tools, skills, and sources used.

The project emphasizes open collaboration, welcoming pull requests to add new models or update existing ones. It serves as both an educational resource and a reference for understanding how different LLMs are instructed, enabling users to compare prompt structures across providers.

## How does it work?
The repository organizes prompts by provider in top-level directories (Anthropic, OpenAI, Google, xAI), each containing markdown files with the system prompt text and metadata. Updates are typically done manually or via scripts that scrape official sources, then merged through PRs. The project uses standard GitHub features like issues and pull requests for collaboration.

## Why is it important? (Core Value)
This repository offers immediate transparency into how leading AI models are instructed, which is invaluable for researchers and developers working on prompt engineering, model comparison, or building custom agents. By providing access to the hidden system prompts of Claude, ChatGPT, Gemini, Grok, and others, it enables deep analysis of design choices across providers, helping users understand and potentially replicate or improve upon these instructions. For someone focused on AI agents and developer tools, this serves as a foundational resource for understanding model behavior and creating more informed, transparent systems.
