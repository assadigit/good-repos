# pasban_db

> **TL;DR:** A curated Persian language database with 18,000+ native word alternatives to foreign loanwords for software localization.

**`keyaruga33/pasban_db`** · ⭐ 68 · 🔧 N/A

## What is it?
Pasban DB (پایگاه داده پاسبان) is a comprehensive Persian language database containing over 18,000 foreign loanwords mapped to their native Persian equivalents. It was created by the Pasban Parsi community to preserve and promote the use of pure Persian vocabulary in software applications, websites, and other digital products. The project provides the dataset in multiple formats including SQLite, JSON, and CSV, making it directly usable for localization and internationalization workflows. Each entry has been reviewed by a community of dedicated word-keepers (واژه‌بانان), ensuring linguistic accuracy and cultural authenticity.

## How does it work?
The database is maintained by a volunteer community of Persian language enthusiasts who curate and review entries mapping common foreign loanwords to their pure Persian equivalents. The data is distributed as static files in SQLite, JSON, and CSV formats, which developers can integrate into their applications for text replacement or as a lookup reference. The project is part of the broader Pasban Parsi initiative, which also includes a website (pasbans.ir) and a Telegram channel for ongoing community collaboration and continuous updates.

## Why is it important? (Core Value)
For a software engineer working with AI agents and LLM tooling, this project offers a ready-made localization dataset that can be integrated into NLP pipelines, RAG systems, or LLM prompt engineering for Persian-language applications. It's particularly valuable for anyone building AI agents or chatbots in Persian, as it provides a curated vocabulary database that ensures linguistic authenticity. The multiple file formats (SQLite, JSON, CSV) make it straightforward to load into vector databases, embedding pipelines, or LLM context windows. As an open-source, community-maintained resource, it offers a self-hosted alternative to commercial localization services and fits well within the user's interest in developer productivity tools and infrastructure.

## Difference from Others
Unlike general-purpose dictionaries or translation APIs, Pasban DB is specifically focused on replacing foreign loanwords with native Persian equivalents rather than providing translations between languages. It is not a general dictionary but a curated substitution database designed for software localization. Its community-driven curation model and multi-format distribution set it apart from static language datasets. Compared to other Persian NLP resources, its unique value lies in its specific mission of linguistic preservation through direct software tooling integration.
