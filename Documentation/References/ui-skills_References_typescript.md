# ui-skills

**`ibelick/ui-skills`** · ⭐ 4,616 · 🔧 TypeScript

## What is it?
ui-skills is a CLI-based knowledge base of UI/UX design skills organized into categories (motion, layout, typography, etc.). It provides commands to list categories, retrieve specific skills, and start an interactive session that routes agents through the appropriate UI skill set for given tasks.

## How does it work?
Built as a Node.js CLI tool, ui-skills reads structured data files containing skill definitions. The npx ui-skills start command initializes an interactive mode where user prompts guide navigation through skill categories. Additional commands (list, get) query the data store directly. A static web frontend serves documentation images and possibly a simple web interface.

## Why is it important? (Core Value)
This project provides a self-hostable reference for UI design skills that can be integrated into developer workflows. For a researcher curating tools, it offers an organized knowledge base that reduces reliance on external documentation, supports agent routing through UI skill sets, and aligns with interests in developer productivity and self-hosted alternatives.

## Key Features & Technologies
- CLI interface
- Category-based organization
- Interactive agent routing
- MIT license
- Node.js runtime
- Static assets
- Self-hostable

## Difference from Others
Unlike static documentation sites (e.g., Microsoft Fluent UI guidelines) or generic design resources, ui-skills is programmatically accessible via CLI and explicitly designed to route agents through skills. It provides a structured data model rather than just curated content, making it unique among UI skill repositories.
