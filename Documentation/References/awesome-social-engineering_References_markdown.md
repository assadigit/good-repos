# awesome-social-engineering

> **TL;DR:** Curated list of social engineering resources for cybersecurity professionals, penetration testers, and educational use.

## What is it?
awesome-social-engineering is a GitHub-curated collection of high-quality social engineering materials organized into categories such as online courses, capture-the-flag challenges, psychology books, documentation, tools, miscellaneous items, OSINT resources, and contribution guidelines. It follows the popular awesome-* list style on GitHub, providing hyperlinks to external resources like Udemy, PacktPub, Cybrary, and Social-Engineer.com. The project is maintained by giuliacassara and is intended for cybersecurity professionals, penetration testers, and educational use in controlled environments. No active manipulation campaigns are included—the list is purely reference material.

The repository serves as a centralized knowledge base for learning social engineering techniques, psychological aspects of manipulation, and practical tools used in security assessments. It includes links to courses that teach social engineering from scratch, CTF platforms like DEFCON SECTF, psychology books on manipulation, OSINT resources, and a variety of tools categorized under the 'tools' section. A dedicated contribution section outlines how others can add resources, maintaining the curated quality.

This project exemplifies the awesome-* pattern of community-driven resource aggregation, making it easy for learners to discover credible, well-vetted materials without sifting through scattered websites or forums.

## How does it work?
The project is a static markdown file hosted on GitHub that aggregates hyperlinks to external resources. It does not run any code or services; its operation relies entirely on the maintainer (giuliacassara) curating and updating the list over time. Contributions are managed through GitHub issues and pull requests, following standard awesome-list guidelines for adding and reviewing new resources. The repository includes a table of contents with anchor links to each category section, making navigation straightforward within the README.

There is no complex architecture or deployment beyond a simple Git repository. It does not host any APIs, databases, or dynamic content—all functionality is provided by the linked external sites. The project's simplicity ensures it remains lightweight and easy to maintain, though this also means it cannot be self-hosted or integrated into automated workflows without manual updates.
