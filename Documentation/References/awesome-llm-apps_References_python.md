# awesome-llm-apps

> **TL;DR:** Curated collection of 100+ AI agents, RAG apps, and agent skills — ready-to-clone templates for building LLM applications.

**`Shubhamsaboo/awesome-llm-apps`** · ⭐ 125,753 · 🔧 Python

## What is it?
Awesome LLM Apps is a curated repository containing over 100 open-source AI agents, agent skills, and Retrieval-Augmented Generation (RAG) applications. The project focuses on providing hand-built, tested end-to-end implementations that are Apache-2.0 licensed — meaning they're completely free and open-source, allowing you to clone, customize, and ship them without licensing concerns.

The repository is organized with each agent or RAG app living in its own subdirectory containing the necessary code, configuration files, and often Dockerfiles for containerized deployment. It explicitly supports multiple AI models including Claude, Gemini, GPT, DeepSeek, Llama, Qwen, and other open-source options, making it model-agnostic rather than locked into a single provider.

Beyond just providing templates, the project includes step-by-step tutorials hosted on Unwind AI that guide users through setting up and running these agents. The README showcases several example projects like Project Graveyard (an agent that autopsies dead side projects), Insurance Claim Live Agent Team (voice claims settled in real time), and others across different domains.

## How does it work?
The repository operates as a centralized collection of self-contained application templates, each structured with standard files: main application code (typically Python scripts or notebooks), requirements.txt for dependencies, Dockerfiles for containerized deployment, and README.md files explaining each project's purpose and setup instructions. The design allows users to browse the gallery, pick an agent that matches their use case, clone it locally, modify configuration parameters like API keys and model endpoints, and deploy it with minimal friction.

The Apache-2.0 licensing is a deliberate architectural choice that removes permission barriers — you're free to use these templates commercially or in personal projects without attribution requirements. This means the repository serves as a reliable source of production-ready code rather than just experimental notebooks. The modular organization ensures each agent can be run independently, making it easy to pick and choose only what you need rather than maintaining one monolithic system.

## Difference from Others
Unlike generic AI tool collections or individual agent repositories, Awesome LLM Apps is specifically curated around agents and RAG applications — not general-purpose LLM utilities or library collections. The repository emphasizes production-ready templates rather than experimental code or notebooks, with each project thoroughly tested end-to-end.

Compared to similar curated repositories like awesome-llm (which covers a broader range of LLM-related tools including libraries, APIs, and resources), this collection focuses tightly on deployable agent implementations and RAG apps. Many other agent collections are either single-project repositories or lack the comprehensive Apache-2.0 licensing that removes permission barriers. The inclusion of both simple agents and complex multi-agent teams (like Insurance Claim Live Agent Team) provides a range of sophistication levels not always present in comparable projects.
