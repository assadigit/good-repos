## What is it?
awesome-public-real-time-datasets is a curated collection of publicly available real-time data sources maintained by the team at bytewax.io. Inspired by awesome-public-datasets, this repository focuses specifically on live data streams that are normally accessed via HTTP or WebSockets. The list is organized into Free and Paid sections, with each subsection categorized by domain such as finance/crypto, weather, IoT, and more.

The project serves as a centralized reference for developers seeking to discover and integrate real-time data sources into their applications. Each entry includes links to official documentation, API endpoints, and often WebSocket URLs for live streaming data. The curation effort helps avoid the tedious process of searching through individual API provider websites to find real-time data capabilities.

The repository is open-source and maintained via GitHub, allowing community contributions through pull requests. It's particularly useful for developers building dashboards, monitoring systems, or applications that require live market data streams.
