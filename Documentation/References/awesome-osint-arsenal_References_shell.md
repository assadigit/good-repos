# awesome-osint-arsenal

> **TL;DR:** Curated OSINT toolkit with 751+ tools across 50 categories, multi-distro installers, and Georgian OSINT resources.

**`rawfilejson/awesome-osint-arsenal`** · ⭐ 1,172 · 🔧 Shell

## What is it?
The Awesome OSINT Arsenal is a comprehensive collection of over 751 open-source intelligence tools organized into 50 categories, designed to streamline reconnaissance and security research. It covers SOCMINT (social media intelligence), GEOINT (geospatial intelligence), network reconnaissance, dark web monitoring, forensic analysis, and more. Each tool includes verified installation instructions or direct links to the official repository, ensuring reliability and ease of integration.

Key features include multi-distro installers that work across various Linux distributions and Termux, a one-command installer script for quick deployment, and curated Georgian OSINT resources. The project emphasizes ethical hacking and penetration testing, making it a valuable asset for security professionals, researchers, and enthusiasts seeking efficient information gathering workflows.

## How does it work?
The repository is structured as a markdown-driven toolkit with each tool represented by a dedicated entry containing a brief description, command-line usage, and installation instructions. A shell script automates the installation process across multiple distributions, pulling dependencies where needed. Tools are sourced from verified upstream repositories, ensuring authenticity and up-to-date functionality.

This toolkit is essential for anyone involved in security research, open-source intelligence gathering, or forensic analysis because it consolidates dozens of specialized tools into a single, well-maintained collection.
