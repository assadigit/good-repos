# best-of

> **TL;DR:** Curated collection of 25 open-source project lists across 10 categories with quality scoring.

**`best-of-lists/best-of`** · ⭐ 1,749 · 🔧 N/A

## What is it?
This repository aggregates 25 high-quality open-source project lists across 10 categories, totaling over 43K stars. Each list is ranked by an automatically calculated quality score derived from metrics like GitHub stars, forks, and community engagement. The README includes badges showing project count (25), contribution welcome status, and last update date to indicate freshness.

## How does it work?
The project maintains a projects.yaml file listing all curated lists and individual projects within each category. Quality scores are computed by fetching data from GitHub APIs and various package registries to assess popularity, recency, and community interest. Users can submit issues or pull requests to add new lists, update existing entries, or request removals of outdated projects.

## Why is it important? (Core Value)
This repository serves as a centralized reference for discovering exceptional open-source tools, libraries, and frameworks. For the user specifically, it aligns with their objective to curate a personal knowledge base of useful tools and frameworks. The curated lists provide vetted starting points for finding AI agent frameworks, MCP servers, self-hostable software, and other developer utilities relevant to their interests in automation and infrastructure.

## Key Features & Technologies
- Curated 25 best-of lists across 10 categories
- Automatic quality scoring based on GitHub metrics
- Badge display for project count and contribution status
- Projects.yaml for easy editing and updates
- Issue/Pull request workflow for community contributions
- Links to guides for creating your own best-of list

## Difference from Others
Unlike generic "awesome" lists that are often maintained by single contributors without verification, this repository aggregates multiple curated lists with quality scores calculated from multiple metrics. It provides a centralized hub rather than scattered individual lists, making it easier to discover high-quality projects across different domains in one place.
