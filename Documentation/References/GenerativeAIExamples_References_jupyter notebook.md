# GenerativeAIExamples

> **TL;DR:** NVIDIA reference workflows for RAG pipelines, agentic AI, and GPU-accelerated LLM inference with Triton Server.

**`NVIDIA/GenerativeAIExamples`** · ⭐ 4,126 · 🔧 Jupyter Notebook

## What is it?
GenerativeAIExamples is NVIDIA's official repository of reference workflows and tutorials for developers looking to integrate with the NVIDIA software ecosystem. It serves as a starting point for building generative AI systems using NVIDIA's GPU-accelerated infrastructure, covering RAG pipelines, agentic workflows, model fine-tuning, and various specialized topics like Knowledge Graph RAG, Vision NIM, Data Flywheel, and Safer Agentic AI.

## How does it work?
The repository is organized into topic-based sections with corresponding notebooks, tools, and projects. Each section provides examples that leverage NVIDIA's NIM (NVIDIA Inference Microservices) platform, TensorRT for optimized model inference, and Triton Inference Server for serving models in microservice architecture. Documentation includes getting started guides, how-to tutorials, and reference materials to help developers integrate these workflows into their development stack.

## Why is it important? (Core Value)
This project is particularly valuable because it provides ready-to-use, GPU-accelerated implementations of common generative AI patterns using NVIDIA's ecosystem, which aligns with the user's interest in self-hostable alternatives and developer tools. ## Key Features & Technologies
- Uses NIM microservices

## Difference from Others
Unlike generic LLM example repositories, this collection is specifically optimized for NVIDIA's GPU-accelerated inference stack with TensorRT and Triton Server. It also includes agentic workflow examples beyond just model serving, covering topics like Data Flywheel and Safer Agentic AI which are not typically found in standard open-source LLM tutorials.
