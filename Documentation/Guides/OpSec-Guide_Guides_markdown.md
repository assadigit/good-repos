# OpSec-Guide

> **TL;DR:** OpSec guide offering privacy and security recommendations for web browsing and more.

**`Scrut1ny/OpSec-Guide`** · ⭐ 479 · 🔧 N/A

## What is it?
OpSec-Guide is a comprehensive guide focused on enhancing personal and professional privacy, anonymity, and security. It provides actionable recommendations for individuals seeking to protect themselves from tracking and mass surveillance. The project curates resources across multiple categories, including browser engines, search engines, and browser extensions, offering users structured guidance on selecting privacy-focused tools.

The guide covers both Gecko-based browsers like LibreWolf, Waterfox, Mullvad, and Tor, as well as Chromium-based options such as Brave and ungoogled-chromium. It also recommends privacy-respecting search engines including SearXNG, DuckDuckGo, Startpage, and Brave Search. For extensions, it lists tools like uBlock Origin, Violentmonkey, User-Agent Switcher, and SponsorBlock, each tailored to specific use cases.

This project serves as a curated reference resource rather than an automated system, relying on markdown documentation and external links to official sources for detailed information. It aims to help users make informed decisions about tools that prioritize privacy and security in their daily digital activities.

## How does it work?
The guide is structured as a markdown-based reference document organized into logical sections: browsers (subdivided by engine), search engines, and browser addons/extensions. Each section lists specific tool recommendations with links to official websites or documentation for further details.

Unlike automated systems or APIs, this project functions as a curated collection of resources that users can consult directly. It does not appear to rely on scraping, API integrations, or complex tooling beyond standard markdown formatting and external references. The information is presented in a clear, navigable format that allows users to quickly find relevant privacy-focused tools without needing to navigate multiple websites.

## Why is it important? (Core Value)
This project helps the user by offering a curated collection of privacy-focused browser and extension recommendations that align with their interest in self-hosted alternatives and security-conscious tooling. The guide can be referenced when evaluating tools for homelab or personal use, especially for browsers they might use for sensitive tasks. It provides structured information on privacy-respecting search engines and extensions, which supports the user's goal of building a personal knowledge base of useful tools organized by domain.

By consolidating these recommendations in one place, the project reduces the effort needed to research individual tool options. This is particularly valuable for someone curating GitHub projects into an Obsidian vault, as the guide serves as a reliable source for privacy and security considerations that can be cross-referenced with other tools like AI agents or automation scripts. It also complements the user's interest in developer productivity tools by offering practical advice on securing their own browsing environment.

## Difference from Others
While other operational security guides exist—such as the 'How To Be Anonymous' book or various curated privacy browser lists—this project stands out by focusing specifically on web browsing tools. Unlike broader guides that may cover email, messaging, or system hardening, OpSec-Guide zeroes in on browsers and extensions, making it a niche but highly relevant resource for developers who want to secure their web usage.

Additionally, many privacy browser recommendations are scattered across multiple sources, requiring users to consult several websites. This guide consolidates those recommendations in one place, providing a centralized reference that can be easily integrated into personal knowledge bases or workflow documentation.
