# build-ai-agents-free

> **TL;DR:** Free open-source guide to build AI agents with LangChain+LangGraph, Groq/Gemini, no paid APIs.

**`Moh4696/build-ai-agents-free`** · ⭐ 215 · 🔧 Python

## What is it?
This is a beginner-friendly tutorial and guide for building functional AI agents without paying for any APIs. The project walks readers through setting up a complete agent system using entirely free tools: LangChain and LangGraph as the framework, Groq or Google Gemini's free tier as the LLM backend, and running everything on your own machine with just Python and a text editor.

The guide specifically avoids the common pattern found in other tutorials where a paid API key is introduced mid-way through. It emphasizes that everything is free forever—no credit card required, no trial that expires, no bait-and-switch tactics. The project targets people who want to actually build agents that can reason, call tools, and loop until tasks complete, rather than just reading about them.

## How does it work?
The guide uses LangChain+LangGraph as the core agent-building framework (MIT-licensed), which provides the scaffolding for creating agents with tool-calling capabilities. For the LLM 'brain', it recommends Groq's free tier, which runs open models like Llama 3.3 70B at approximately 300 tokens per second and provides around 14,400 requests per day without a credit card. An alternative mentioned is Google's Gemini free tier with 1,500 requests/day and a million-token context window.

All execution happens on the user's own machine—no cloud dependencies beyond the API access. The guide likely walks through environment setup (pip install), connecting to Groq or Gemini via their console/API keys, and using LangGraph's create_agent function to stand up a working agent.
