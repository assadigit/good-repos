# llm_engineering

> **TL;DR:** Educational repo with hands-on projects for mastering LLM engineering concepts and practical skills.

**`ed-donner/llm_engineering`** · ⭐ 6,922 · 🔧 Jupyter Notebook

## What is it?
LLM Engineering is an educational repository designed to accompany a comprehensive course on mastering large language models. It structures learning into an eight-week journey where each week introduces progressively challenging projects that build on previous knowledge, allowing learners to develop deeper expertise systematically.

The repository focuses on practical application rather than just theory, with hands-on coding exercises that cover prompt engineering, model APIs, and real-world use cases. Projects are designed to be completed using Cursor, an AI-powered code assistant, which helps learners implement solutions efficiently while still gaining understanding of the underlying concepts.

## How does it work?
The course is structured as a sequence of weekly modules where each project builds on the previous ones, ensuring cumulative learning and skill development. Projects typically involve writing Python code that interfaces with various LLM APIs, experimenting with prompt engineering techniques, and integrating models into practical applications. The use of Cursor as the primary development environment means learners can leverage AI assistance for coding tasks while still developing their own understanding.
