# awesome-free-models

> **TL;DR:** Curated list of free AI models, APIs, and tools you can use without paying a cent.

**`12britz/awesome-free-models`** · ⭐ 1,216 · 🔧 N/A

## What is it?
This GitHub repository is a curated collection of freely available AI models, APIs, and tools that can be used without any cost. It aggregates open-weight models that can be self-hosted, free-tier APIs from major providers, and various local inference tools. The list includes sections for chatbot UIs, coding assistants, RAG/vector databases, agentic frameworks, fine-tuning tools, prompt engineering utilities, datasets, and model hosting platforms.

All links are verified to be live as of July 4, 2026, with archived or dead entries removed. The project tracks org renames and acquisitions/rebrands, ensuring the information stays current. It serves as a resource hub for developers and researchers looking to avoid vendor lock-in and credit card dependencies when working with AI.

The repository is licensed under CC0, making it freely redistributable. It contains over 29 model entries and 135 tool entries across 15 sections, providing a comprehensive starting point for anyone wanting to explore free AI solutions.

## How does it work?
The project is a static markdown repository with no backend services. Sections are organized by topic, each containing direct links to model pages, API documentation, or tool repositories. The owner manually updates entries and verifies that URLs resolve correctly, as indicated by the 'Last Checked' badge.

Each section in the README lists specific GitHub repositories, Hugging Face model cards, and official API docs. The structure is simple: a markdown file with headings, bullet points, and badges for verification status. No complex architecture or dependencies are involved.
