# design-patterns-for-humans

> **TL;DR:** Persian-language guide explaining design patterns (SOLID, Creational, Behavioral) with simple real-world and code examples.

**`3lf/design-patterns-for-humans`** · ⭐ 1,115 · 🔧 N/A

## What is it?
Design Patterns for Humans is a Persian-language educational repository that teaches software design patterns in plain, accessible language. It covers the SOLID principles (SRP, OCP, LSP, ISP, DIP), creational patterns (Simple Factory, Factory Method, Abstract Factory), and other GoF categories with real-world analogies and code examples to make abstract concepts tangible. The project is a translation and adaptation of the well-known English-language repository by Kamran Ahmed, which itself was adapted from a Python-focused variant, combining sources from both Persian and English technical literature.

## How does it work?
The repository is structured as a long-form Markdown document with a table of contents that organizes patterns into categories: SOLID principles, Creational, Structural, and Behavioral. Each pattern entry provides a plain-language definition, a real-world analogy, and code examples (originally Python-oriented) to illustrate the concept. The Persian translation was crafted by selecting the clearest definitions from multiple Farsi and English sources to maximize comprehension for native Persian speakers.

## Why is it important? (Core Value)
For a software engineer curating developer tools and frameworks, this resource builds foundational design-pattern fluency that makes it easier to evaluate the architectural quality of any codebase encountered in GitHub curation. Understanding SOLID principles and factory/adapter patterns directly supports assessing whether a tool is well-structured or tightly coupled—knowledge that complements technical due diligence on AI agent frameworks, MCP servers, and self-hosted alternatives. It also serves as a quick-reference when reviewing pull requests or contributing to open-source projects.

## Key Features & Technologies
- Persian-language translation of the popular design-patterns-for-humans guide
- Covers SOLID principles (SRP, OCP, LSP, ISP, DIP)
- Explains creational, structural, and behavioral GoF patterns
- Uses real-world analogies alongside code examples
- Based on the widely recognized kamranahmedse/design-patterns-for-humans original

## Difference from Others
Unlike the original English-language repository, this version removes the language barrier for Persian-speaking developers by translating and adapting the content with culturally resonant examples. It also merges insights from multiple Farsi and English technical sources rather than being a literal translation, aiming for clarity over fidelity. Compared to generic design-pattern textbooks, it keeps the informal, human tone of the original 'for humans' series, making patterns feel less academic.
