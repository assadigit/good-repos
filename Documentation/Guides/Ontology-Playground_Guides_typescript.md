# Ontology-Playground

> **TL;DR:** Interactive web app for learning ontologies, exploring Microsoft Fabric IQ, and designing RDF graphs – zero backend.

**`microsoft/Ontology-Playground`** · ⭐ 1,997 · 🔧 TypeScript

## What is it?
Ontology Playground is a free, open-source web application designed to help users learn about ontologies and explore Microsoft Fabric IQ. It provides a curated catalogue of pre-built ontologies across six domains (Retail, E-Commerce, Healthcare, Finance, Manufacturing, Education) that users can browse, search, and load instantly. Beyond consuming existing ontologies, the tool lets you design your own knowledge structures using a visual editor, then export the result as RDF/XML for use in semantic web applications or agent tooling.

## How does it work?
The application is built as a fully static site with no backend dependencies, making it lightweight and easy to host anywhere—from GitHub Pages to any static server. The UI is implemented with React and TypeScript for type-safe component development. Ontology data is loaded and rendered using Cytoscape.js, which powers an interactive node-and-edge graph explorer where users can pan, zoom, click nodes to inspect properties, and filter via a live search bar. RDF parsing handles the ingestion of ontology files, while the visual editor provides an intuitive interface for constructing new ontologies.

## Difference from Others
Similar ontology tools often come as heavyweight desktop applications (e.g., Protégé) or require database backends for persistence. Ontology Playground stands out by being fully static and browser-native, requiring no server setup or persistent storage—just download and run. It also includes a curated catalogue of official and community ontologies, which many standalone editors lack. The visual editor is specifically tailored for learning and exporting RDF/XML, whereas other graph explorers typically focus on visualization without editing capabilities. This combination of educational content, zero-backend simplicity, and Microsoft's backing makes it unique in the space.
