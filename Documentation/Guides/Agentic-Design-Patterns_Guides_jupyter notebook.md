# Agentic-Design-Patterns

> **TL;DR:** A comprehensive book/guide covering 21 chapters on AI agent design patterns with PDF materials and code notebooks.

**`evoiz/Agentic-Design-Patterns`** · ⭐ 2,243 · 🔧 Jupyter Notebook

## What is it?
This repository contains the complete materials for 'Agentic Design Patterns: A Hands-On Guide to Building Intelligent Systems' by Antonio Gulli. It includes all 21 chapters in PDF format along with accompanying code notebooks for hands-on learning. All author royalties are donated to Save the Children, making it an educational resource rather than a commercial product.

The guide covers foundational patterns including prompt chaining, routing, and parallelization; advanced techniques like reflection, tool use, planning, and multi-agent systems; memory and learning management; production patterns such as exception handling, human-in-the-loop workflows, and RAG; optimization strategies including resource-aware patterns and guardrails; plus real-world applications from GUI environments to broader systems.

## How does it work?
This is an educational book repository that combines PDF chapter materials with Jupyter notebooks for practical implementation. The structure follows a traditional book format organized into chapters, each pairing theoretical content with executable code examples. Readers can study the PDF explanations and then immediately experiment with the patterns using the provided notebooks in any Python environment.

The repository serves primarily as documentation and learning material rather than an active software system. It doesn't implement agents itself but provides the design patterns and best practices for building intelligent agent systems, making it a reference resource for developers looking to understand agent architecture principles.
