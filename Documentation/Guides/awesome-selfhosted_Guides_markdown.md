## What is it?
awesome-selfhosted is a curated collection of free software projects that can be self-hosted. It serves as a comprehensive list of network services and web applications that users can run on their own servers instead of relying on SaaS providers. This aligns with the philosophy of self-hosting promoted by GNU and privacy-focused communities.

Key features include its community-maintained nature, automated checks for broken links and unmaintained projects, availability in both Markdown (this GitHub repo) and HTML versions, and a separate page for non-free software. It emphasizes open-source software and provides a starting point for users interested in building their own homelab or self-hosting infrastructure.

The project is part of the "awesome" series (like awesome-python), making it easy to navigate and discover relevant tools. It's a valuable resource for developers, privacy enthusiasts, and anyone looking to reduce dependency on cloud providers.

## How does it work?
awesome-selfhosted is primarily a curated Markdown list maintained within a GitHub repository, serving as the source for an HTML version hosted at awesome-selfhosted.net. The project employs GitHub Actions workflows to automatically detect broken links (check-dead-links.yml) and identify unmaintained projects (check-unmaintained-projects.yml), ensuring the list remains current and helpful. The README explicitly notes that non-free software is listed on a separate page, and the project emphasizes free software alignment with GNU philosophy. Each entry in the Markdown file typically includes a name, description, URL, and license information, allowing users to quickly assess relevance and compatibility with their infrastructure needs. The core value proposition is that it aggregates thousands of self-hostable software recommendations in one place, making discovery and decision-making significantly easier for users building homelabs or seeking privacy-focused alternatives to SaaS services.
