# Amphion

> **TL;DR:** Open-source toolkit enabling reproducible research in audio, music, and speech generation with models and evaluation metrics.

**`open-mmlab/Amphion`** · ⭐ 9,920 · 🔧 Python

## What is it?
Amphion is a comprehensive open-source toolkit designed to support reproducible research in audio, music, and speech generation. It provides a unified platform for researchers and engineers to experiment with various models including text-to-speech (TTS), voice conversion (VC), singing voice conversion (SVC), text-to-audio (TTA), and vocoders. The toolkit includes implementations of numerous state-of-the-art models like VALL-E, NaturalSpeech2, FastSpeech2, VITS, Emilia, MaskGCT, and VEVO, along with evaluation metrics for comparing model performance.

## How does it work?
The toolkit is built primarily in Python using PyTorch as its deep learning framework. It follows a modular architecture where each subdomain (TTS, VC, SVC, TTA, Vocoder) contains its own model implementations, training scripts, and evaluation code. The project maintains extensive example code (egs) for different tasks, allowing users to reproduce official results or train custom models. Evaluation modules provide standardized metrics like Mel-Cepstral Distortion (MCD) and Mean Opinion Score (MOS), enabling fair comparison across different approaches.

## Why is it important? (Core Value)
This toolkit is highly valuable because it consolidates dozens of audio generation models and evaluation tools into one actively maintained repository with over 9.9K stars, indicating strong community adoption. For the user specifically, Amphion offers a well-documented, self-hostable alternative to scattered model implementations and online demos—aligning perfectly with their interest in self-hosted software and reliable open-source projects from major tech companies (open-mmlab). The comprehensive evaluation tools help researchers compare models rigorously, and the modular design makes it easy to integrate specific components into personal projects or build custom audio generation pipelines without depending on external services.

## Key Features & Technologies
- PyTorch-based deep learning framework
- Models for text-to-speech (VALL-E, FastSpeech2, VITS, Emilia)
- Voice conversion implementations (VEVO, MaskGCT)
- Singing voice conversion models
- Text-to-audio generation
- Comprehensive evaluation metrics (MCD, MOS)
- Extensive example code and training scripts

## Difference from Others
Unlike fragmented model repositories or commercial audio AI services, Amphion provides a unified toolkit covering the full spectrum of audio generation tasks with standardized evaluation protocols. While other projects might focus on a single domain (e.g., just TTS), Amphion's cross-domain approach and inclusion of both models and evaluation tools make it particularly useful for comparative research.
