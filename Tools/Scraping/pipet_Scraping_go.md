# pipet

**`bjesus/pipet`** · ⭐ 4,745 · 🔧 Go

## What is it?
Command-line web scraper supporting HTML/JSON parsing and JS evaluation via unix pipes.

## How does it work?
Pipet uses curl to fetch web content and pipes it through a series of Unix commands (jq, grep, etc.) for processing. It also supports client-side JavaScript evaluation via Playwright, allowing dynamic rendering. The tool is written in Go and designed to be extended with custom pipelines.

## Why is it important? (Core Value)
This project offers a powerful, hackable scraping solution ideal for developers who prefer command-line tools. Its Unix pipe architecture allows flexible data extraction workflows without relying on heavy GUI-based frameworks. For users interested in automation and self-hosted tools, it provides a lightweight alternative to commercial scrapers.

## Key Features & Technologies
- HTML parsing
- JSON parsing
- Client-side JavaScript evaluation via Playwright
- Unix pipe support
- curl-based fetching
- MIT license
- Go implementation

## Difference from Others
Unlike browser-only scrapers like Puppeteer or Playwright alone, pipet integrates curl for efficient resource fetching and leverages Unix pipes for modular processing. This makes it particularly suited for complex data extraction tasks requiring multiple transformation steps.
