# Lead-Generation

> **TL;DR:** Python web scraper that extracts business leads from Google Maps, websites, and directories for sales outreach.

**`Madi-S/Lead-Generation`** · ⭐ 275 · 🔧 Python

## What is it?
Lead-Generation is a Python-based tool designed to extract business contact information such as websites, email addresses, and phone numbers from Google Maps and other online directories. The project focuses on providing a self-hostable solution for lead generation without requiring programming expertise, with plans to expand functionality through MCP plugins and automated outreach systems.

## How does it work?
The scraper leverages browser automation libraries like Chromedriver and Playwright to navigate Google Maps listings, extract structured data from HTML pages, and handle asynchronous operations for efficient large-scale scraping. It includes parser components to clean and organize extracted information, with sync/async implementations planned to accommodate different use cases. Future enhancements include Gmail SMTP integration for automated email outreach and Twilio support for phone number handling.

## Difference from Others
Unlike commercial SaaS solutions like Apollo.io or ZoomInfo, Lead-Generation is open-source and fully self-hostable, giving users complete control over scraping logic and data handling. While many scrapers focus on single sources, this project emphasizes versatile techniques across multiple directories with plans to add more sources like 2gis. Its integration path for MCP servers distinguishes it from generic automation tools, positioning it as a specialized lead generation resource.
