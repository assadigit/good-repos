# crawl4ai

> **TL;DR:** Crawl any site into clean LLM-ready markdown — the scraping half of your RAG pipeline.

**`unclecode/crawl4ai`** · ⭐ 42,987 · 🔧 Python

## What is it?
A web crawler designed for LLMs — turns entire sites into clean markdown and structured data, ready for RAG pipelines.

## How does it work?
Async crawling engine with Playwright rendering, automatic content extraction to markdown, and LLM-friendly chunking strategies.

## Why is it important? (Core Value)
Feeding LLMs real web content is the missing half of most RAG stacks. crawl4ai produces the clean half for free.

## Key Features & Technologies
- Playwright-backed JS rendering
- Markdown-first extraction
- Structured output schemas
- RAG-optimized chunking
