# free-soundsnap-audios

> **TL;DR:** Web app and userscript that fetches audio sources from Soundsnap without requiring a premium subscription.

**`GooglyBlox/free-soundsnap-audios`** · ⭐ 16 · 🔧 JavaScript

## What is it?
free-soundsnap-audios is a simple tool that allows users to download audio files from the Soundsnap website (https://www.soundsnap.com) without needing a paid premium account. It provides two access methods: a web application and a userscript for direct browser use. The project serves as a proof of concept for accessing Soundsnap's audio content freely.

## How does it work?
The tool operates by parsing the HTML/JavaScript of Soundsnap pages to locate embedded audio source URLs, which are then extracted and made available for download. For the web app option, it runs on Node.js (npm-based) with a development server listening on localhost:3000. The userscript variant injects functionality directly into the browser's DOM when loaded in Chrome/Firefox, intercepting page loads or analyzing the current page to find audio resources.
