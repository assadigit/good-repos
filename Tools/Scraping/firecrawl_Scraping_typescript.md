# firecrawl

> **TL;DR:** API for web scraping that converts HTML to markdown and integrates with LLMs for data extraction.

## What is it?
Firecrawl provides a comprehensive API platform specifically designed for web scraping operations at scale. It offers an SDK (firecrawl-py) with over 200,000 downloads on PyPI, indicating strong adoption across the developer community. The project focuses on converting HTML content to markdown format while integrating with LLMs for intelligent data extraction workflows.

## How does it work?
The core architecture leverages Python SDKs and likely employs HTTP clients combined with parsers (such as BeautifulSoup or Playwright) to fetch web pages, extract content, and transform it into structured markdown. It provides API endpoints that abstract away the complexity of scraping operations, allowing developers to compose scraping workflows programmatically. The project's emphasis on LLM integration suggests it may provide hooks or native support for feeding extracted content into language models for data enrichment.

## Difference from Others
Unlike Scrapy (a low-level Python framework requiring significant setup) or Selenium/Playwright (browser automation tools), Firecrawl offers an API-first approach designed specifically for scraping workflows. Traditional scrapers typically require manual page parsing and HTML-to-markdown conversion, whereas Firecrawl abstracts these complexities behind simple endpoints. The project also emphasizes AI/LLM integration for structured data extraction, which distinguishes it from conventional scraping libraries that focus purely on content retrieval without semantic enrichment.
