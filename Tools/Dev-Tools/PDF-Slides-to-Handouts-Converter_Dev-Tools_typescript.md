# PDF-Slides-to-Handouts-Converter

> **TL;DR:** Privacy-first PDF handout generator converting slides to printable n-up layouts using Next.js and pdf-lib.

**`flodlol/PDF-Slides-to-Handouts-Converter`** · ⭐ 76 · 🔧 TypeScript

## What is it?
A privacy-first PDF handout converter built with Next.js and pdf-lib. Drag-and-drop any multi-page PDF presentation into your browser, select a layout (2, 4, 6, or 9 slides per page), and download a printable handout without uploading files to any server. No sign-up, no subscriptions, no tracking—everything runs locally for maximum privacy and security.

## How does it work?
The project uses Next.js to build a client-side web application that processes PDF files entirely in the browser. It leverages pdf-lib (and possibly pdfjs) for PDF manipulation, allowing users to combine multiple slides onto single pages in various n-up layouts. Because all processing happens locally, there is no backend server involved—your files never leave your device. The interface provides a simple drag-and-drop area, layout selection controls, and a preview/render step before generating the downloadable result.
