# Telegram-Drive

> **TL;DR:** Open-source Tauri desktop app that turns your Telegram account into a local-first cloud drive for files.

**`caamer20/Telegram-Drive`** · ⭐ 5,077 · 🔧 TypeScript

## What is it?
Telegram Drive is an open-source client that turns your own Telegram account into a local-first file workspace. It lets you organize, transfer, preview, stream, sync, and share files stored in Saved Messages and Telegram channels.

It targets Windows, macOS, Linux, Android, and Google TV, positioning itself as an unlimited, secure cloud storage drive without requiring a separate paid cloud-drive account.

## How does it work?
It uses the Telegram API to treat your authenticated Telegram account as the storage backend, with Saved Messages and channels acting as file locations.

The app is built on Tauri, Rust, and React/TypeScript: Rust provides the system-level client layer, while the React UI presents a drive-like interface for browsing, moving, previewing, streaming, syncing, and sharing files.

## Why is it important? (Core Value)
It solves the problem of depending on separate proprietary cloud-storage services by reusing an existing Telegram account as a cross-platform file drive.

For your knowledge base, it is a concrete open-source alternative to SaaS storage and a local-first desktop tool that can reduce friction in moving files between devices. Although it is not an AI agent or MCP server, its Tauri/Rust/React architecture is relevant if you study local-first client design.

## Key Features & Technologies
- Tauri-based cross-platform client
- Rust system layer
- React/TypeScript UI
- Telegram API integration
- Supports Windows, macOS, Linux, Android, and Google TV
- File organization, transfer, preview, streaming, sync, and sharing

## Difference from Others
Compared with traditional cloud-drive clients, Telegram Drive does not require a separate storage vendor account; it uses your own Telegram account and Saved Messages/channels as the file layer.

Compared with generic Telegram bots or web viewers, it is an open-source cross-platform Tauri application focused on a local-first drive workflow rather than one-off chat file retrieval.
