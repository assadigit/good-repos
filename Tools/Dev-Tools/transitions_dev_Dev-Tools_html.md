# transitions.dev

> **TL;DR:** Collection of reusable CSS transitions for web apps with copy-ready snippets.

**`Jakubantalik/transitions.dev`** · ⭐ 2,245 · 🔧 HTML

## What is it?
Transitions.dev is an interactive collection of reusable CSS transitions. Each card on the index page demonstrates a different interaction pattern and ships a copy-ready, portable CSS snippet for each. The live site showcases 12 transition patterns including card resize, number pop-in, notification badge, text states swap, menu dropdown, modal open/close, panel reveal, page side-by-side, icon swap, success check, avatar group hover, and error state shake. Each card includes a copy button that emits a self-contained CSS snippet using semantic custom properties on :root, namespaced t-* transition rules, and a @media (prefers-reduced-motion: reduce) guard, making it easy to drop into any project without dependencies.

## How does it work?
The site runs as a static web application. Each transition is implemented using modern CSS with custom properties and namespaced selectors (e.g., t-card-resize). JavaScript on the index page detects copy button clicks and inserts the appropriate CSS snippet into the clipboard. The design emphasizes portability and accessibility, ensuring reduced-motion users get a fallback. No build tools or frameworks are required beyond standard web tech.

## Why is it important? (Core Value)
For a software engineer focused on AI agents, developer tools, and automation, this project offers ready-to-use UI polish that can be integrated into any self-hosted web application—whether it's an agent dashboard, a MCP server UI, or a SaaS alternative. By providing copy-ready CSS snippets, you save development time and ensure consistent design language across projects. It also supports accessibility via the prefers-reduced-motion guard, aligning with best practices for production-grade tools.

## Key Features & Technologies
- Copy-ready CSS snippets
- Semantic :root custom properties
- Namespaced t-* transition rules
- @media (prefers-reduced-motion) guard
- Interactive index page with copy buttons
- Pure web tech (no framework dependencies)
- Accessible design

## Difference from Others
Unlike animation libraries like Framer Motion or GSAP, which require JavaScript runtime and often depend on a framework, Transitions.dev delivers pure CSS that can be pasted directly into any project. It also avoids pulling in demo-specific styles, ensuring your CSS remains clean and portable. While other CSS transition collections exist, this one emphasizes self-contained snippets with accessibility guards.
