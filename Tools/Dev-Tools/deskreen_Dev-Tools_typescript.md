# deskreen

> **TL;DR:** Turns any web browser into a secondary screen using WebRTC.

**`pavlobu/deskreen`** · ⭐ 21,133 · 🔧 TypeScript

## What is it?
Deskreen is an Electron.js based application that uses WebRTC to make a live stream of your computer screen to a web browser on any device. It is available for MacOS, Windows and Linux operating systems. The current open-source Community Edition version has limited features, with a Pro version planned for more advanced functionality.

## How does it work?
Deskreen runs as an Electron application that establishes WebRTC peer connections between the host computer and client devices with web browsers. The architecture includes a server component (darkwire-io) that handles the WebRTC signaling and relay, while a client-viewer module serves the screen streaming interface. On startup, it performs npm install of dependencies, cleans the build cache, and runs production mode to start the streaming service.

## Why is it important? (Core Value)
This project provides a privacy-focused, self-hosted screen-sharing solution that directly aligns with your interest in self-hostable alternatives to SaaS products and homelab infrastructure. By running Deskreen on your own network, you avoid sending sensitive screen content through proprietary services. The WebRTC-based architecture means it works over WiFi without requiring physical cables or network adapters, making it ideal for secondary monitor setups. Additionally, it's a developer productivity tool—once configured, you can have multiple devices display different aspects of your workflow simultaneously, which supports your automation and workflow objectives.

## Key Features & Technologies
- Electron.js application
- WebRTC streaming protocol
- TypeScript codebase
- End-to-end encryption support
- Cross-platform (Windows/MacOS/Linux)
- Self-hosted open-source Community Edition

## Difference from Others
Unlike OBS Studio or ShareX which are primarily for recording/streaming to services like Twitch, Deskreen is specifically designed for displaying your screen on any web browser device. Compared to proprietary alternatives like Duet Display or Splashtop, it's open-source with a privacy-first approach that lets you host everything locally. The Electron + WebRTC combination means it runs entirely client-side without needing backend infrastructure for the streaming itself.
