# FinanceDatabase

> **TL;DR:** Open financial symbol database covering equities, ETFs, crypto, currencies with community-maintained CSV data.

**`JerBouma/FinanceDatabase`** · ⭐ 8,152 · 🔧 Python

## What is it?
FinanceDatabase is a massive, free repository of financial symbols covering equities, ETFs, funds, indices, currencies, cryptocurrencies and money markets. It serves anyone with any type of financial product categorization entirely for free, relying on community involvement to add, edit, and remove tickers over time.

The project uses CSV files that can be edited by anyone, even those without coding experience, making contributions easy. It also provides a Python package on PyPI (financedatabase) that loads these CSVs into simple data structures for analysis.

The repository includes documentation at jeroenbouma.com/projects/financedatabase and sponsorship options via GitHub Sponsors and Buy Me a Coffee, encouraging community support while keeping the data open-source.

## How does it work?
The FinanceDatabase stores its data in CSV files that anyone can edit, eliminating the need for a complex backend. Contributors upload CSV updates or modify existing files via the project's repository, which includes scripts to parse these files into a unified JSON format. The package is available on PyPI as a Python library that loads the CSV data and exposes it as simple dictionaries or DataFrames for analysis. Documentation at jeroenbouma.com/projects/financedatabase provides usage examples and API reference.

## Why is it important? (Core Value)
FinanceDatabase provides a free, open-source data source for financial symbols that can be directly used in AI agents or research pipelines. For developers building autonomous agents that need to fetch fundamental data (e.g., equity prices, ETF compositions, crypto market caps), this repository offers CSV files that can be parsed locally, avoiding reliance on paid APIs or SaaS services. Its community-driven model aligns with the user's interest in self-hostable tools and open-source alternatives, making it a valuable addition to a homelab data collection system. Additionally, its integration with OpenBB (an open-source financial data framework) means it can serve as a complementary data feed for agents that already consume OpenBB data.

## Difference from Others
Unlike OpenBB, which provides programmatic access via Python packages and APIs, FinanceDatabase focuses on a publicly editable CSV data store that anyone can contribute to without coding. It covers a broader set of financial symbols (including cryptocurrencies and money markets) and is completely free with no rate limits, making it ideal for self-hosted or offline analysis. Its community-driven model also means updates are faster as non-coders can add tickers directly.
