# optimizerDuck

**`itsfatduck/optimizerDuck`** · ⭐ 5,549 · 🔧 C#

## What is it?
optimizerDuck is a free, open-source Windows optimization tool focused on performance, privacy, and simplicity. It removes bloatware and unnecessary services (debloat), disables telemetry and privacy tracking, and applies performance-oriented registry tweaks to improve system responsiveness. The project is licensed under GPL-3, provides portable installers and GitHub releases, and includes a community-driven CI workflow for automated testing.

## How does it work?
The application is built with C# and the .NET runtime, using WinUI for its modern interface. Core logic consists of reading configuration files to determine which tweaks to apply, then executing system-level changes via registry edits, service modifications, and PowerShell scripts. It runs on Windows 10/11 and is distributed as compiled binaries or portable apps from GitHub releases, with CI pipelines ensuring builds pass before each version.
