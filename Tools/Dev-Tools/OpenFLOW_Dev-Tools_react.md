# OpenFLOW

> **TL;DR:** Open-source PWA diagramming tool with auto-save, privacy-first local storage, and JSON import/export.

**`leonj1/OpenFLOW`** · ⭐ 21 · 🔧 N/A

## What is it?
OpenFLOW is an open-source Progressive Web App (PWA) built with React and the Isoflow library for creating beautiful isometric diagrams entirely in your browser with offline support. It features auto-save every 5 seconds, privacy-first local storage, import/export as JSON files, and works without internet connection.

This tool stands out for its privacy-first design and open-source nature, making it ideal for users concerned about data leakage or wanting full control over their documentation workflow.

## How does it work?
OpenFLOW runs purely client-side using React for its UI framework and the Isoflow library to render isometric 3D-style diagrams. Diagrams are automatically saved every 5 seconds to browser storage (likely localStorage or IndexedDB) with a Quick Save option for immediate persistence, while all data remains local for privacy. The app also implements PWA service workers to cache assets and enable offline functionality, allowing users to create and edit diagrams without an internet connection.

## Why is it important? (Core Value)
For a developer focused on self-hostable tools and workflow automation, OpenFLOW offers a privacy-first diagramming solution that runs entirely locally, eliminating reliance on SaaS platforms like Lucidchart or Miro. This makes it ideal for homelab environments where data sovereignty matters, and its open-source nature allows integration into existing documentation systems. The auto-save functionality ensures no work is lost, while JSON export/import enables version control and sharing without cloud dependencies.

## Key Features & Technologies
- Isometric Diagramming
- Auto-Save (every 5 seconds)
- Privacy-First Local Storage
- Import/Export JSON
- Offline Support

## Difference from Others
Unlike commercial diagramming tools such as Lucidchart or Miro, OpenFLOW is open-source and stores all data locally via browser storage rather than requiring cloud accounts. Its privacy-first design means no telemetry or remote storage, making it suitable for users concerned about data leakage. Additionally, its PWA architecture provides true offline capability, whereas many alternatives only offer basic export features or require persistent internet connections.
