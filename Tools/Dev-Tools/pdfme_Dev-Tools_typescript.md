# pdfme

> **TL;DR:** Open-source TypeScript PDF generator with React UI and WYSIWYG template designer.

**`pdfme/pdfme`** · ⭐ 4,668 · 🔧 TypeScript

## What is it?
pdfme is an open-source PDF generation library built with TypeScript and React. It provides a WYSIWYG template designer for creating PDF layouts visually, a PDF viewer for previewing generated documents, and powerful generation capabilities that work in both browser and Node.js environments.

Under the hood it uses pdf-lib for PDF manipulation, allowing developers to programmatically create PDFs from JSON templates or export designs from the editor. The project is MIT-licensed and maintained by a community, making it free to use and modify.

## How does it work?
The core of pdfme is the TypeScript library that wraps pdf-lib, providing a programmatic API for PDF creation. It supports both browser and Node.js environments, allowing integration into web applications or server-side workflows.

The React-based UI offers a visual editor where users can design templates by adding text, images, and tables, which are then exported as JSON. When generating PDFs, the library takes either a JSON template or a DOM snapshot and renders it into a PDF document using pdf-lib's underlying capabilities.

## Why is it important? (Core Value)
For a developer focused on automation and self-hosted tools, pdfme offers a lightweight, open-source solution for generating PDFs without relying on SaaS services like Adobe or cloud PDF APIs. Its TypeScript-first approach integrates smoothly into modern JavaScript/TypeScript projects.

The React editor makes template creation accessible to non-technical users, while the MIT license means it can be freely used, modified, and deployed in any environment—including homelab servers—making it a credible addition to a personal knowledge base of developer productivity tools.

## Difference from Others
Compared to standalone pdf-lib, pdfme adds a visual editor and React-based UI, making it accessible for non-technical users.

Unlike other PDF generators like jsPDF or Puppeteer (which focus on screenshots), pdfme is purpose-built for creating structured PDFs from templates. It also provides both client-side and server-side usage, whereas many alternatives only work in one environment.
