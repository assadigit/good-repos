# supertonic

> **TL;DR:** Self-hosted TTS engine with pre-built binaries for Python, Rust, Swift, and more.

**`supertone-inc/supertonic`** · ⭐ 13,246 · 🔧 Swift

## What is it?
Supertonic is a lightning-fast, on-device text-to-speech engine that runs natively via ONNX. It provides pre-built binaries across multiple programming languages including Python, Rust, Swift (iOS/macOS), Java, Go, C#, and Node.js, making it highly portable across platforms. The project emphasizes accuracy alongside speed, supporting multilingual TTS capabilities.

## How does it work?
The project uses ONNX Runtime as its backend for inference, allowing Supertonic to load models directly from Hugging Face or custom ONNX files. It provides platform-specific binary packages so developers can integrate the TTS engine into their projects without needing to compile or manage dependencies manually.

## Key Features & Technologies
- ONNX Runtime backend
- Multi-language support (Python, Rust, Swift, Java, Go, etc.)
- Self-hosted binaries for various platforms
- WebGPU integration
- Hugging Face model support

## Difference from Others
Compared to other TTS engines like Coqui TTS or Piper, Supertonic focuses on providing pre-built binaries for many languages and integrating with ONNX Runtime. This makes it more portable and easier to integrate into diverse projects, especially those targeting multiple platforms simultaneously.
