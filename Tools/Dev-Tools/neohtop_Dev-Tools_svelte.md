# neohtop

> **TL;DR:** Modern cross-platform system monitor built with Rust, Tauri & Svelte for desktop resource tracking.

**`Abdenasser/neohtop`** · ⭐ 9,049 · 🔧 Svelte

## What is it?
NeoHtop is a modern, cross-platform system monitoring application that provides detailed resource tracking for your desktop environment. Built on the Tauri framework with Rust and Svelte, it offers a contemporary UI with dark/light mode support and Apple notarization for macOS compatibility.

The project combines high-performance Rust code for system metrics collection with Svelte's reactive frontend for a smooth user experience, all wrapped in Tauri's lightweight desktop framework. This architecture ensures both responsiveness and minimal resource overhead during operation.

## How does it work?
NeoHtop leverages Tauri as its desktop framework to handle windowing, system APIs, and cross-platform compatibility (Windows, macOS, Linux). The UI layer is built with Svelte, providing a reactive, component-based frontend that updates efficiently as system metrics change. Under the hood, Rust handles the performance-critical path for gathering CPU, memory, disk, and network statistics, compiled to native binaries on each platform.

The app icon and screenshot suggest a clean, modern interface design with dark/light mode support, following platform-native aesthetics. The README also indicates Apple notarization has been applied, ensuring smooth integration on macOS.

## Why is it important? (Core Value)
This project delivers self-hosted system monitoring without relying on proprietary tools or SaaS services. For developers, it provides visibility into their development environment across all major platforms with a single installation.

For your specific interests, NeoHtop aligns well with your goals: it's self-hostable (no cloud dependency), built with Rust and Tauri (open-source technologies), and cross-platform. As someone focused on developer productivity tools and infrastructure, you can use this to monitor system resources locally without vendor lock-in. The open-source nature means you can inspect or modify the code if needed. It's particularly useful for homelab or personal development setups where you want full control over monitoring tools rather than depending on built-in OS utilities that may be limited in functionality or UI.

## Difference from Others
Unlike terminal-based monitors like htop or btop, NeoHtop provides a modern graphical interface while still being self-hosted. Compared to native OS tools (Windows Task Manager, macOS Activity Monitor), it offers cross-platform consistency and a more contemporary UI. The Tauri approach also gives it advantages over Electron-based alternatives: Rust's smaller memory footprint and better system-level access. It fills the gap between lightweight terminal tools and heavy GUI monitors with a modern, performant middle ground.
