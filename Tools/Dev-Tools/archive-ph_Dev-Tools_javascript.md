# archive-ph

> **TL;DR:** Firefox extension that adds a context menu to open links in archive.ph quickly.

**`johuellm/archive-ph`** · ⭐ 6 · 🔧 JavaScript

## What is it?
archive-ph is a minimal Firefox web extension that adds a right-click context menu option for opening the selected link in archive.ph. Its purpose is to make on-demand web archiving easier from normal browsing. It does not provide a full archive client or local storage; it simply forwards links to the archive.ph service.

## How does it work?
The project is built as a Firefox WebExtension. It registers a context menu entry for links and, when selected, sends the link URL to archive.ph so the user can create a snapshot. Archive.ph then captures the page on demand, including support for JavaScript-heavy sites and progressive web apps according to the README.

## Why is it important? (Core Value)
For a developer/researcher who values reproducible references and workflow efficiency, this extension offers a low-friction way to preserve cited pages, documentation, or dynamic web sources before they change or disappear. It is useful as a lightweight archival shortcut in a research or reading workflow, though it relies on the external archive.ph service rather than providing self-hosted storage.

## Key Features & Technologies
- Firefox WebExtension
- Adds a context menu item for links
- One-click forwarding to archive.ph
- Relies on archive.ph snapshot capture
- Minimal add-on with no visible configuration

## Difference from Others
Compared with general bookmark managers or full web-archive clients, this project is intentionally thin and focused: it does not manage collections, sync bookmarks, or store archives locally. Its main advantage is direct integration with archive.ph through the browser context menu.
