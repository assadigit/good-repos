# bifrost

> **TL;DR:** CLI file transfer tool that bridges your computer and phone via QR code with end-to-end encryption.

**`axiom0x0/bifrost`** · ⭐ 59 · 🔧 Go

## What is it?
Bifrost is a CLI utility that enables you to bridge files between your computer and phone directly, without relying on cloud services or physical cables. It supports two-way transfers where you can both send and receive files in the same session, and it also lets you browse a directory on your computer as if it were a mobile-friendly file picker on your phone.

## How does it work?
The tool operates as a single binary that serves a local HTTP server when invoked. It uses AES-256-GCM encryption with the key embedded directly in the QR code, so keys never traverse the network—encryption happens locally on both ends. The mobile interface is a simple web page generated by the server, which displays files with download buttons and an upload form for two-way transfers.

## Why is it important? (Core Value)
This project aligns perfectly with your interest in self-hostable alternatives to SaaS products: it provides a privacy-focused way to move files between devices without uploading them to any third-party cloud service. ## Key Features & Technologies
- Two-way transfers in a single session
- Directory browsing as mobile file picker
- End-to-end encryption (AES-256-GCM)
- Zero config—single binary, no accounts
- Available for Linux, macOS, and Windows
- Go install option via go install github.com/axiom0x0/bifrost@latest
- Build from source with make install or make all

## Difference from Others
Compared to cloud-based file sharing services (Google Drive, Dropbox) or general-purpose sync tools like Syncthing, Bifrost is purpose-built for quick, encrypted transfers via QR code without requiring persistent internet connectivity or account management. Unlike SendAnywhere which focuses on web uploads, this CLI tool works directly from your terminal and can serve a local web page for mobile access. Its emphasis on encryption embedded in the QR code rather than transmitted over the network also distinguishes it from many other peer-to-peer file transfer utilities.
