# WEF

**`D3Ext/WEF`** · ⭐ 3,016 · 🔧 Shell

## What is it?
Wi-Fi Exploitation Framework (WEF) is a Bash-based tool for security researchers to test WPA/WPA2/WPS/WEP vulnerabilities on 2.4 GHz and 5 GHz networks. It provides an intuitive interface with automated/manual attack techniques, detailed logging, and customizable options. This is not a professional tool.

## How does it work?
WEF leverages common Wi-Fi testing utilities (e.g., Aircrack-ng) and runs as a Bash script that orchestrates various attacks against wireless networks. It supports both 2.4 GHz and 5 GHz bands, logs attack results, and allows users to customize parameters. The framework is designed for Kali Linux and integrates with the OSCP curriculum.

## Why is it important? (Core Value)
For a self-hosted knowledge base focused on developer productivity, security testing, and automation, WEF offers a ready-to-use, MIT-licensed CLI tool that can be integrated into your own infrastructure or used as a reference implementation. It aligns well with your interest in open-source alternatives to commercial Wi-Fi testing suites and provides a concrete example of how to build custom penetration testing pipelines.

## Key Features & Technologies
- Supports WPA/WPA2/WPS/WEP attacks
- Works on 2.4 GHz & 5 GHz networks
- Detailed logging and customizable options
- Intuitive Bash-based interface
- Designed for Kali Linux
- MIT license with active maintenance

## Difference from Others
Unlike Aircrack-ng (single tool) or Reaver (WPS recovery only), WEF unifies multiple attack vectors into a single framework. It also differs from commercial suites by being self-hostable and actively maintained, making it suitable for personal knowledge bases and open-source collections.
