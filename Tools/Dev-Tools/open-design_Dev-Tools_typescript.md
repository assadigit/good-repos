# open-design

> **TL;DR:** Local-first desktop app that uses AI agents to generate prototypes, landing pages, dashboards, slides, images & video — exports real files (HTML/PDF/PPTX/MP4).

**`nexu-io/open-design`** · ⭐ 75,814 · 🔧 TypeScript

## What is it?
Open Design is an open-source desktop application that positions itself as a Claude Design alternative. It's built around the concept of using coding AI agents as the design engine — you can prompt models like Codex, OpenCode, Pi, and others to generate prototypes, landing pages, dashboards, slides, images, and video content. The app then exports real files including HTML/PDF/PPTX/MP4 formats, giving you tangible deliverables rather than just in-app previews.

## How does it work?
The application runs as a local-first desktop app, likely built with Rust (given the repo topics include rust). It integrates with multiple coding agents — Codex, OpenCode, Pi, and others — that can be invoked through the BYOK (Bring Your Own Key) system supporting 20+ CLI tools. Sessions are designed to persist across turns so you don't lose progress on long design workflows, and it includes model picker functionality to switch between different AI models quickly without configuration.
