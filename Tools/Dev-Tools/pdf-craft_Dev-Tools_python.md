# pdf-craft

> **TL;DR:** PDF conversion tool that handles scanned documents with OCR.

## What is it?
pdf-craft is a Python-based PDF processing library focused on converting PDF files into various formats, with particular emphasis on handling scanned book PDFs. The project integrates DeepSeek-OCR for extracting text from image-based PDF pages, enabling users to process digitized books and documents that would otherwise be difficult to work with programmatically.

## How does it work?
The tool likely leverages OCR models (DeepSeek-OCR) to extract text content from scanned PDF pages, then converts the processed documents into multiple output formats such as plain text, Markdown, or HTML. Based on its PyPI distribution and Python version support badges in the README, it provides a pip-installable interface with CLI or API usage patterns for batch processing workflows.

## Difference from Others
