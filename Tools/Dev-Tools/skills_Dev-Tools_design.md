## What is it?
Skills for Design Engineers is a knowledge resource that provides curated design expertise specifically for software engineers building user interfaces. The project draws from years of experience working at companies like Vercel and Linear, focusing on helping developers make better decisions about animations, easing functions, border styling, and other subtle UI/UX details that can compound over time to significantly impact user experience.

The project emphasizes that AI doesn't replace domain expertise—it amplifies it. Rather than trying to automate design decisions, it provides structured guidance that developers can reference when making difficult choices. This approach recognizes that good design requires human judgment and experience, with AI serving as a tool to enhance rather than substitute that expertise.
