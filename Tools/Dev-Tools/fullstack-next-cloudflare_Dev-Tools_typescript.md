# fullstack-next-cloudflare

**`ifindev/fullstack-next-cloudflare`** · ⭐ 1,395 · 🔧 TypeScript

## What is it?
Production-ready full-stack template with Next.js 15, Cloudflare Workers, D1 database, R2 storage, and Better Auth.

## How does it work?
This template uses Next.js 15 for server components and Server Actions to handle data fetching and mutations at the edge. It leverages Cloudflare Workers as the runtime environment, providing ultra-low latency across 300+ locations. D1 serves as a serverless SQL database optimized for edge deployments, while R2 offers highly durable object storage for media and assets. Better Auth provides a self-hostable authentication layer with OAuth providers and session management. CI/CD pipelines automate deployment to Cloudflare Workers, ensuring seamless updates and scaling.

## Why is it important? (Core Value)
For your focus on developer tools and infrastructure, this template delivers a self-hostable full-stack foundation using Cloudflare's edge network—aligning with your interest in open-source projects from major tech companies. It eliminates dependency on traditional databases by integrating D1 (serverless SQL) and R2 (object storage), making it ideal for MVPs or homelab deployments. Better Auth gives you control over authentication without SaaS lock-in, supporting your goal of finding self-hostable alternatives. The CI/CD automation reduces deployment friction, directly aiding your workflow optimization objectives. Additionally, the project's inspiration from the Cloudflare SaaS Stack (powering Supermemory.ai) demonstrates its enterprise-grade design, providing credible, production-ready code you can extend for AI agent tooling or other integrations.

## Key Features & Technologies
- Next.js 15 with Server Components and Server Actions
- Cloudflare Workers edge runtime
- D1 serverless SQL database

## Difference from Others
Unlike generic Next.js templates, this project specifically targets Cloudflare's edge infrastructure, integrating D1 and R2 directly rather than relying on traditional databases like PostgreSQL. It also includes Better Auth out-of-the-box, whereas other templates may require configuring separate auth solutions. The inspiration from the Cloudflare SaaS Stack provides more comprehensive examples and documentation compared to minimal starter kits.
