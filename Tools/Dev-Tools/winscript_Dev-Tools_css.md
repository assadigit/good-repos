# winscript

> **TL;DR:** Open-source Windows script tool for debloat, privacy, performance tweaks & app install.

**`flick9000/winscript`** · ⭐ 2,575 · 🔧 CSS

## What is it?
WinScript is a lightweight and easy to use tool designed to improve and customize your Windows experience. It provides pre-built PowerShell scripts that handle common system modifications out of the box, making it accessible to both advanced users and those who prefer plug-and-play solutions.

The project focuses on four main areas: debloat (removing bloatware), privacy (blocking telemetry and sensitive permissions), performance (optimizing Windows settings), and install-script (bulk installing favorite apps). These scripts collectively address the problem of Windows becoming bloated with unnecessary components, excessive telemetry, and pre-installed applications that consume resources.

## How does it work?
The project leverages PowerShell as its primary execution language to modify the Windows system. It likely includes modules or functions that interact with the Windows Registry, Services, Tasks Scheduler, and various system APIs to perform uninstallations, disable features, block network access for specific apps, and apply performance tweaks.

The architecture appears to be modular, with separate scripts for different categories of changes - debloat, privacy, performance, and install. This modularity allows users to selectively enable or disable script groups, providing flexibility while maintaining a clean, organized codebase.

## Why is it important? (Core Value)
This project is valuable because it provides self-hosted alternatives to commercial bloatware removal tools like O&O ShutUp10 or various registry cleaner utilities. It addresses a real problem: Windows comes with significant telemetry by default and includes many unwanted applications that consume resources, while legitimate privacy-focused users often lack the technical knowledge to safely perform these modifications.

For me specifically, this aligns well with my interests in developer productivity tools and self-hosted software. I could integrate WinScript into my homelab or personal PC setup, potentially combine it with other automation projects in my Obsidian vault under the Tools category, and use it as a reference for learning PowerShell system administration techniques. The open-source nature means I can audit the scripts to ensure they're safe and only perform documented actions.

## Key Features & Technologies
- Uses PowerShell scripts

- Bulk app installation

## Difference from Others
Compared to similar projects like Windows10 Debloater, O&O ShutUp10, or various registry cleaner utilities, WinScript stands out as an open-source, modular collection of scripts rather than a single monolithic tool. Unlike commercial debloaters that often require purchasing licenses or have limited functionality, this provides free, auditable code. It also differs from simple uninstaller tools by including privacy and performance tweaks, making it more comprehensive than basic bloatware removal solutions.
