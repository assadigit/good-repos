# mini-qr

> **TL;DR:** Beautiful QR code generator & scanner with customizable styles, multi-format export, and 30+ languages.

**`lyqht/mini-qr`** · ⭐ 2,254 · 🔧 TypeScript

## What is it?
Mini QR is a Vue 3 + Vite web application that allows you to create beautiful, customizable QR codes and also scan various QR code types. It provides a clean, accessible interface for generating QR codes with adjustable colors, styles, and logo uploads, while supporting multiple export formats including PNG, JPG, SVG, ASCII, and Unicode text.

## How does it work?
The project uses Vue 3 with the Composition API, Vite as its build tool, vue-i18n-next for internationalization, and crowdin for managing translations across 30+ languages. UI components come from shadcn-vue, and accessibility is handled via WCAG A compliant patterns. For scanning, it integrates a QR library (likely quagga or similar) to detect various QR code types. Export functionality renders the generated QR to canvas elements using html2canvas-style manipulation, while the copy-to-clipboard feature uses the Clipboard API.

- Customizable colors & styles

## Difference from Others
Compared to other QR code generators, Mini QR stands out for its combined generation + scanning capability in a single UI, accessibility compliance (WCAG A), and built-in multilingual support through crowdin. Many similar projects are CLI-based or lack scanning functionality entirely. It also offers ASCII/Unicode text export options that most competitors don't provide. The Vue 3 + Vite stack makes it easier to self-host than Node.js-only solutions, and its clean design with shadcn-vue components gives it a modern aesthetic unlike older jQuery-based generators.
