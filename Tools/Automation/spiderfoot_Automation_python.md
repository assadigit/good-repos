# spiderfoot

**`smicallef/spiderfoot`** · ⭐ 19,551 · 🔧 Python

## What is it?
SpiderFoot is an open-source OSINT automation framework that integrates over 100 data sources (WHOIS, DNS, IP, email, Shodan, VirusTotal) to map attack surfaces and gather threat intelligence. It provides a web UI server and REST API for programmatic access, making it suitable for security researchers and penetration testers.

## How does it work?
SpiderFoot is written in Python 3.7+ and uses a modular architecture where each data source (e.g., DNS queries, WHOIS lookups, Shodan searches) is implemented as a separate module or class. Core engine orchestrates requests, processes responses, and aggregates data from multiple sources. It includes an embedded web server for a clean UI but can also be run via CLI. Extensibility is achieved through plugins that allow adding new sources without modifying core code.

## Why is it important? (Core Value)
For your objectives of self-hosting alternatives to SaaS products and automating OSINT workflows, SpiderFoot offers a fully open-source framework you can host on your own infrastructure, reducing reliance on external services. It provides a comprehensive set of data source integrations that can be leveraged by AI agents or MCP servers for threat intelligence gathering. Its modular design makes it easy to extend with custom scripts, aligning with your interest in developer tools and automation. Additionally, its web UI and API enable seamless integration into existing security toolchains.

## Difference from Others
Unlike commercial OSINT platforms like Maltego or Recon-ng, SpiderFoot is entirely open-source and self-hostable, offering full control over data handling. While other tools may focus on specific domains (e.g., network scanning only), SpiderFoot provides a broad suite of integrations across DNS, IP, WHOIS, email, social media, and threat intelligence APIs. Its plugin architecture allows adding new sources without modifying core code, whereas many alternatives require recompiling or using external scripts.
