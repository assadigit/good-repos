## What is it?
WireTapper is a self-hosted wireless OSINT platform that passively detects and maps nearby radio signals from Wi-Fi, Bluetooth, IoT devices, CCTV cameras, and more, providing situational intelligence without active intrusion.

## How does it work?
WireTapper uses passive signal scanning to identify devices across multiple wireless protocols (Wi-Fi, Bluetooth, Zigbee, etc.) and correlates them into a map. It employs privacy-protecting k-Anonymity techniques to extract leaked credentials while minimizing data exposure. The tool likely runs as a server or CLI utility, processing radio frequency data in real-time.
