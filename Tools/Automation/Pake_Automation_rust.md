# Pake

> **TL;DR:** Turn any webpage into a desktop app with one command, supporting macOS, Windows, and Linux.

**`tw93/Pake`** · ⭐ 59,826 · 🔧 Rust

## What is it?
Pake is a lightweight tool that converts any webpage into a standalone desktop application using Rust's Tauri framework. Unlike traditional Electron-based apps, it produces installers that are nearly 20 times smaller, typically under 10M on disk. The project is actively maintained by tw93 and has gained significant traction with over 59k stars.

## How does it work?
Pake leverages Tauri—a Rust-based webview framework—to embed webpages within native desktop windows. It uses the system's built-in webview APIs (WebKit on macOS, EdgeHTML/WebView2 on Windows) rather than bundling Chromium like Electron does, which enables its compact footprint. The installer is a single binary that extracts to a minimal directory structure.

## Why is it important? (Core Value)
This project directly aligns with your interests in self-hosted alternatives and lightweight developer tools. It provides a practical way to create personal desktop apps for any website you use daily—forums, dashboards, documentation—without relying on heavy frameworks or SaaS dependencies. For someone curating a knowledge base of useful GitHub projects, Pake represents an excellent example of how modern Rust ecosystems are replacing Electron-based tooling. Its cross-platform support (macOS, Windows, Linux) means it can be adopted in various environments without vendor lock-in.

## Key Features & Technologies
- Built with Rust Tauri
- Lightweight installer (~10M)
- Cross-platform (macOS/Windows/Linux)
- No-electron architecture
- Supports multiple websites

## Difference from Others
Compared to Electron-based apps, Pake's installers are dramatically smaller and faster. Against similar projects like web2desktop (which converts webpages to native desktop wrappers in various languages), Pake stands out by being actively maintained with a strong community following. Unlike generic webview tools that may require manual setup, Pake provides a streamlined one-command workflow for converting any webpage.
