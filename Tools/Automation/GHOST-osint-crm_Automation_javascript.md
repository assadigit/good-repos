# GHOST-osint-crm

> **TL;DR:** Self-hosted OSINT investigation CRM built for individual researchers using Node.js/React/PostgreSQL.

**`elm1nst3r/GHOST-osint-crm`** · ⭐ 630 · 🔧 JavaScript

## What is it?
GHOST is a full-stack, self-hosted OSINT investigation management system designed as an alternative to spreadsheet-based case tracking. It provides a modern web interface for investigators, researchers, and hobbyists who want structured case management without relying on Excel spreadsheets. The project uses a Node.js backend with React frontend and PostgreSQL database to store investigation data, connections, and intelligence information.

## How does it work?
The application follows a traditional full-stack architecture: a Node.js server handles business logic and API endpoints for case management, while the React frontend provides an interactive UI for investigators to create cases, track people, document connections, and manage intelligence data. PostgreSQL serves as the primary database for persistent storage. The self-hosted nature means users can run their own instance on any infrastructure they control, with no dependency on cloud services or vendor lock-in.

## Why is it important? (Core Value)
GHOST directly aligns with your interest in self-hostable alternatives to SaaS products and developer productivity tools. Its Node.js/React/PostgreSQL stack is compatible with homelab environments, and its CC BY-NC-SA license lets you freely modify it for personal OSINT projects. While not an AI agent, it can serve as a structured data layer for your AI workflows—e.g., feeding investigation records into LLM-driven analysis pipelines or automating case updates via scripts in your Obsidian vault. As a single-maintainer project with no SLA, it fits your hobbyist/research use case and complements your knowledge base by providing a concrete example of open-source OSINT tooling.

## Difference from Others
Unlike spreadsheet-based OSINT tools (e.g., Excel) or commercial OSINT platforms like Maltego, GHOST offers a free, self-hosted full-stack CRM built for individual investigators. It lacks enterprise features and AI integration but provides a modern UI and permissive licensing for hobbyists.
