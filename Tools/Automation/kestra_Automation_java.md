# kestra

> **TL;DR:** Open-source event-driven orchestration platform for data, AI, and infrastructure workflows with scheduling, pipelines, and low-code UI.

**`kestra-io/kestra`** · ⭐ 27,851 · 🔧 Java

## What is it?
Kestra is an open-source orchestration platform for data, AI, and infrastructure workflows. It provides event-driven orchestration and scheduling for mission-critical applications, helping teams run pipelines, ETL, AI agent tasks, and infrastructure automation from one control plane.

It targets teams that need reliable, scalable workflow orchestration across data engineering, AI, and DevOps. The platform supports pipeline-as-code, low-code authoring, and high-availability operations, making it suitable for production environments where workflows must be scheduled, event-triggered, and observable.

## How does it work?
Kestra operates as an event-driven orchestration and scheduling platform. Workflows are defined as pipelines, often as code, and can be triggered by schedules, events, or manual actions. The platform coordinates tasks across data, AI, and infrastructure operations, with a low-code interface and high-availability design for mission-critical workloads.

It is built in Java and positions itself as a unified control plane for pipeline execution, scheduling, and orchestration. This allows teams to model complex workflows without relying solely on ad-hoc scripts or separate tools for data, AI, and infrastructure tasks.

## Why is it important? (Core Value)
For your goal of finding self-hostable alternatives to SaaS products, Kestra offers an open-source orchestration platform that can serve as a central control plane for data pipelines, AI agent workflows, and infrastructure automation. It is especially relevant to your interest in AI/LLM tooling because it explicitly supports AI workflows and AI agents, giving you a way to orchestrate agent tasks alongside data and infrastructure operations.

It also fits your interest in automation, developer productivity, and infrastructure by providing pipeline-as-code, low-code authoring, scheduling, and event-driven triggers. This can help you build repeatable, observable workflows for AI experiments, ETL, and infra ops without depending on a SaaS-only solution.

## Difference from Others
Compared with data-focused orchestrators like Airflow or Prefect, Kestra positions itself as a broader platform for data, AI, and infrastructure workflows, not only data pipelines. It emphasizes event-driven orchestration, scheduling, high availability, and a low-code control plane for mission-critical applications.

Compared with general workflow or durable execution systems, Kestra differentiates by combining pipeline-as-code, AI workflow support, and infrastructure automation in one open-source platform. This makes it attractive for teams that want a unified orchestration layer rather than separate tools for data, AI, and DevOps tasks.
