# PolyUploader

> **TL;DR:** Upload files remotely to multiple hosting services with link protection and CORS management.

**`spel987/PolyUploader`** · ⭐ 353 · 🔧 JavaScript

## What is it?
PolyUploader is a self-hosted utility that enables uploading files directly to various hosting platforms via API calls. It provides a web interface and CLI tool for managing file transfers across different services without manual intervention.

The project supports multiple hosting providers through HTTP API integration and handles cross-origin resource sharing (CORS) policies automatically. Users can configure link protection settings to generate direct download links with expiration control, and it includes telemetry features for tracking upload statistics.

## How does it work?
PolyUploader operates by invoking HTTP APIs of each supported host service using standard fetch/axios-style requests with configurable headers. It dynamically manages CORS headers based on the target host's requirements, ensuring seamless uploads from any origin. The web interface communicates with a backend service that handles file storage and upload logic, while telemetry data is collected and served through a dedicated statistics endpoint.

## Why is it important? (Core Value)
For a software engineer interested in AI agents and automation, PolyUploader offers a self-hosted alternative to SaaS file hosting services, reducing reliance on third-party platforms. Its link protection and telemetry features can be integrated into agent workflows that need to store files across multiple cloud services securely. Additionally, its open-source nature allows customization for homelab environments, aligning with the interest in self-hostable software and developer productivity tools.

## Key Features & Technologies
- Supports multiple file-hosting services
- Link protection with expiration control
- CORS management for cross-origin requests
- Telemetry and statistics dashboard
- Open-source repository with GitHub releases

## Difference from Others
Unlike closed-source services like Mirrored.to or Mirrorace.org, PolyUploader is open-source and self-hostable, giving users full control over link protection settings and CORS policies. It also provides a telemetry dashboard for tracking upload statistics, a feature not present in the compared tools.
