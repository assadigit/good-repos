# dnsChanger-desktop

**`DnsChanger/dnsChanger-desktop`** · ⭐ 1,216 · 🔧 TypeScript

## What is it?
dnsChanger-desktop is an open-source DNS client application designed for Windows, macOS, and Linux operating systems. The project's primary purpose is to provide a secure, user-friendly interface for switching between different public DNS servers (such as Google DNS, Cloudflare, Quad9, etc.) directly from the desktop. By centralizing DNS management in a trusted application, users can improve their privacy, speed, and reliability without relying on ISP-provided DNS settings.

## How does it work?
The application is built using Electron.js, which combines Node.js with Chromium to create native desktop applications. The backend logic is written in TypeScript, providing type safety for the DNS resolution and server selection processes. The user interface leverages React components rendered within the Electron renderer process. When a user selects a DNS provider, the app updates the system's DNS configuration files or uses platform-specific APIs (Windows: SetDnsServerAddresses; macOS: dns-setserver; Linux: resolvectl/NetworkManager) to apply the changes securely.

## Difference from Others
Unlike Cloudflare's official DNS app (which is closed-source and limited to their servers) or relying on OS-level DNS settings, dnsChanger-desktop provides an open-source GUI with multi-provider support. Compared to CLI-only tools like dnscat2 or raw resolvectl commands, this project offers a graphical interface for non-technical users while maintaining full transparency. It also includes antivirus testing badges and release binaries, making it more user-friendly than pure scripting approaches.
