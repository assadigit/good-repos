# invidious

**`iv-org/invidious`** · ⭐ 21,881 · 🔧 Crystal

## What is it?
Invidious is a privacy-focused, self-hosted alternative front-end to YouTube that provides full access to all YouTube features while avoiding Google's proprietary client. It runs as a web application that proxies YouTube API requests through your own server, giving you complete control over data and privacy.

## How does it work?
Invidious uses Rust for high-performance proxying of YouTube API calls, then renders the results through a web interface similar to YouTube's own UI. The architecture consists of a backend service that handles all YouTube API interactions, a frontend that mimics the YouTube experience, and optional database storage for user accounts and settings. It can be deployed on any server or container, making it suitable for self-hosting.

## Why is it important? (Core Value)
This project directly supports your interests in self-hosted software and homelab infrastructure by giving you a complete YouTube alternative you control. As someone focused on privacy and open-source tools, Invidious lets you avoid Google's data collection while still accessing all YouTube content. It's particularly valuable for your objectives around discovering self-hostable alternatives to SaaS products—this is exactly that for YouTube. The AGPLv3 license ensures it remains open and community-driven.

## Key Features & Technologies

## Difference from Others
Unlike official YouTube or Piped, Invidious provides a more complete YouTube experience with all features including comments, playlists, and subscriptions. It also has a mature ecosystem of public instances (instances.invidious.io) and extensive documentation. The project is actively maintained by a large community with many contributors.
