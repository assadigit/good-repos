# WiFiAudioStreaming-Desktop

**`marcomorosi06/WiFiAudioStreaming-Desktop`** · ⭐ 263 · 🔧 Kotlin

## What is it?
Desktop app that streams your PC's internal audio to any device on the local network via a companion Android app.

## How does it work?
The application captures system audio using OS-specific APIs (WASAPI on Windows, PulseAudio on Linux) and encodes it into a stream. It then broadcasts the audio over the local network via UDP/TCP, allowing any device running the companion app to receive and play it. The UI is built with Jetpack Compose, following Material You design principles.

## Why is it important? (Core Value)
This self-hosted solution gives you full control over your audio streaming without relying on proprietary services like AirPlay or Spotify Connect. It works across Windows, Linux, and macOS, making it ideal for homelab setups and custom media servers. For your workflow, it can serve as a building block for automated audio distribution to smart speakers or for testing network streaming protocols.

## Key Features & Technologies
- Kotlin backend
- Jetpack Compose UI
- Wireless audio streaming
- Android companion app
- Server & client modes
- Material You design
- Open-source

## Difference from Others
Unlike AirPlay, Spotify Connect, or Chromecast, this is fully self-hosted and open-source, giving complete control over the stream. It also works across different OSes without requiring specific hardware like Apple TV or Google Chromecast.
