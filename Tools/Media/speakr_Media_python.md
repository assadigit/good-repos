# speakr

> **TL;DR:** Self-hosted AI transcription platform that converts audio to searchable notes.

**`murtaza-nasir/speakr`** · ⭐ 3,505 · 🔧 Python

## What is it?
Speakr is a self-hosted AI transcription and intelligent note-taking platform designed for privacy-conscious individuals and groups. It transforms audio recordings into organized, searchable, and intelligent notes while running entirely on your own infrastructure rather than relying on cloud services.

The platform provides a web-based interface where users can upload or stream audio files, which are then processed by AI models to generate transcriptions. These transcriptions are stored in a local database and made available through a searchable UI that allows users to find specific content within their recordings.

Built under the AGPL v3 license, Speakr emphasizes open-source principles and community contribution. It's packaged with Docker support for easy deployment, making it suitable for homelab environments and self-hosting workflows.

## How does it work?
Speakr operates as a full-stack web application with a backend that processes audio files using deep learning models for speech-to-text conversion. The architecture supports streaming audio uploads, allowing users to transcribe recordings in real-time or batch mode. Transcriptions are persisted to a local database (likely SQLite or PostgreSQL), and the system provides API endpoints for programmatic access.

The frontend is served through a web interface that displays transcripts with search capabilities, enabling users to quickly locate specific content within their audio library. Docker build workflows are configured for containerized deployment, making it straightforward to run the application in isolated environments without requiring complex infrastructure setup.
