# freecut

**`walterlow/freecut`** · ⭐ 1,780 · 🔧 TypeScript

## What is it?
Browser-based multi-track video editor with keyframe animation, AI generation, and export via WebGPU/WebCodecs. Runs entirely in your browser with no uploads or server dependencies. Projects and media stay local while editing, preview, analysis, transcription, AI generation, and export run in the browser through WebGPU, WebCodecs, Web Workers, OPFS, and the File System Access API.

## How does it work?
FreeCut uses React + TypeScript for its UI, Web Workers for CPU-bound tasks, and WebGPU/WebCodecs APIs for GPU-accelerated video processing. Media files and project data are stored locally using OPFS (Origin Private File System) or the File System Access API, keeping everything on disk in a workspace folder you choose. No uploads to servers occur—editing, preview, analysis, transcription, AI generation, and export all run client-side.

## Why is it important? (Core Value)
FreeCut provides a privacy-first video editing workflow that runs entirely locally in your browser, eliminating the need to upload footage to cloud services or install software. For your objectives, this directly supports self-hostable alternatives to SaaS products like DaVinci Resolve or CapCut—you can edit high-quality videos without any server dependencies, keeping all your media and projects on your own hardware. The open-source nature also means you can inspect the codebase, understand exactly how it processes video, and potentially integrate it into your homelab infrastructure for content creation workflows.

## Key Features & Technologies
- Browser-based multi-track editing
- Keyframe animation editor
- Real-time preview
- High-quality export (MP4/WebM)
- WebGPU/WebCodecs for GPU acceleration
- OPFS/File System Access API for local storage
- Open-source

## Difference from Others
Unlike DaVinci Resolve, Adobe Premiere Rush, CapCut, or OpenToonz which require installation and often rely on cloud services, FreeCut runs entirely in the browser with no uploads. The privacy-first approach means your footage never leaves your machine during editing—analysis, transcription, AI generation, and export all happen locally through WebGPU/WebCodecs. While these alternatives provide professional features, they typically require downloading large applications or uploading projects to servers.
