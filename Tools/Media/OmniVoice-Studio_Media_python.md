# OmniVoice-Studio

**`debpalash/OmniVoice-Studio`** · ⭐ 8,006 · 🔧 Python

## What is it?
Open-source ElevenLabs alternative providing local TTS, ASR, zero-shot voice cloning, and cinematic video dubbing on desktop.

## How does it work?
OmniVoice-Studio runs entirely locally without API keys, leveraging open-source models like Coqui TTS for text-to-speech and Whisper variants for speech recognition. The application likely uses a GUI (possibly Electron or native) to orchestrate these models, allowing real-time dictation and dubbing workflows.

For you, this project offers a self-hosted media tool that aligns with your interest in homelab infrastructure and developer productivity.
