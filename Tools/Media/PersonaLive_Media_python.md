## What is it?
AI-driven expressive portrait animation tool for live streaming, generating realistic talking-head videos from static images using diffusion models.

## How does it work?
The project likely leverages face detection and alignment (e.g., MediaPipe or similar) to extract facial landmarks, then applies a diffusion-based video generation pipeline conditioned on audio input for lip-syncing. It may use pre-trained models fine-tuned on portrait datasets, with inference optimized for real-time streaming requirements.
