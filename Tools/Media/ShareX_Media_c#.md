# ShareX

> **TL;DR:** Open-source screen capture and file sharing tool with OCR, GIF recording, and multiple upload destinations.

**`ShareX/ShareX`** · ⭐ 38,627 · 🔧 C#

## What is it?
ShareX is a free, open-source Windows application that lets users capture screenshots or record screen activity with a single keystroke. It supports a wide range of upload destinations including Dropbox, Google Drive, Imgur, and many others, as well as built-in tools for OCR, color picking, and image annotation.

## How does it work?
ShareX is implemented in C# using the Avalonia UI framework, which provides a cross-platform desktop experience while targeting Windows primarily. At runtime, the application registers global hotkeys that trigger capture operations via Windows UIAutomation for screenshots and DirectX for video recording. Captured images are encoded as PNG or GIF (using FFmpeg/libav for animated captures) and stored locally before being uploaded to configured destinations.

## Why is it important? (Core Value)
ShareX solves the problem of quickly capturing and sharing visual content without relying on proprietary SaaS services. Its open-source codebase means you can audit it for security, self-host it in a homelab, or extend it with custom destinations. For a developer interested in productivity tools, it offers a reliable way to generate documentation screenshots, embed OCR-extracted text into notes, and archive GIFs locally.

## Key Features & Technologies
- Screen capture via C#
- GIF recording
- OCR integration
- File upload to multiple destinations (Dropbox, FTP, URL shortener)
- Color picker
- Self-hosted Avalonia UI

## Difference from Others
ShareX differs from Windows' built-in Snipping Tool by offering a far richer set of upload destinations and OCR capabilities. Compared to Greenshot or Lightshot, it is cross-platform (via Avalonia) and open-source, allowing full inspection of the code. While ScreenToGif focuses solely on GIF capture, ShareX provides screenshots, OCR, color picking, and annotation in one package.
