# pigeon-pod

> **TL;DR:** Self-hosted YouTube/Bilibili podcast sync with RSS feeds for any client.

**`aizhimou/pigeon-pod`** · ⭐ 1,150 · 🔧 Java

## What is it?
PigeonPod is an open-source self-hosted application that lets users subscribe to YouTube and Bilibili channels and playlists, generating secure RSS feeds for any podcast client. It supports single-video subscriptions by converting individual videos into auto-generated playlist feeds. The platform offers flexible audio/video output options, allowing users to download content in their preferred quality and format. Additionally, it includes multi-user and role-based access controls for managing multiple accounts with granular permissions.

## How does it work?
The frontend is built with React and Mantine UI, providing a responsive web interface for managing subscriptions and viewing feeds. The backend runs on Spring Boot 3 and handles all core logic, including scraping YouTube/Bilibili APIs, generating RSS feeds, and managing multi-user sessions. Integration with Podsync enables content synchronization, while the self-hosted deployment model allows full control over data and privacy.

## Why is it important? (Core Value)
PigeonPod addresses the need for a fully self-hosted alternative to services like Listenbox, enabling users to manage YouTube and Bilibili subscriptions without relying on cloud SaaS products. Its multi-user support and role-based access controls make it suitable for homelab deployments where multiple accounts must be managed securely. For developers interested in scraping and automation, it provides a concrete example of combining content extraction with RSS feed generation, which can be adapted into custom workflows or integrated with other self-hosted tools.

## Key Features & Technologies
- Uses React
- Spring Boot 3 backend
- Self-hosted deployment
- Integrates with Podsync
- Generates secure RSS feeds
- Mantine UI components
- Multi-user access control

## Difference from Others
Unlike Listenbox, which is a hosted SaaS service for syncing YouTube/Bilibili to podcast apps, PigeonPod offers a self-hosted alternative with full control over data and privacy. Podsync focuses on content synchronization, while PigeonPod adds multi-user management and flexible audio/video output options. The difference lies in the self-hosted nature and additional features like role-based access.
