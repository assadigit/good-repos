# audiocraft

> **TL;DR:** PyTorch library for deep learning audio generation with EnCodec tokenizer and MusicGen model.

**`facebookresearch/audiocraft`** · ⭐ 23,448 · 🔧 Jupyter Notebook

## What is it?
Audiocraft is a PyTorch-based library designed for deep learning research on audio generation. It provides inference and training code for two state-of-the-art AI generative models: AudioGen and MusicGen, both capable of producing high-quality audio outputs. The library features the EnCodec audio compressor/tokenizer, which represents the current best-in-class approach for audio compression and tokenization.

## How does it work?
Audiocraft leverages PyTorch's deep learning framework to train and run generative models for audio synthesis. It incorporates EnCodec as a tokenizer/compressor, enabling efficient representation of audio content. The MusicGen model uses transformer-based architectures conditioned on text and melody, allowing controllable generation. Training involves optimizing these models on large audio datasets, while inference runs the trained models to generate new audio from prompts.

## Why is it important? (Core Value)
Audiocraft fills a significant gap in open-source audio generative AI by providing state-of-the-art, research-grade tools for music and audio synthesis. Its EnCodec tokenizer offers superior compression ratios compared to alternatives, making it valuable for both research and practical deployment. For the user specifically, this project aligns with several interests: it's an open-source library from Facebook Research (a major tech company), it demonstrates PyTorch-based deep learning approaches that could inform or enhance audio-related automation workflows, and it represents a self-hostable alternative to proprietary audio generation services like Suno or Udio.

## Key Features & Technologies
- State-of-the-art EnCodec audio compressor/tokenizer
- MusicGen music generation LM with textual/melodic conditioning
- AudioGen model support
- PyTorch-based deep learning framework
- Inference and training code for AI generative models

## Difference from Others
While librosa, torchaudio, and other audio libraries focus on processing and analysis, Audiocraft specializes in generative audio synthesis. Unlike commercial services (Suno, Udio) that are proprietary and cloud-dependent, Audiocraft is open-source and self-hostable. Compared to other PyTorch audio projects, it uniquely combines EnCodec's advanced tokenization with MusicGen's controllable generation, making it distinct from simpler audio generation demos or research prototypes.
