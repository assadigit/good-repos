# audiobookshelf

**`advplyr/audiobookshelf`** · ⭐ 13,580 · 🔧 JavaScript

## What is it?
Self-hosted audiobook and podcast server with metadata management and streaming.

## How does it work?
Audiobookshelf runs as a self-hosted backend server that fetches metadata from multiple sources, streams audio formats on-the-fly without requiring full downloads, and maintains user progress across devices. It includes a web UI that functions as a Progressive Web App (PWA) for any browser, with optional native Android and iOS clients in beta. The system auto-detects library updates to avoid re-scanning, supports bulk folder uploads, and backs up metadata daily.

## Why is it important? (Core Value)
This project offers a robust self-hosted alternative to proprietary audiobook/podcast services. With 13,580 stars it's clearly popular and well-maintained. For users interested in self-hosted software, homelab infrastructure, and open-source alternatives to SaaS products, this delivers centralized media management with multi-user permissions, device sync, backup automation, and cross-platform clients. It also demonstrates good architectural patterns for metadata handling, streaming, and PWA deployment.

## Key Features & Technologies
- Fully open-source including Android & iOS apps (beta)
- Streams all audio formats on-the-fly
- Multi-user support with custom permissions
- Auto-detects library updates without re-scanning
- Bulk upload via drag-and-drop folders
- Automated daily metadata backups
- Progressive Web App (PWA) support
- Chromecast integration

## Difference from Others
Unlike Calibre which primarily handles ebook conversion, Audiobookshelf focuses on streaming audio formats with on-the-fly playback. Compared to standalone podcast players like Pocket Casts, it combines audiobooks and podcasts in one interface while remaining self-hosted. While media servers like Jellyfin or Plex are general-purpose, Audiobookshelf specializes in audiobook metadata management with features like chapter editors, Audnexus API integration, and ebook support (EPUB, PDF, CBR, CBZ) including sending to Kindle devices.
