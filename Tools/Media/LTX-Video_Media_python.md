# LTX-Video

> **TL;DR:** Open-source video generation model from Lightricks with audio sync and ComfyUI support.

**`Lightricks/LTX-Video`** · ⭐ 10,636 · 🔧 Python

## What is it?
LTX-Video is an open-source repository for a video generation model developed by Lightricks. It provides capabilities for generating videos from images or text, with features like synchronized audio, multiple keyframe support, and integration with ComfyUI for streamlined workflows. The project emphasizes being the latest version (LTX-2) which builds on the original LTX model.

The model is designed to be a foundation model for video generation, incorporating diffusion techniques and DiT architectures. It aims to offer high-quality video synthesis with audio synchronization, making it suitable for content creators and developers looking to build video generation pipelines without relying on proprietary SaaS services.

## How does it work?
The LTX-Video project leverages advanced diffusion models and DiT (Diffusion Transformer) architectures to generate videos from either image or text inputs. It includes a trainer repository (LTX-Video-Trainer) for fine-tuning the model, and integrates with ComfyUI for accessible workflow composition. The model supports multiple keyframe interpolation and synchronized audio generation, indicating it processes both visual and audio latents in a unified framework.
