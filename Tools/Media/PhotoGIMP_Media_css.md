# PhotoGIMP

> **TL;DR:** A patch that makes GIMP's UI look like Photoshop.

**`Diolinux/PhotoGIMP`** · ⭐ 11,973 · 🔧 CSS

## What is it?
PhotoGIMP is a community-driven patch for GIMP that makes its interface resemble Adobe Photoshop, easing the transition for users switching from Photoshop. It includes a reorganized tool layout, custom splash screen, maximized canvas space, and Photoshop-like keyboard shortcuts. The project aims to provide a familiar environment while retaining GIMP's powerful, free editing capabilities.

This patch is maintained by Diolinux and has garnered significant community interest with over 11k stars on GitHub. It is released under the GPL v3 license, ensuring open-source compatibility and transparency. The project serves as a bridge between two major image editing ecosystems, allowing users to leverage GIMP's free tools without sacrificing workflow familiarity.

## How does it work?
PhotoGIMP works by applying configuration patches and UI modifications to GIMP's default interface. It likely uses GIMP's plugin system or custom themes to reposition tools, change the splash screen, and adjust keyboard shortcuts. The project is open-source, allowing users to install it directly on their GIMP installation.

The patch integrates with GIMP's architecture by modifying its toolbar layout files and splash screen resources. It does not alter GIMP's core editing functionality, preserving all original features while enhancing usability for Photoshop users.
