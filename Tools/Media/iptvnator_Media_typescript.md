# iptvnator

> **TL;DR:** Cross-platform IPTV player for m3u/m3u8 playlists with EPG, catch-up, favorites, and PWA/Electron support.

**`4gray/iptvnator`** · ⭐ 6,956 · 🔧 TypeScript

## What is it?
IPTVnator is a cross-platform IPTV player application designed for watching internet-based television streams. Its core purpose is to provide a focused client for personal IPTV services rather than a general-purpose video player.

The project emphasizes playlist-based playback and TV-oriented features such as m3u and m3u8 support, favorites, TV guide/EPG, and TV archive/catch-up. It is positioned as a fair-source application that can be used across desktop and web-style environments.

## How does it work?
IPTVnator operates as a client-side media application for consuming IPTV streams supplied by the user or a provider. It works with playlist formats such as m3u and m3u8, which are common in IPTV and HLS-based streaming workflows.

The project is built around a PWA-style web experience plus Electron packaging for desktop use, allowing it to run across multiple platforms. Features like favorites, TV guide/EPG, and catch-up/archive playback suggest it maintains local state and consumes structured provider data to present a television-like browsing experience rather than just raw video files.

## Why is it important? (Core Value)
For your focus on self-hostable tools and homelab infrastructure, IPTVnator is useful as a local, non-SaaS client for personal IPTV streams. It can complement a home media setup by providing a dedicated interface for playlist-based TV services, EPG browsing, catch-up playback, and favorites without relying on a hosted video platform.

It also has value as a reference implementation for cross-platform media applications using PWA and Electron. While it is not an AI or agent project, it demonstrates practical patterns for building desktop/web clients around streaming playlists, provider data, and stateful UI features such as guides and favorites.

## Key Features & Technologies
- Supports m3u and m3u8 IPTV playlists
- Cross-platform PWA and Electron distribution
- TV guide/EPG support
- TV archive/catch-up playback
- Favorites management
- Xtream Codes-style provider integration

## Difference from Others
Compared with generic media players, IPTVnator is specialized for IPTV workflows. It prioritizes playlist consumption, EPG-style browsing, catch-up/archive access, and favorites in a way that matches how users interact with TV services rather than local video files.

Unlike proprietary or cloud-centric IPTV clients, it is a fair-source, cross-platform application that can be deployed locally as a PWA or Electron app. This makes it more suitable for self-managed setups and personal IPTV stacks where the user controls playlists, provider credentials, and playback environment.
