# Antra

**`anandprtp/Antra`** · ⭐ 1,237 · 🔧 Python

## What is it?
Converts Spotify, Apple Music, Tidal, etc. streams into FLAC/ALAC/AAC/MP3 for local libraries.

## How does it work?
Antra runs as a desktop application on Windows, macOS, and Linux, using streaming service APIs to fetch metadata and download audio files in FLAC, ALAC, AAC, or MP3 formats. It applies proper tagging (artist, album, track) to the downloaded files, making them ready for import into self-hosted media servers like Jellyfin or Navidrome.

## Why is it important? (Core Value)
Antra solves the problem of converting streaming music links into local files for offline listening and self-hosted media servers. It uniquely supports multiple streaming services (Spotify, Apple Music, Tidal, etc.) and outputs in lossless formats (FLAC, ALAC) or compressed (AAC, MP3). For you, it's a self-hostable alternative to SaaS platforms, aligns with homelab infrastructure, and improves developer productivity by enabling curated media libraries.

## Key Features & Technologies
- Supports Spotify, Apple Music, Tidal, Qobuz, Deezer, and more
- Outputs FLAC, ALAC, AAC, or MP3 for lossless or compressed audio
- Integrates with Jellyfin and Navidrome media servers
- Community support via Telegram and Discord
- Desktop app for Windows, macOS, and Linux

## Difference from Others
Unlike MusicBrainz Picard (metadata-focused) or yt-dlp (single-service), Antra is built specifically to convert Spotify, Apple Music, Tidal, and others into tagged local files. It also integrates directly with Jellyfin/Navidrome, making it a complete solution for self-hosted media libraries.
