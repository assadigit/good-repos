# ViniPlay

**`ardoviniandrea/ViniPlay`** · ⭐ 549 · 🔧 JavaScript

## What is it?
A powerful, self-hosted IPTV player built with a Node.js backend that runs inside a Docker container. It parses M3U playlists and integrates EPG data, providing a polished streaming experience comparable to premium services. The server resolves CORS issues by proxying or transcoding streams via FFMPEG, ensuring broad browser compatibility.

The feature-rich frontend offers a responsive UI for browsing channels, managing users, casting to TVs (Chromecast), and watching multiple channels simultaneously. A modern web interface includes a TV guide page, multi-view page, and direct player, making navigation seamless. It also supports user authentication and role-based access for shared installations.

## How does it work?
Runs inside a Docker container with a Node.js backend that resolves CORS and browser compatibility issues by proxying or transcoding streams via FFMPEG. The feature-rich frontend provides a responsive UI for browsing channels, viewing EPG data, managing users, and casting to TVs. The architecture separates server-side stream handling from client-side playback, enabling multi-view and Chromecast support.

## Why is it important? (Core Value)
For a self-hosted enthusiast, ViniPlay offers a privacy‑focused alternative to commercial IPTV services. By deploying it in Docker, you gain full control over your media stack, can store M3U playlists locally, and avoid vendor lock‑in. The Node.js backend and FFMPEG transcoding mean you don't need a powerful GPU; even modest hardware can stream high‑definition content. This aligns with your interest in self‑hostable software and homelab infrastructure.
