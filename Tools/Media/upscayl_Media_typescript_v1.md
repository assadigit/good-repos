# upscayl

> **TL;DR:** Free open-source AI image upscaler for Linux, macOS, and Windows that uses deep learning models to increase image resolution.

**`upscayl/upscayl`** · ⭐ 48,564 · 🔧 TypeScript

## What is it?
Upscayl is a free and open-source AI-powered image upscaling application available on Linux, macOS, and Windows. It allows users to upscale low-resolution images while preserving or even enhancing detail, using advanced deep learning models like ESRGAN (Enhanced Super-Resolution Generative Adversarial Networks). The project has gained significant traction with over 48K stars, making it one of the most popular open-source image upscalers available. It provides a user-friendly Electron-based GUI that makes AI-powered image enhancement accessible to non-technical users.

## How does it work?
Upscayl leverages pre-trained deep learning models (primarily ESRGAN and related super-resolution architectures) to perform image upscaling. The application runs these GPU-accelerated or CPU-compatible models locally on the user's machine, avoiding the need for cloud APIs or subscriptions. It uses Electron as its frontend framework, bundling a native GUI with the underlying AI inference engine (typically based on PyTorch/TensorFlow models). Upscaling factors of 2x, 4x, and higher are supported by applying generative adversarial networks that learn to reconstruct high-frequency details from low-resolution inputs.

## Why is it important? (Core Value)
For someone interested in self-hosted software alternatives to SaaS products, Upscayl is an excellent fit. It directly replaces paid services like Topaz Gigapixel, Adobe Photoshop's Super Resolution, and other commercial upscalers—running entirely offline with no subscription fees or data privacy concerns. The project aligns perfectly with the user's interest in self-hostable alternatives to SaaS products, as it provides full local control over image processing without relying on external APIs. Additionally, its use of advanced AI models (ESRGAN) demonstrates practical application of deep learning for computer vision tasks, which complements interests in AI tooling and development workflows.

## Key Features & Technologies
- Runs ESRGAN and other deep learning super-resolution models locally
- Electron-based cross-platform GUI for Linux, macOS, and Windows
- GPU-accelerated upscaling via CUDA or OpenCL support
- Supports multiple upscaling factors (2x, 4x, and more)
- Batch processing capabilities for multiple images
- Fully offline operation with no cloud dependencies
- Open-source with community-contributed models

## Difference from Others
Unlike commercial alternatives like Topaz Gigapixel or Adobe's Super Resolution (which require paid subscriptions), Upscayl is completely free and open-source. It also differs from online upscaling services (like BigJPG or Waifu2x web tools) by running entirely locally, ensuring complete privacy since images never leave the user's machine. While other open-source projects like Real-ESRGAN exist as command-line tools, Upscayl provides a polished GUI that makes AI upscaling accessible to average users without requiring Python knowledge or manual model configuration.
