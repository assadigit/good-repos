# Local-NotebookLM

**`Goekdeniz-Guelmez/Local-NotebookLM`** · ⭐ 944 · 🔧 Python

## What is it?
Local-NotebookLM is a self-hosted AI tool that converts uploaded PDF documents into engaging audio content like podcasts or summaries using local LLMs and TTS models. It provides PDF text extraction, customizable audio generation with multiple styles and lengths, support for various LLM providers (OpenAI, Groq, LMStudio, Ollama, Azure), text-to-speech conversion with voice selection, a flexible pipeline, programmatic API, FastAPI server access, and includes an example podcast. The project runs entirely locally without cloud dependencies.

## How does it work?
The application extracts text from uploaded PDF documents, processes it through a selected local LLM (OpenAI, Groq, LMStudio, Ollama, or Azure) for summarization or content generation, then uses a TTS model (ElevenLabs API, or other local models like Piper or Coqui) to convert the output text into audio. It runs as a FastAPI server providing RESTful endpoints for PDF upload, LLM selection, and audio generation. The pipeline allows flexible configuration of content style, voice, and length via environment variables or config files.

## Why is it important? (Core Value)
This project directly addresses your interest in self-hosted AI tools by offering a local alternative to Google's NotebookLM, giving you full control over data privacy and model choice. It supports multiple LLM providers (OpenAI, Groq, LMStudio, Ollama, Azure), which aligns with your goal of experimenting with different models locally. The TTS integration is unique among self-hosted alternatives, making it a valuable addition to your homelab infrastructure. Additionally, the programmatic API and FastAPI server enable easy integration into your automation workflows, supporting your objectives around developer productivity and workflow orchestration.

## Key Features & Technologies
- PDF text extraction and processing
- Customizable audio generation (podcasts, summaries, interviews)
- Support for multiple LLM providers (OpenAI, Groq, LMStudio, Ollama, Azure)
- Text-to-Speech conversion with voice selection
- Programmatic API for integration
- FastAPI server for web-based access

## Difference from Others
Unlike Google's cloud-based NotebookLM, Local-NotebookLM runs entirely on your machine without any external dependencies. It supports multiple LLM providers (OpenAI, Groq, LMStudio, Ollama, Azure) whereas NotebookLM is limited to Google's own models. The inclusion of TTS with voice selection makes it a more comprehensive media generation tool compared to other local alternatives that only summarize text.
