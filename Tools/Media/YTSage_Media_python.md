# YTSage

**`oop7/YTSage`** · ⭐ 3,824 · 🔧 Python

## What is it?
YTSage is a modern GUI YouTube downloader built on yt-dlp with a clean PySide6 interface. It lets users download videos in any quality, extract audio, fetch subtitles, remove ads via SponsorBlock integration, and preview video metadata before downloading. The application supports cross-platform deployment (Windows, macOS, Linux) under an MIT license.

## How does it work?
The project leverages yt-dlp as its backend engine for robust metadata extraction and stream processing. A PySide6-based GUI provides a responsive interface where users can paste YouTube URLs, select quality/audio/subtitle options, and trigger downloads. SponsorBlock integration fetches ad segment timestamps from the SponsorBlock API, applying filters to skip unwanted content before saving the final video file.

## Why is it important? (Core Value)
As a software engineer interested in self-hostable alternatives to SaaS tools, YTSage offers a privacy-friendly, open-source solution for media consumption workflows. Unlike commercial YouTube downloaders, this MIT-licensed project runs locally without sending data to third parties. Its integration with SponsorBlock and subtitle support makes it valuable for building personal media libraries or homelab setups where you want full control over content acquisition.

## Difference from Others
Compared to older YouTube downloader GUIs (e.g., ytdl-gui, youtube-dl-gui), YTSage uses the actively maintained yt-dlp engine for better compatibility and performance. Its modern PySide6 UI is more polished than Qt-based alternatives, and SponsorBlock integration is a distinctive feature not commonly found in other downloaders.
