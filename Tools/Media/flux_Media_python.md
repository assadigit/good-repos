# flux

**`black-forest-labs/flux`** · ⭐ 25,698 · 🔧 Python

## What is it?
Open-weight image generation library for FLUX.1 models with minimal inference code and TensorRT support.

## How does it work?
The repository provides a minimal inference codebase built on PyTorch to run image generation and editing with the official FLUX.1 open-weight models. Models are loaded from HuggingFace repositories, and inference runs via straightforward forward passes. For NVIDIA GPUs, a separate TensorRT installation path is supported; you must import a PyTorch image from NVIDIA and install the repository with the `[tensorrt]` extra to enable accelerated inference. The repo is designed for local use, with editable installs (`pip install -e .[all]`) allowing easy integration into larger pipelines.

## Why is it important? (Core Value)
Flux provides a self-hostable image generation model suite, enabling offline image creation for AI agents or workflow automation. Its open-weight nature and minimal inference code make it suitable for homelab deployment, aligning with your interest in self-hostable alternatives to SaaS products. The TensorRT support offers performance gains if you're building high-throughput media pipelines.

## Key Features & Technologies
- Uses Python

## Difference from Others
Unlike Stable Diffusion or DALL·E, Flux offers open-weight models with minimal inference code, making it easy to self-host. It also includes TensorRT support for faster generation compared to pure Python implementations.
