# upscayl

> **TL;DR:** Free open-source AI image upscaler built with Electron that runs ESRGAN models locally for lossless image resizing.

**`upscayl/upscayl`** · ⭐ 48,564 · 🔧 TypeScript

## What is it?
Upscayl is a free, open-source desktop application available on Linux, macOS, and Windows that uses artificial intelligence to upscale images without losing quality. It provides an intuitive graphical interface for users to enhance resolution of photos, illustrations, and digital art using neural network-based models like ESRGAN (Enhanced Super-Resolution Generative Adversarial Network).

## How does it work?
The application is built with Electron as its framework, providing a cross-platform desktop GUI. Under the hood, it leverages pre-trained AI/ML models (ESRGAN variants) that are downloaded and run locally on the user's machine. The neural network analyzes low-resolution input images and uses generative adversarial networks to predict high-frequency details, effectively increasing resolution while preserving or even enhancing image quality without traditional interpolation artifacts.

## Why is it important? (Core Value)
For a software engineer interested in self-hosted alternatives to SaaS products, Upscayl is an excellent example of locally-run AI that eliminates the need for cloud-based processing. It directly competes with commercial solutions like Topaz Gigapixel but runs entirely offline using open-source models. The project also serves as a great reference for understanding how ESRGAN and similar GAN-based approaches are applied to practical image processing tasks, making it valuable both as a tool and as a learning resource.

## Key Features & Technologies
- Electron-based cross-platform desktop application
- ESRGAN neural network models for AI upscaling
- Fully offline/local execution - no cloud API required
- Multiple scale factors (2x, 4x, 8x) with different model presets
- Batch processing support for multiple images
- Open-source and free to use without licensing restrictions

## Difference from Others
Unlike commercial upscalers like Topaz Gigapixel or online services that require subscriptions or cloud uploads, Upscayl is completely free, open-source, and runs entirely locally. It doesn't send your images to external servers, making it ideal for privacy-conscious users and those with limited internet access. The Electron framework also makes it accessible across all major desktop platforms without needing separate installations.
