# MyTube

> **TL;DR:** Self-hosted YouTube/Bilibili/Twitch downloader & player with auto-downloads, channel subscriptions, local storage, and Cloudflare Tunnel support.

**`franklioxygen/MyTube`** · ⭐ 1,076 · 🔧 TypeScript

## What is it?
MyTube is a self-hosted downloader and media player supporting YouTube, Bilibili, Twitch, MissAV, and yt-dlp sites. It features channel subscriptions, automatic downloads, local media storage, private RSS feed links for external readers like Feedly, and collections organized via a sleek Material UI interface.

## How does it work?
The project runs in Docker containers with an ExpressJS backend API that handles download requests via yt-dlp, streams video/audio content, and stores metadata in SQLite. The frontend UI is built with Material UI (MUI) and uses TanStack Query for state management. Cloudflare Tunnel is integrated to provide secure remote access without port forwarding, and the build process leverages the franklioxygen/agent-workflows framework for orchestration.
