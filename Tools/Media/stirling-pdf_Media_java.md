# stirling-pdf

**`Stirling-Tools/stirling-pdf`** · ⭐ 86,273 · 🔧 Java

## What is it?
Open-source PDF platform with 50+ editing tools, OCR, compression — runs as desktop app, browser UI, or self-hosted server.

## How does it work?
Stirling PDF is built on a Java backend exposed via REST API. The core engine handles PDF manipulation operations (split, merge, edit pages, add signatures/redactions, convert formats). A Docker image packages the application with its dependencies, making deployment straightforward. Clients — whether the desktop client app or browser UI — connect to the API to issue commands and receive results, keeping all processing local.

## Why is it important? (Core Value)
For your objectives, this is a self-hostable alternative that replaces cloud-dependent PDF tools (Adobe Acrobat Online, Smallpdf, etc.) with complete privacy control. The project's 'everywhere you work' design means it can live in your homelab as Infrastructure, be deployed on a server for team use, or run locally as a personal Desktop app — fitting your interest in self-hosted software and homelab infrastructure. If you want to integrate PDF editing into an automation workflow (e.g., batch processing documents, OCR-ing scanned files), the private API lets you script it without any external services.

## Difference from Others
Compared to Adobe Acrobat (proprietary, cloud-dependent) and PDFtk (limited toolset), Stirling PDF is open-source with 50+ tools including OCR and compression. Unlike online converters that require uploading files to third-party servers, this platform runs entirely locally or on your own infrastructure.
