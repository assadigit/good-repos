# Retrieval-based-Voice-Conversion-WebUI

> **TL;DR:** Self-hosted voice conversion framework that turns any audio into another style using only 10 minutes of reference samples.

**`RVC-Project/Retrieval-based-Voice-Conversion-WebUI`** · ⭐ 36,275 · 🔧 Python

## What is it?
Retrieval-based-Voice-Conversion-WebUI (RVC) is a self-hosted framework built on the VITS architecture that enables high-quality voice conversion with minimal data requirements. It allows users to transform their own voice into any style using as little as 10 minutes of reference audio, making it practical for content creators, developers, and researchers who need flexible audio processing tools without relying on commercial services. The project is actively maintained by the RVC-Project community and supports both real-time inference and batch processing workflows.

## How does it work?
The system leverages VITS (Voice Conversion with Interpolation and Synthesis), a neural vocoder model trained to map source audio features to target voice characteristics. During training, the model learns to replicate the prosody, timbre, and phonetic patterns of a reference voice while preserving the semantic content of the input audio. The retrieval component matches reference audio segments to the target voice during inference, enabling high-quality conversion with minimal data. The framework includes a WebUI for easy interaction and supports both real-time streaming and batch processing, making it suitable for integration into larger pipelines.

## Difference from Others
RVC stands out from other voice conversion tools primarily due to its extremely low data requirement—many alternatives need hours of reference audio, while RVC works with just 10 minutes. This makes it uniquely accessible for homelab and resource-constrained environments. Compared to commercial offerings like ElevenLabs or Resemble AI, it's free and self-hostable but trades off some polish and ease-of-use for flexibility. Other open-source tools often require more data and lack real-time streaming capabilities that RVC provides. The active community also means frequent improvements and shared models are readily available.
