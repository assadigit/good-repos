# remove-ai-watermarks

> **TL;DR:** CLI + Python library to strip visible/invisible AI watermarks (Gemini, SynthID) and provenance metadata from images.

**`wiltodelta/remove-ai-watermarks`** · ⭐ 3,986 · 🔧 Python

## What is it?
This tool removes both visible overlays (like Gemini's sparkle) and invisible AI watermarks (SynthID) from images generated by models such as Stable Diffusion, Flux, and others. It also strips provenance metadata including C2PA Content Credentials and EXIF/XMP 'Made with AI' labels, all via a single CLI command or Python import. The project offers two paths: a self-contained Python library for local use (requires GPU for invisible watermark removal) and a free online service at raiw.cc that handles visible-watermark and metadata removal without any setup or hardware.

## How does it work?
The core workflow uses computer vision techniques like diffusion-model inpainting to regenerate image regions where watermarks sit, effectively erasing them while preserving content. Visible watermarks are detected via simple pixel/overlay analysis, then removed with the same inpainting pipeline. Metadata stripping is done at the file level: C2PA tags are parsed and deleted, EXIF/XMP sidecar files are ignored or removed, and IPTC blocks are cleared. The CLI wraps these operations into a single call, optionally invoking GPU-accelerated models for invisible watermark handling. The online version runs these models on cloud GPUs, so users get results without installing anything.

Unlike generic image editors that only crop or filter visible marks, this tool handles both visible overlays and invisible SynthID watermarks using diffusion-model regeneration. It also includes provenance metadata stripping (C2PA), which many other watermark removers ignore. The online service further differentiates it from purely local tools by offering free, no-setup removal for visible-watermark and metadata cases, while the CLI provides full control for advanced users.
