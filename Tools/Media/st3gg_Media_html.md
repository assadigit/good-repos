# st3gg

**`elder-plinius/st3gg`** · ⭐ 1,642 · 🔧 HTML

## What is it?
st3gg is a comprehensive steganography toolkit for Python that hides arbitrary data in any file type (images, audio, video, text) and provides extraction utilities.

## How does it work?
It implements multiple embedding algorithms (LSB, DCT, quantization) and modality-specific handlers. The library uses Pillow for image processing, NumPy for array manipulation, and SciPy for audio/video handling. Users call encode() to embed payloads into a cover file or decode() to extract hidden data, optionally verifying integrity via hash checks.

## Why is it important? (Core Value)
This toolkit solves the problem of privacy-preserving data transport and content provenance verification without relying on cloud services. It is self-hosted, open-source (AGPL-3.0), and provides 100+ ready-to-use examples, making it a practical alternative to commercial steganography SaaS. For your workflow, it fits under Media tools and can be integrated into pipelines that generate or analyze media assets, supporting your interest in self-hosted alternatives and developer productivity.

## Key Features & Technologies
- PyPI package (stegg)
- AGPL-3.0 license
- Python 3.9+ requirement
- 100+ example files
- Multi-modality support
- Web UI at ste.gg

## Difference from Others
Unlike Stegano or OpenStego, st3gg unifies many algorithms and formats in one package with a web interface for quick testing. Its extensive example set and active community (1642 stars) make it more approachable for newcomers, while still offering advanced options for power users.
