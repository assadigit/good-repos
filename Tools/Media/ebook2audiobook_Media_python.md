# ebook2audiobook

**`DrewThomasson/ebook2audiobook`** · ⭐ 19,468 · 🔧 Python

## What is it?
Converts e-books to narrated audiobooks using advanced TTS engines with voice cloning support for 1158+ languages.

## How does it work?
The project parses e-book formats (EPUB, PDF) to extract text content and metadata, then applies specialized TTS models like XTTS, Piper, or Coqui for audio synthesis. It supports voice cloning features and produces multi-chapter audiobooks with preserved formatting and metadata. The tool is packaged as a self-contained Docker image for easy deployment across platforms.

## Why is it important? (Core Value)
This project directly serves your interests in self-hosted alternatives and media processing tools. As a software engineer looking for automation solutions, E2A provides a complete open-source solution for converting e-books to audiobooks—useful both for accessibility workflows and content preservation/archival. The Docker-based approach aligns with your homelab infrastructure goals, and the extensive language support (1158+) makes it particularly valuable for multilingual projects or research involving non-English sources.

## Key Features & Technologies
- Converts EPUB/PDF to audiobooks
- Voice cloning support
- 1158+ language TTS engines
- Docker-based self-hosting
- Chapter metadata preservation

## Difference from Others
While many TTS tools exist, this project is specifically tailored for e-book-to-audiobook conversion with voice cloning capabilities and massive multi-language support that most alternatives lack. The Docker image approach makes it more portable than typical media processing tools that require manual environment setup.
