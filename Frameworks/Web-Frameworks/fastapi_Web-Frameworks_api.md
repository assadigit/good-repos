# fastapi

> **TL;DR:** Type-hint-driven Python APIs: validation, serialization and docs from one source of truth.

**`fastapi/fastapi`** · ⭐ 86,750 · 🔧 Python

## What is it?
Modern, fast (high-performance) web framework for building APIs with Python 3.8+ based on standard Python type hints.

## How does it work?
ASGI core with dependency injection; type hints become validation, serialization AND OpenAPI docs automatically.

## Why is it important? (Core Value)
The de-facto standard for Python APIs — type hints do the work of three libraries at once.

## Key Features & Technologies
- Automatic OpenAPI docs
- Async-native request handling
- Dependency injection system
- Pydantic-powered validation
