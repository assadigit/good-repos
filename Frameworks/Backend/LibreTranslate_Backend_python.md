# LibreTranslate

**`LibreTranslate/LibreTranslate`** · ⭐ 15,834 · 🔧 Python

## What is it?
Self-hosted open-source machine translation API powered by Argos Translate, no proprietary dependencies.

## How does it work?
LibreTranslate wraps the Argos Translate library, which uses neural machine translation models trained on open-source data. It exposes an HTTP API endpoint that accepts source text and target language codes, returning translated output. The service runs locally or in containers (Docker support is provided), enabling offline-capable translations without internet access to proprietary APIs.

## Why is it important? (Core Value)
For your self-hosted homelab and AI agent workflows, LibreTranslate provides a privacy-preserving translation endpoint you can deploy alongside other tools. Since you're interested in open-source alternatives to SaaS products, this eliminates reliance on Google/Azure APIs. Its Argos Translate foundation means no black-box vendor dependencies—ideal for inspecting or modifying the codebase. You can expose it as an internal API for multilingual agent capabilities, or use it to translate user-facing content within your automation pipelines.

## Key Features & Technologies
- Uses Argos Translate (open-source NMT library)
- Self-hosted HTTP API
- Docker container support
- Offline-capable translations
- Multi-language support
- Open source under Apache-2.0 license
- No proprietary backend dependencies

## Difference from Others
Unlike Google Cloud Translation API or Azure Translator, LibreTranslate doesn't incur per-character costs or rate limits. Compared to raw Argos Translate, it adds a production-ready HTTP server and configuration UI. It also avoids the black-box nature of commercial APIs while maintaining acceptable translation quality for many use cases.
