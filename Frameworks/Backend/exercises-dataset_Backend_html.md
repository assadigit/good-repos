# exercises-dataset

> **TL;DR:** Multilingual fitness exercise dataset (JSON) for building self-hosted app backends.

**`hasaneyldrm/exercises-dataset`** · ⭐ 10,149 · 🔧 HTML

## What is it?
This repository provides a comprehensive JSON dataset of fitness exercises structured for developer use. Each entry contains metadata including name, category, target muscle group, equipment type, and step-by-step instructions. The dataset spans multiple languages—English, Spanish, Italian, Turkish, Russian, and Chinese—with each instruction translated into all six languages.

A key design decision is that exercise media (thumbnail images and animation GIFs) are explicitly excluded from this repository. This avoids the complications of conflicting ownership claims over the media assets; instead, each record includes a `media_id` field referencing the original ExerciseDB source. This makes the dataset easy to distribute and integrate without legal or attribution issues.

## How does it work?
The project is organized as a simple data repository containing structured JSON files (e.g., `data/exercises.json`). The README provides badges indicating the total exercise count, languages covered, and format type. Developers can parse these JSON files directly to build backends for fitness applications, create database schemas, or generate API responses. The absence of media assets keeps the repository lightweight and focused purely on metadata.

This project aligns well with your interests in developer productivity tools and self-hosted alternatives. ## Difference from Others
Other fitness datasets often include media files directly or are single-language. This project stands out by deliberately excluding media (due to ownership disputes) while providing a clean, structured JSON dataset with multilingual instructions—ideal for developers building backends without worrying about image hosting or attribution.
