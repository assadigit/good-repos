# obsidian-pm

> **TL;DR:** Self-hosted Obsidian plugin for project management with Gantt, Kanban, and table views stored as Markdown.

**`StepanKropachev/obsidian-pm`** · ⭐ 443 · 🔧 TypeScript

## What is it?
Obsidian PM is a full-featured project management tool that runs natively inside your Obsidian vault. It provides Table, Gantt, and Kanban views with subtasks, dependencies, time tracking, and custom fields — all stored as plain Markdown with YAML frontmatter. No external services or subscriptions; your data stays yours.

The plugin integrates seamlessly with Obsidian's community plugin system, allowing you to manage projects alongside your notes. Data is saved as Markdown files in the vault, making it portable across devices and preserving your data ownership. Time tracking and smart scheduling features help you estimate effort and deadlines directly within your workflow.

## How does it work?
It leverages Obsidian's plugin API to read/write Markdown files, parse YAML frontmatter for metadata, and render views using JavaScript. Table views format tasks as grids; Gantt charts likely use simple HTML/CSS or SVG embedded in the UI; Kanban boards organize tasks into columns. All processing is done locally within Obsidian — no cloud sync or external APIs.

## Why is it important? (Core Value)
This project stands out because it offers a self-hosted alternative to SaaS project management tools like Trello or Asana, integrating directly with Obsidian vaults. For a user focused on self-hostable software and homelab infrastructure, Obsidian PM aligns perfectly — it keeps data private, works offline, and respects your data ownership.

Additionally, it combines project management with note-taking, which is valuable for users who want to organize tasks within their personal knowledge base. This tool specifically helps the user by providing a privacy-first, portable solution that fits into their Obsidian workflow, addressing their interest in self-hosted alternatives to SaaS products and developer productivity tools.

## Difference from Others
While Trello, Asana, and ClickUp are cloud-based project management tools that require internet connectivity and subscriptions, Obsidian PM runs entirely within your Obsidian vault. It stores data as plain Markdown files, making it portable across devices and preserving your data ownership. Unlike Obsidian itself (a knowledge base), Obsidian PM adds dedicated project management views (Kanban, Gantt) without requiring external integrations. This makes it a unique niche tool for users who want to combine task tracking with note-taking in a self-hosted environment.
