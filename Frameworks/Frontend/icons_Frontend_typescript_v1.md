# icons

> **TL;DR:** React TypeScript icon set with five SVG style variants for UI projects.

**`stash-ui/icons`** · ⭐ 19 · 🔧 TypeScript

## What is it?
Stash Icons is a collection of 24x24 SVG icons implemented as React components in TypeScript. It provides a cohesive, design-focused icon library created by the Pingback team for use in front-end applications.

The project organizes the icons into five style variations—Duotone, Light, Regular, Solid, and Editor—each available as separate installable packages under packages/. This makes it easy to adopt only the visual style needed while keeping the icon set consistent across a product.

## How does it work?
The repository is structured as a TypeScript/React icon library with separate packages for each style variant. Icons are authored as SVG assets and exposed through React components, allowing developers to import individual icons or use them within UI code.

Because each style is installed separately, the architecture avoids bundling unwanted variants into an application. The design source is linked in Figma, and the project includes a public website for browsing the icon set.

## Why is it important? (Core Value)
For a developer focused on productivity and self-hosted tooling, this project offers a ready-made React/TypeScript UI asset that can speed up front-end work without adding custom SVG authoring overhead. It is useful when building dashboards, admin panels, or internal tools where consistent iconography matters.

Its modular package layout also aligns with lean development workflows: you can install only the needed style variant and avoid unnecessary dependencies. While it does not directly address AI agents or MCP, it supports the developer-tooling side of the knowledge base by providing a credible, reusable front-end component library.

## Key Features & Technologies
- 24x24 SVG icon set
- React components written in TypeScript
- Five distinct style variations: Duotone, Light, Regular, Solid, and Editor
- Separate installable packages for each style
- Design source available in Figma

## Difference from Others
Compared with common generic icon sets, Stash Icons is a curated design system from the Pingback team rather than a broad utility collection. Its main distinction is the separation of five visual styles into independent packages, which lets developers choose a precise aesthetic without pulling an entire monolithic icon library.

It also emphasizes consistent 24x24 sizing and React/TypeScript integration, making it suitable for modern front-end teams that want design polish with minimal setup.
