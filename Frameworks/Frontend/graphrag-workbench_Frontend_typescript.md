# graphrag-workbench

> **TL;DR:** Interactive 3D visualization of Microsoft GraphRAG knowledge graphs with community detection.

**`ChristopherLyon/graphrag-workbench`** · ⭐ 704 · 🔧 TypeScript

## What is it?
GraphRAG Workbench is a modern, interactive web application built on Next.js and React that enables users to build and visualize knowledge graphs generated by Microsoft's GraphRAG framework. The project transforms uploaded documents into an explorable 3D knowledge graph with advanced AI-powered analysis and querying capabilities.

The application provides immersive visual analytics where users can explore entities, relationships, and communities through interactive navigation. It includes features like community detection with color-coded boundaries, smart node sizing that reflects entity importance, and advanced filtering by entity types, community levels, and relationship weights.

## How does it work?
The workbench is built as a Next.js application using React and TypeScript, providing a modern web framework foundation. For the interactive 3D visualization component, it likely leverages a WebGL-based rendering library such as Three.js to create the immersive graph experience in the browser.

Document processing involves PDF upload with drag-and-drop functionality, automatic text extraction, and batch operations for processing multiple documents simultaneously. The application maintains archive management capabilities allowing users to save and restore different knowledge graph versions, along with progress tracking for indexing operations.

## Difference from Others
Unlike generic graph visualization tools like Neo4j Browser or Gephi, this workbench is specifically built around Microsoft's GraphRAG framework and includes integrated document processing capabilities. The 3D immersive approach contrasts with standard 2D node-link diagrams, offering a more engaging way to explore large knowledge graphs. It also provides archive management features that aren't typically included in graph visualization tools.
