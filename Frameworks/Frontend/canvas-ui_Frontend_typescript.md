# canvas-ui

> **TL;DR:** Open-source framework-agnostic canvas UI library adding WebGL/WebGPU shader, fluid, and 3D effects to real HTML interfaces.

**`DavidHDev/canvas-ui`** · ⭐ 4,606 · 🔧 TypeScript

## What is it?
Canvas UI is an open-source library of creative, framework-agnostic canvas components for adding visual effects to web interfaces. It targets developers who want fluid simulations, shader effects, and 3D scenes layered over normal HTML without replacing the interface with a full WebGL scene.

The project emphasizes real DOM interactivity plus GPU-accelerated visuals, supporting React, Vue, Svelte, and vanilla usage. It can render through WebGL or WebGPU via vgpu, making it suitable for modern frontend stacks that need polished motion, shader-based materials, and interactive 3D elements without a heavy framework lock-in.

## How does it work?
Canvas UI wraps canvas/WebGL rendering around standard HTML components, so effects are drawn over live interactive UI rather than replacing it. Components expose shader-based visuals such as fluid simulations and 3D scenes, while the underlying interface remains normal DOM elements.

The library is framework-agnostic and TypeScript-oriented, providing integrations for React, Vue, Svelte, and vanilla usage. Rendering can use WebGL or WebGPU through vgpu, allowing developers to choose a GPU backend while reusing the same component API.

## Why is it important? (Core Value)
For your development workflow, canvas-ui is a useful open-source frontend library when you need visually rich web UIs for tools, dashboards, agent interfaces, or product pages without relying on paid SaaS design assets. Its framework-agnostic approach means you can drop components into React, Vue, Svelte, or vanilla TypeScript projects and keep full ownership of the code.

It also fits your interest in self-hosted, open-source alternatives: it is a local library you can install and customize rather than an external service. While not an AI/agent tool itself, it can improve the presentation layer of developer tools, agent control panels, or research dashboards where shader effects, fluid animation, or 3D visualization add value.

## Key Features & Technologies
- Open-source TypeScript component library
- Supports React, Vue, Svelte, and vanilla usage
- Runs WebGL effects over live HTML/DOM interfaces
- Provides shader-based visual effects using GLSL
- Includes fluid simulations and 3D scene components
- Offers WebGL or WebGPU rendering via vgpu

## Difference from Others
Compared with raw Three.js or threejs-based component libraries, canvas-ui focuses on higher-level creative UI components that overlay real HTML rather than requiring developers to build full 3D scenes from scratch. Compared with CSS/animation libraries, it uses WebGL/WebGPU and GLSL shaders for effects such as fluid simulations and shader materials.

Its standout value is framework-agnostic component packaging: the same visual components can be used in React, Vue, Svelte, or vanilla code, while preserving interactive DOM behavior underneath.
