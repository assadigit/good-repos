# astryx

**`facebook/astryx`** · ⭐ 5,794 · 🔧 TypeScript

## What is it?
A Meta design system delivering 150+ accessible React components, dark mode theming, and an open-source CLI for building UI.

## How does it work?
Astryx uses React with StyleX for styling, providing typed components that can be composed at any level. The system ships ready-to-ship templates and a CLI for scaffolding projects. Theming works via CSS custom property overrides—no build plugin needed. Internals are fully open; components can be "swizzled" to eject their source into your project so you own the implementation.

Both people and AI assistants build with the same tooling, meaning its APIs and theming are designed to be consumed by agents as well as developers.

## Why is it important? (Core Value)
Astryx is important because it combines scale (13,000+ apps at Meta) with openness (no styling lock-in, exportable internals). It solves the problem of fragmented design systems by providing a cohesive, customizable stack that works with any CSS-in-JS library or plain CSS. The open internals mean you can extend components without fighting an API, and the CLI reduces boilerplate.

For you specifically, Astryx can serve as a starting point for agent UIs in your Obsidian vault—its agent-ready design means components are structured for consumption by AI tools. Its CLI could help you scaffold self-hosted dashboards or homelab interfaces quickly. As an open-source project from Meta, it offers a credible, well-tested alternative to commercial component libraries, aligning with your interest in major-company open-source tools.

## Key Features & Technologies
- Open internals (component swizzling)
- No styling lock-in (supports Tailwind/CSS modules)
- 150+ accessible UI components
- Dark mode & theming
- CLI for scaffolding
- Typed React components
- CSS custom property overrides

## Difference from Others
Astryx differs from Material UI, Chakra UI, and Tailwind UI by exposing internals—components can be ejected so you own their source. It also has no styling lock-in; override with any CSS library via className rather than being bound to its default style engine. The system is built by Meta for scale (13,000+ apps) and explicitly designed for both human and agent consumption, whereas most design systems target only developers.
