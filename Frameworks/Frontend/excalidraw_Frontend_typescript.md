# excalidraw

## What is it?
Excalidraw is an open source virtual whiteboard application that enables users to create hand-drawn style diagrams and illustrations directly in their browser. The project provides a collaborative experience with real-time editing capabilities, allowing multiple users to work on the same canvas simultaneously. It emphasizes end-to-end encryption for privacy and security, ensuring that all drawings and communications remain encrypted between clients.

The application runs entirely client-side using web technologies like HTML5 Canvas for rendering graphics and WebSockets for real-time collaboration. The server acts primarily as a synchronization point for maintaining state consistency across connected users, while the client handles all drawing operations. This architecture allows for low-latency collaboration without requiring heavy server-side processing.
