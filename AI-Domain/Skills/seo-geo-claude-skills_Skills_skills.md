# seo-geo-claude-skills

> **TL;DR:** Signpost repository for SEO/GEO agent skills; install from aaron-marketing-skills bundle

**`aaron-he-zhu/seo-geo-claude-skills`** · ⭐ 62 · 🔧 N/A

## What is it?
This repo is a signpost for SEO/GEO agent skills, directing users to the main skills bundle (aaron-marketing-skills) where 16 active SEO/GEO skills are developed alongside other disciplines. The standalone 20-skill line from v9.9.12 is preserved here unchanged for backward compatibility.

The repository contains a metadata file (plugin.json) listing the 16 skills with their identifiers and descriptions. Installation is handled via the Skills CLI (npx skills add ...) or through Claude Code's marketplace plugin. New installs pull from the umbrella bundle, while existing installations continue to work without updates to this repo.
