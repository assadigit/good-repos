# OmniParser

**`microsoft/OmniParser`** · ⭐ 25,178 · 🔧 Jupyter Notebook

## What is it?
OmniParser is a screen parsing tool designed to convert UI screenshots into structured, easy-to-understand elements, enhancing the ability of GPT-4V to generate actions that can be accurately grounded in the corresponding regions of the interface. It provides both V1 and V2 model versions hosted on Hugging Face, with interactive YOLOv9-E region detection added as a feature for more precise UI element localization. The project includes local logging of trajectory data and is self-hostable under the MIT license, making it suitable for researchers and developers building vision-based GUI agents.

## How does it work?
OmniParser leverages GPT-4V's visual understanding to parse screenshots into structured UI elements. It includes a YOLOv9-E interactive region detector for fine-grained localization of UI components. The model weights are released on Hugging Face (both V1 and V2), allowing users to run inference locally or integrate via the provided demo space. Logging capabilities enable trajectory tracking for debugging and analysis.

## Difference from Others
Compared to other screen parsing tools that rely solely on OCR or simple bounding boxes, OmniParser uses GPT-4V's multimodal reasoning for semantic understanding of UI elements. It also adds YOLOv9-E for region detection, offering higher precision than generic vision models. Unlike general-purpose agent frameworks, OmniParser is specialized for the visual grounding step, making it a complementary skill rather than a full agent runtime.
