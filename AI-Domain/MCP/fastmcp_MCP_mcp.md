# fastmcp

> **TL;DR:** The fastest way to expose Python functions to LLMs via the Model Context Protocol.

**`jlowin/fastmcp`** · ⭐ 6,210 · 🔧 Python

## What is it?
The high-speed Python framework for building Model Context Protocol servers, with a decorator-first API that makes exposing tools to LLMs a one-liner.

## How does it work?
Decorated Python functions are auto-inspected into MCP tool schemas; FastMCP handles the JSON-RPC transport, validation and streaming.

## Why is it important? (Core Value)
MCP is becoming the USB-C of LLM tooling. FastMCP makes your local tools LLM-callable in minutes instead of days.

## Key Features & Technologies
- Decorator-first tool definitions
- Type-safe schemas from signatures
- FastMCP server CLI
- Composable resources & prompts
