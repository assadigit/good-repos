# mcptube

> **TL;DR:** Transforms YouTube videos into a compounding knowledge base with transcripts, vision, and agentic search via MCP.

**`0xchamin/mcptube`** · ⭐ 135 · 🔧 Python

## What is it?
mcptube-vision is a Python-based tool that transforms YouTube videos into a persistent, structured knowledge base by extracting both transcripts and visual frame analysis. It follows the Karpathy LLM Wiki pattern where knowledge compounds with every video added, creating wiki pages with cross-references rather than re-discovering information from scratch on each query.

## How does it work?
The project uses MCP (Model Context Protocol) to serve as a tool for LLMs like Claude and Copilot. When processing videos, it extracts transcripts and performs vision analysis on video frames, then constructs wiki pages with cross-references between related content. For queries, it uses FTS5 (Full-Text Search) combined with semantic chunk search, making the system get smarter as more videos are ingested.

Unlike traditional video knowledge tools that re-discover information from scratch on every query, this project builds a persistent wiki that compounds with each video. Compared to other MCP servers for LLMs, it is specialized for YouTube content with integrated vision analysis rather than generic tool use.
