# Crucix

**`calesthio/Crucix`** · ⭐ 10,469 · 🔧 JavaScript

## What is it?
Personal intelligence terminal monitoring 27 OSINT sources locally with Node.js.

## How does it work?
Uses Node.js and Express to crawl multiple OSINT data feeds, detect changes via rule-based or AI-assisted analysis, and notify users through web dashboard or command-line. Runs entirely on local infrastructure without cloud dependencies.

## Why is it important? (Core Value)
This project directly addresses your interest in self-hosted alternatives to SaaS products by providing a locally-run intelligence terminal that aggregates 27 OSINT sources without relying on external services. As a software engineer focused on AI agents and automation, Crucix offers a practical tool for monitoring real-world data streams while maintaining full control over your infrastructure. Its zero-cloud architecture aligns with homelab principles, making it suitable for integration into your Obsidian vault under self-hosted tools or OSINT utilities.

## Key Features & Technologies
- Monitors 27 OSINT data sources
- Runs on Node.js 22+
- Zero cloud dependency (self-hosted)

- Dashboard UI with world map and globe views
