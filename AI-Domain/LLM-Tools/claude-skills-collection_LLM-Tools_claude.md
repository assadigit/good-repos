# claude-skills-collection

> **TL;DR:** Curated collection of 218 Claude Skills across 13 categories for productivity, coding, research, and automation workflows.

## What is it?
This repository is a curated collection of Claude Skills, which are modular tools that extend Anthropic's Claude model with practical workflows for coding, debugging, planning, writing, research, design, and automation. It aggregates both official skills from Anthropic and community contributions, providing a comprehensive resource for developers who want to leverage Claude's capabilities beyond basic chat interactions.

The collection includes 218 skills organized into 13 categories: Development & Code Tools (72), Marketing & SEO (20), Writing & Research (20), Collaboration & Project Management (18), Utility & Automation (25), Security & Testing (13), Learning & Knowledge (14), Creative & Design (9), Career & Job Search (6), Media & Content (6), Scientific & Research Tools (5), Data & Analysis (5), and Document Skills (5). Each skill represents a self-contained capability that can be invoked to extend Claude's functionality.

## How does it work?
Each skill is a modular function accessible via the Claude API, typically requiring Claude Pro/Max/Team or Enterprise plans with code execution enabled. The repository acts as a catalog and reference—developers browse by category, explore capabilities, and can kickstart their own Skill creation. While individual skills aren't technically described in depth here, they're structured as callable extensions that integrate into existing LLM-based workflows.

There is no custom runtime or framework layer; the repo simply curates and organizes publicly available skills, highlighting popular picks like `grill-me` (pressure-test plans), `tdd` (red/green/refactor), and `diagnosing-bugs` (root-cause loop). Usage notes indicate that Skills are invoked through Anthropic's standard interface rather than requiring special infrastructure.
