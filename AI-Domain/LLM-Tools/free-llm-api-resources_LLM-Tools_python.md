# free-llm-api-resources

> **TL;DR:** Curated list of free LLM inference APIs and trial credit providers for developers.

**`cheahjs/free-llm-api-resources`** · ⭐ 25,351 · 🔧 Python

## What is it?
This project is a curated list of free-tier LLM inference API resources that developers can access without cost. It covers major cloud providers including OpenRouter, Google AI Studio, NVIDIA NIM, Mistral (both La Plateforme and Codestral), Vercel AI Gateway, and several others. The list is organized into two main sections: completely free providers with no usage limits, and providers offering trial credits for new accounts.

## How does it work?
The project is maintained through an automated script at src/pull_available_models.py that generates this README file. The script likely queries provider documentation or API endpoints to gather current information about free tiers, model availability, rate limits, and trial credit amounts. This approach ensures the list stays up-to-date with the rapidly changing landscape of LLM services.
