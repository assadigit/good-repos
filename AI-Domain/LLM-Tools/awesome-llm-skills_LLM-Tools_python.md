# awesome-llm-skills

> **TL;DR:** Curated list of LLM skills and tools for customizing AI workflows on Claude Code, Codex CLI, Gemini CLI, Qwen Code, and OpenCode.

**`Prat011/awesome-llm-skills`** · ⭐ 1,374 · 🔧 Python

## What is it?
Awesome LLM Skills is a curated markdown repository containing skills, resources, and tools for customizing AI agent workflows across multiple platforms. It serves as a comprehensive reference guide rather than an executable tool, organizing recommendations by platform including Claude Code (Anthropic), Codex CLI (OpenAI), Gemini CLI (Google), Qwen Code (Alibaba), OpenCode, and more.

## How does it work?
The project is structured as a markdown-based curated list organized into sections for different LLM platforms. Each platform section contains categorized recommendations for skills and tools that enhance interaction with that specific LLM interface. The repository follows the Awesome list convention with clear contribution guidelines, allowing community members to add new entries while maintaining consistent formatting.

This project directly supports your objectives in AI/LLM tooling and knowledge base curation. Unlike generic tool lists or comprehensive LLM repositories that catalog all available tools indiscriminately, this project focuses specifically on skills and resources for customizing AI agent workflows.
