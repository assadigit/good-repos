# ACE-Step-Studio

> **TL;DR:** Self-hosted AI music generation studio creating full songs with vocals locally on NVIDIA GPUs.

**`timoncool/ACE-Step-Studio`** · ⭐ 227 · 🔧 Python

## What is it?
ACE-Step Studio is a portable, self-hosted AI music generation application built on the ACE-Step 1.5 XL model — an open-source 4B parameter DiT (Diffusion Transformer) architecture designed for music generation. It provides a Gradio-based user interface that allows users to create full songs with vocals, lyrics, covers, remixes, and even generate accompanying music videos entirely offline.

## How does it work?
The project runs the ACE-Step model locally on NVIDIA GPUs requiring 12+ GB of VRAM. It uses a Gradio UI for interactive generation workflows, where users input prompts or song details and receive generated audio output. Installation is handled via batch scripts (install.bat/run.bat) designed for Windows, making deployment straightforward without needing Docker or complex environment setup.

## Difference from Others
Compared to other local AI music tools, ACE-Step Studio is distinctive because it offers a complete end-to-end studio experience rather than just voice cloning (like RVC models) or simple text-to-music snippets. The project includes music video generation capabilities alongside audio, which few similar open-source projects offer. Its one-click install workflow and explicit offline/portable design also differentiate it from many cloud-first alternatives that require subscriptions or internet access.
