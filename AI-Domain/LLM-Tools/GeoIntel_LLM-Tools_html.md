> **TL;DR:** Python tool using Google's Gemini API to locate where photos were taken through AI-powered geo-location analysis.

## What is it?
GeoIntel is a self-contained Python utility that leverages Google's Gemini multimodal model to perform AI-powered geolocation analysis on images. The project provides both a modern web interface and a command-line interface for flexibility in use cases, from quick spot checks to systematic OSINT investigations.

The tool accepts image files or URLs and uses the Gemini API to analyze visual content—likely examining landmarks, signage, environmental features, and contextual clues—to infer the geographic origin of photos. Results are presented interactively through an embedded 3D Google Maps view with detailed explanations generated by the AI model.

The project is implemented as a Python script that wraps Google's Gemini API calls. Images are sent to the multimodal model, which returns structured responses containing location information and supporting details. The CLI mode reads image paths or URLs, optionally accepts context hints and user guesses via flags, and outputs results as JSON to a specified file. This design allows it to be easily integrated into scripts or automated workflows.
