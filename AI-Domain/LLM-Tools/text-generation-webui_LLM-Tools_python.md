# text-generation-webui

**`oobabooga/text-generation-webui`** · ⭐ 47,424 · 🔧 Python

## What is it?
Desktop app for running local LLMs with UI + API, tool-calling, vision & web search.

## How does it work?
text-generation-webui is a portable desktop application that bundles all dependencies needed to run large language models locally. It primarily uses llama.cpp (GGUF format) as its core inference engine, with optional support for ExLlamaV3 and Transformers backends. The app provides both a graphical chat interface and an OpenAI-compatible API endpoint, allowing it to function as a local LLM server. It integrates tool-calling capabilities and supports vision models, making it suitable for agent-like workflows that require reasoning over files, web search, and multimodal inputs.

This project aligns perfectly with your objectives of discovering self-hostable alternatives to SaaS products and finding AI tools that improve development workflow. As a software engineer focused on AI agents and developer tools, you can use text-generation-webui as a private local LLM endpoint for your own agent systems—whether building custom MCP servers or integrating local reasoning into your automation workflows. The API compatibility lets you treat it like any cloud LLM service while keeping everything on your hardware, directly supporting your interest in self-hosted software and open-source alternatives.

## Key Features & Technologies
- OpenAI-compatible API
- GGUF (llama.cpp) model support
- Tool-calling with file/web access
- Vision model support
- Portable builds for macOS/Linux/Windows
- GPU backends (CUDA, Vulkan, ROCm)
- 100% private, no telemetry

## Difference from Others
Compared to Ollama and LM Studio, text-generation-webui distinguishes itself by offering a unified desktop app with both UI and API access bundled together—Ollama is primarily a CLI service requiring separate setup, while LM Studio focuses on chat but lacks the same breadth of tool-calling integrations. It also provides more explicit privacy guarantees than many cloud-based alternatives. The portable nature of the builds makes it easier to deploy across different environments without needing complex container orchestration, which is valuable for someone building personal homelab infrastructure.
