# langextract

> **TL;DR:** Python LLM library for extracting structured information from unstructured text with source grounding and visualization.

**`google/langextract`** · ⭐ 37,117 · 🔧 Python

## What is it?
LangExtract is a Python library designed to extract structured information from unstructured text using large language models. It provides precise source grounding, allowing users to trace extracted information back to specific parts of the original text. The library also includes interactive visualization features that help users understand and verify extraction results.

## How does it work?
LangExtract operates by interfacing with various LLM model providers through a unified Python API. It sends prompts to models (including OpenAI, Google Vertex AI, Ollama, and community providers), processes their responses, and applies grounding techniques to link extracted information to source locations. The library supports both cloud-based models via API keys and local models like those served by Ollama, making it flexible for different deployment scenarios.
