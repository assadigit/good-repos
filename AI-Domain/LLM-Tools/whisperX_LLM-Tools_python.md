# whisperX

**`m-bain/whisperX`** · ⭐ 22,925 · 🔧 Python

## What is it?
Automatic speech recognition with word-level timestamps and speaker diarization using the Whisper model.

## How does it work?
WhisperX processes audio files through the Whisper neural network, extracting text transcriptions while precisely timestamping each word's position in the audio. Simultaneously, it applies speaker diarization algorithms to identify and label different speakers throughout the conversation, outputting both the transcription with timing information and speaker annotations.

## Why is it important? (Core Value)
This project provides an open-source alternative to commercial speech-to-text APIs by combining accurate Whisper-based recognition with built-in diarization capabilities. For your objectives, it offers a self-hostable transcription solution that can be integrated into AI agent workflows or used as a backend for meeting documentation systems. The word-level timestamps enable precise alignment of spoken content with video or other media, while diarization helps attribute speech to specific speakers—both valuable features for building automated transcription pipelines.

## Key Features & Technologies
- Uses Whisper model for speech recognition
- Provides word-level timestamps for each transcribed word
- Includes speaker diarization functionality
- Self-hostable with MIT license
- Supports multiple audio formats

## Difference from Others
Unlike standard Whisper implementations that only provide transcription without timing or speaker information, whisperX integrates diarization directly into the pipeline. It also offers precise word-level timestamps rather than just sentence-level boundaries, making it more suitable for applications requiring fine-grained temporal alignment with video or other media.
