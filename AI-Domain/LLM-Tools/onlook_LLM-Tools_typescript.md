# onlook

> **TL;DR:** AI-powered visual design tool that lets you edit React codebases with natural language or UI interactions.

**`onlook-dev/onlook`** · ⭐ 26,134 · 🔧 TypeScript

## What is it?
Onlook is an open-source AI-first design tool for React and Next.js applications. It enables designers to interact with a codebase visually, using LLMs to understand component structure and apply edits via natural language commands or UI gestures. The tool integrates with Tailwind CSS for styling, Supabase for backend services, and Drizzle ORM for database queries.

Currently in early access, Onlook aims to reduce boilerplate by automating repetitive design tasks. It represents a new approach to AI-native development, where the AI assists not just with code generation but also with visual design workflows, bridging the gap between design tools and code editors.

The project is open-source, which aligns with the goal of providing self-hostable alternatives to proprietary SaaS products. Users can contribute to its development or deploy it locally, making it a valuable addition to a personal knowledge base focused on AI tooling and developer productivity.

## How does it work?
Onlook likely builds a semantic model of the React/Next.js codebase using an LLM. It parses component files to understand hierarchy, props, and styling (Tailwind classes). When a user issues a command—either through text or UI interaction—the system maps this intent to a series of edits (e.g., diff patches or direct file modifications).

The backend uses Supabase for data storage, while Drizzle ORM handles database queries. The frontend is React/TypeScript with Tailwind CSS for styling. The AI component probably runs via an LLM API, though the exact model implementation is not specified in the provided README. Overall, it combines visual editing capabilities with language models to enable a 'design-to-code' workflow.
