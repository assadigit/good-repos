# openwhispr

**`OpenWhispr/openwhispr`** · ⭐ 4,725 · 🔧 JavaScript

## What is it?
OpenWhispr is a privacy-first voice-to-text dictation application that supports local AI models (Nvidia Parakeet/Whisper) and cloud APIs via BYOK. It offers meeting transcription, note-taking, and works across macOS, Windows, and Linux.

## How does it work?
The app runs locally using Whisper or Nvidia's Parakeet for speech recognition, optionally forwarding audio to cloud LLM APIs (OpenAI, Anthropic, Gemini, Groq) when configured with BYOK. It manages model selection, API endpoints, and privacy settings through a unified configuration system, allowing users to switch between local and remote processing without leaving their environment.
