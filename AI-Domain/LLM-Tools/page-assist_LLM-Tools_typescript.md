# page-assist

> **TL;DR:** Open-source browser extension that lets you interact with your local LLM from any webpage.

**`n4ze3m/page-assist`** · ⭐ 8,044 · 🔧 TypeScript

## What is it?
Page Assist is an open-source browser extension that provides a sidebar and web UI interface for connecting to your locally running AI model. It allows you to interact with your model directly from any webpage, creating a seamless integration between web browsing and local AI assistance. The project supports multiple browsers including Chromium-based browsers (Chrome, Brave, Edge) and Firefox.

## How does it work?
The extension communicates with a locally running Ollama instance via API calls, streaming responses back to the chat interface. It likely uses a Chrome extension manifest (v3) with background service worker handling API requests, content scripts injecting the UI into page context, and popup/sidebar UI for the chat interface. Configuration is exposed through a settings panel where users can specify the Ollama endpoint URL, select models, and tune parameters like temperature.

## Difference from Others
Unlike cloud-based AI assistants that require API keys and internet connectivity, Page Assist runs entirely locally using Ollama—no SaaS dependencies. Compared to other browser extensions like ChatGPT plugins or Perplexity AI, it specifically targets local model integration rather than relying on external APIs. The project also stands out for its focus on Chromium extension architecture with a dedicated settings panel, making it more transparent and customizable than proprietary alternatives.
