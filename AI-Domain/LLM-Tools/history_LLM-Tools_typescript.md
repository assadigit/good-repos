# history

> **TL;DR:** Interactive 3D globe that uses AI to research historical context for any location on Earth.

## What is it?
History is a web application that combines an interactive 3D globe interface with AI-powered historical research capabilities. The project was created by someone who spent hours doomscrolling Google Maps, discovering obscure locations like remote Pacific atolls and Arctic settlements with minimal Wikipedia coverage. This experience inspired the creation of a tool that brings deep historical research directly to users' fingertips.

The application provides an immersive exploration experience where users can visually navigate the globe while simultaneously accessing AI-generated historical context for any location. This addresses a real gap: many fascinating places exist without adequate documentation, and traditional encyclopedic sources often lack depth or are simply absent for remote locations.

## How does it work?
The architecture appears to combine multiple technologies: a WebGL-based 3D rendering layer (likely using Three.js or a similar library) to provide the interactive globe interface, with an AI/LLM backend that generates historical context and research summaries. The README mentions building 'AI that researches anywhere on Earth,' indicating integration with large language models for generating contextual information about locations.

The project is self-hostable with open-source licensing, suggesting a typical web stack: a Python or Node.js backend framework handling API requests, processing location data, calling LLMs for historical research, and serving responses to the frontend. The 3D globe layer communicates with this backend to fetch contextual information as users explore different coordinates.
