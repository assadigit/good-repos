# repomix

> **TL;DR:** Packs entire repositories into AI-friendly single files for feeding to LLMs.

**`yamadashy/repomix`** · ⭐ 27,283 · 🔧 TypeScript

## What is it?
Repomix is a tool that consolidates an entire codebase into a single, structured file optimized for consumption by large language models. It intelligently selects relevant files and directories, filters out noise, and formats the content into a readable markdown document that preserves context and relationships between components. This makes it easy to provide comprehensive project context to AI agents or tools without overwhelming them with raw repository structure.

## How does it work?
Repomix is implemented as a Node.js/TypeScript command-line utility that scans the target repository's file tree, applying configurable patterns to determine which files and directories are relevant for AI consumption. It extracts file contents, preserves relative paths and directory structures, and formats them into a single markdown document with clear section headers and metadata. The tool uses standard Node.js fs modules for file system access and leverages libraries like glob or minimatch for pattern matching. It runs entirely locally, making it self-hostable and compatible with any environment that can execute Node.js scripts.
