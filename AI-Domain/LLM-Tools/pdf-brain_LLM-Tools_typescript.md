# pdf-brain

**`joelhooks/pdf-brain`** · ⭐ 317 · 🔧 TypeScript

## What is it?
Local PDF & Markdown knowledge base with semantic search and AI-powered enrichment.

## How does it work?
The project uses pdf-parse to extract content from PDFs, processes markdown files, then sends text through Ollama running llama3.2:3b for embeddings. Results are stored in libSQL with HNSW indexing and cosine similarity retrieval. It also supports hybrid search combining vector similarity with full-text search, and includes an MCP server interface.

## Why is it important? (Core Value)
This project directly aligns with your interests in AI/LLM tooling, self-hosted software, and developer productivity. As a local-first knowledge base, it replaces SaaS alternatives with no API costs—perfect for homelab infrastructure. The built-in AI enrichment (extracting titles, summaries, tags) and SKOS taxonomy support give you structured, organized content without external services. The MCP server capability means you can integrate this into your Obsidian vault workflow as a curated tool in your personal knowledge base.

## Key Features & Technologies
- PDF + Markdown indexing
- Local-first architecture
- AI enrichment via Ollama LLM
- SKOS taxonomy support
- Vector search with HNSW
- Hybrid search capabilities
- MCP server for Claude/Cursor

## Difference from Others
Unlike commercial SaaS knowledge bases (Notion AI, Obsidian plugins) or generic local-first LLM tools, pdf-brain specifically targets PDFs while maintaining a unified workflow with markdown. It also combines MCP server support with hybrid search, which most alternatives lack.
