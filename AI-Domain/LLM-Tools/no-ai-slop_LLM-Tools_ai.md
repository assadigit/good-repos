# no-ai-slop

**`petergyang/no-ai-slop`** · ⭐ 784 · 🔧 N/A

## What is it?
This skill removes 20+ patterns of AI slop from your writing and can also help detect slop. It detects binary contrasts, throat-clearing openers, faux-insight setups, colon reveals, superficial analysis, importance puffery, weasel attribution, fake-strong verbs, synonym cycling, negative listing, dramatic fragmentation, and enforces fundamentals like active voice, concrete numbers, and untangling hard-to-follow sentences.

## How does it work?
The skill is invoked via `/no-ai-slop` in an AI harness such as Claude Code or Codex. It makes the minimum effective edit to remove slop patterns, then checks its own work against eval.md to ensure quality. Installation involves pasting a URL into the AI harness to add it globally.

## Why is it important? (Core Value)
For a software engineer and researcher focused on AI agents, developer tools, and automation, this tool directly supports your interest in AI/LLM tooling and developer productivity. It helps clean up documentation, reports, or any writing you produce, ensuring it doesn't contain AI slop patterns that could detract from credibility. Being open-source, it can be self-hosted if needed, aligning with your interest in self-hostable alternatives.

## Key Features & Technologies
- Detects 20+ AI slop patterns
- Enforces writing fundamentals (active voice, concrete numbers)
- Minimum effective editing
- Self-evaluation via eval.md
- Works with AI harnesses (Claude Code, Codex)

## Difference from Others
Unlike generic text editors or grammar checkers, this skill is specifically focused on removing AI slop patterns rather than general text editing. It enforces fundamentals like active voice and concrete numbers, which many tools don't. Its self-evaluation via eval.md also sets it apart from typical LLM editors or style guides.
