# magic-resume

> **TL;DR:** AI-powered online resume editor built with TanStack Start and Framer Motion, featuring real-time preview, custom themes, PDF export, and auto-save.

**`JOYCEQL/magic-resume`** · ⭐ 8,702 · 🔧 TypeScript

## What is it?
Magic Resume is an open-source web application designed to make creating professional resumes simple and enjoyable. It provides a modern editing interface where users can build their resumes with real-time preview capabilities, ensuring they see exactly how their document will look as they edit it.

The platform supports extensive customization through custom theme support, allowing users to tailor the visual style of their resumes. It includes dark mode for comfortable editing in any environment and offers export to PDF functionality, making it practical for sharing applications. The project is built with Apache 2.0 license, ensuring it's freely available for use and modification.

## How does it work?
Magic Resume is a frontend-first application built on TanStack Start with TypeScript and React. It uses Tiptap for rich text editing capabilities, enabling sophisticated resume content manipulation. State management is handled through Zustand for efficient data handling across the application.

The AI integration leverages DeepSeek and Doubao models to provide intelligent assistance during resume creation—likely offering suggestions, content generation, or formatting help. Local storage preserves user drafts automatically, while responsive design ensures accessibility across devices. The PDF export functionality appears integrated through a dedicated library for document generation.

## Why is it important? (Core Value)
This project addresses the common pain point of creating professional-looking resumes quickly while maintaining control over the final output. ## Difference from Others
Unlike Canva's resume templates or Google Docs' built-in resume guides, Magic Resume offers a dedicated AI-enhanced editing experience with real-time preview and auto-save. Compared to other open-source resume builders, it stands out for its modern frontend stack (TanStack Start + React + Tailwind) and integration of AI models (DeepSeek/Doubao) directly into the editing workflow. The Apache 2.0 license makes it more permissive than many commercial alternatives while providing a self-hostable option.
