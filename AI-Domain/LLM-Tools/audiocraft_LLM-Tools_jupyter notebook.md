# audiocraft

> **TL;DR:** Meta's PyTorch audio generation library featuring EnCodec tokenizer and MusicGen model for text-to-audio synthesis.

**`facebookresearch/audiocraft`** · ⭐ 23,448 · 🔧 Jupyter Notebook

## What is it?
Audiocraft is a PyTorch-based open-source library designed for deep learning research on audio generation. It provides pre-trained and train-from-scratch code for two state-of-the-art generative models: AudioGen for general audio creation and MusicGen for controllable music generation with textual conditioning. The project also includes EnCodec, a high-quality audio compressor/tokenizer that enables efficient representation of audio waveforms.

## How does it work?
The library leverages PyTorch's deep learning ecosystem to train and deploy audio generative models. AudioGen uses a diffusion-based architecture for generating arbitrary audio from noise, while MusicGen combines a latent diffusion model with an encoder-decoder architecture to condition generation on text prompts or melodic inputs. EnCodec operates as a separate tokenizer that compresses audio waveforms into discrete codes, enabling efficient storage and retrieval of audio content.

It also differs from general-purpose audio synthesis libraries by providing specialized generative models conditioned on text prompts, making it a unique tool for creating controllable audio content.
