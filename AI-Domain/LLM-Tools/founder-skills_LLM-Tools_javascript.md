# founder-skills

> **TL;DR:** Collection of Claude Code skills for founders, marketers, and business owners.

**`ognjengt/founder-skills`** · ⭐ 246 · 🔧 JavaScript

## What is it?
founder-skills is a curated repository containing 20+ pre-built Claude Code skills designed specifically for founders, marketers, content creators, and business owners. Rather than prompting from scratch, users can leverage proven marketing, copywriting, and product development capabilities that companies pay millions for. The repository includes skills like sop-creator (Standard Operating Procedures), cro-optimization (conversion rate optimization analysis), viral-hook-creator, lead-magnet-generator, prd-generator (product requirements), and more.

## How does it work?
The project follows a simple skill-pack architecture where each skill is a reusable Claude Code module stored in a skills/ directory. Installation offers two paths: via npx ("npx skills add [repo-url]") for direct command-line access, or manual installation by cloning the repo and copying contents to ~/.claude/skills/ or .claude/skills/. Each skill appears designed as a prompt/template package that Claude Code can load and invoke.
