# openbrief

> **TL;DR:** Desktop app that turns local or URL-based video/audio into transcripts, grounded summaries, and chat notes using Tauri.

**`tantara/openbrief`** · ⭐ 576 · 🔧 TypeScript

## What is it?
OpenBrief is an open-source desktop application for turning videos and audio into clear, listenable briefings. It lets users import local media files or video URLs, extract or generate transcripts, create grounded markdown summaries, and chat with the content. The project is built as a pnpm/Turborepo workspace around a Tauri v2 app and targets macOS, Windows, and Linux.

## How does it work?
OpenBrief uses a Tauri v2 desktop shell to run media import, transcription, summarization, and chat workflows locally. It can download remote media through bundled tooling, extract captions or run on-device speech-to-text, then use language-model context to produce grounded summaries and answer questions about the media. The workspace also supports organizing items into playlists and exporting reusable notes.

## Why is it important? (Core Value)
For a software engineer and researcher focused on self-hosted tools and LLM workflows, OpenBrief offers a privacy-first alternative to cloud video summarizers: it keeps media processing on the desktop, supports local files and URLs, and produces exportable notes that can feed an Obsidian knowledge base. Its AGPL license and Tauri architecture make it inspectable and adaptable for building similar local media-to-knowledge pipelines.

## Key Features & Technologies
- Import local audio/video files or video URLs
- Extract captions or run on-device speech-to-text
- Generate grounded markdown summaries
- Chat with transcript/media context
- Organize content into playlists
- Export reusable notes

## Difference from Others
Unlike cloud-based YouTube summarizers, OpenBrief is a local-first desktop app that emphasizes importing both local media and URLs, on-device transcription, and open-source licensing. Compared with generic note apps or video players, it combines media download, transcription, LLM-grounded summarization, chat, playlist organization, and note export in one Tauri-based workspace.
