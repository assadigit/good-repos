# digital-marketing-pro

**`indranilbanerjee/digital-marketing-pro`** · ⭐ 539 · 🔧 Python

## What is it?
Digital Marketing Pro is an open-source AI marketing plugin designed for agencies and in-house teams managing multiple brands. It provides 158 skills and 24 specialist agents, fully compliant with EU AI Act Article 50. The plugin integrates with Claude Code, Anthropic Cowork, OpenAI Codex, Cursor, GitHub Copilot CLI, Google Antigravity, Hermes Agent, and OpenClaw, enabling consistent marketing workflows across platforms.

## How does it work?
Digital Marketing Pro operates by installing as a plugin across multiple AI agent platforms—Claude Code, Anthropic Cowork, OpenAI Codex, Cursor, Copilot CLI, Google Antigravity, Hermes Agent, and OpenClaw. Each platform exposes its own LLM API, allowing the plugin to route marketing tasks (content creation, SEO analysis, brand positioning) to the appropriate model. Skills are modular functions that can be combined in a 12-Part Strategy Flow, ensuring consistent depth across brands. The plugin maintains team-persistent state via Cowork, enabling collaborative workflows.

## Why is it important? (Core Value)
Digital Marketing Pro solves the problem of inconsistent marketing depth across multiple brands and lack of agency playbooks. By providing a standardized 12-Part Strategy Flow with auditable outputs, it eliminates 'what did the last agency do?' mysteries. For a software engineer focused on AI agents and automation, this plugin offers a self-hostable alternative to SaaS marketing tools, allowing integration into personal workflows. Its EU AI Act Article 50 compliance makes it relevant for developers concerned about regulatory aspects of AI systems. The plugin's modular skills could be adopted as part of an agent framework or MCP server collection, aligning with the user's goal of curating useful tools and frameworks.
