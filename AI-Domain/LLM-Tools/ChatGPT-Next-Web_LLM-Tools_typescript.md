# ChatGPT-Next-Web

> **TL;DR:** Self-hosted chat interface supporting Claude, Gemini, GPT-4, and Ollama models.

**`ChatGPTNextWeb/ChatGPT-Next-Web`** · ⭐ 88,395 · 🔧 TypeScript

## What is it?
NextChat (formerly ChatGPT-Next-Web) is a cross-platform AI assistant web application that provides a lightweight, fast interface for interacting with multiple large language models. It serves as an open-source alternative to commercial chat platforms, allowing users to self-host their own AI companion without vendor lock-in. The project supports web browsers, desktop environments via Tauri, iOS, Android, Linux, and Windows, making it accessible across all major platforms.

## How does it work?
Architecture-wise, NextChat combines Next.js for the responsive web UI with Tauri for generating native desktop applications on Windows, macOS, and Linux. The frontend communicates with multiple AI model APIs through configurable endpoints, allowing users to switch between cloud providers (like OpenAI or Anthropic) and local deployments (via Ollama). The project maintains separate codebases for web, desktop, mobile iOS, and Android platforms while sharing core logic through a modular design. It includes enterprise features like session management, custom branding, and API key handling for self-hosted instances.

## Why is it important? (Core Value)
This project specifically helps the user because it provides a self-hostable alternative to commercial chat interfaces, aligning directly with their interest in homelab infrastructure and avoiding vendor lock-in. As an AI researcher focused on developer tools, they can deploy NextChat on their own server to integrate with their existing LLM stacks (Ollama, local models), giving them full control over data privacy and model selection. The cross-platform nature means it works seamlessly across their development environments—whether on a Linux workstation, macOS laptop, or Windows machine—making it a practical addition to their personal knowledge base of useful tools.

## Key Features & Technologies
- Next.js UI
- Tauri desktop apps
- Multi-LLM support (Claude/Gemini/GPT-4/Ollama)

- PWA support
- Enterprise edition options

## Difference from Others
Compared to the official ChatGPT web interface, NextChat is open-source and self-hostable, giving users full control over their data and model choices. Unlike other chat UIs that only support a single provider (like OpenAI), NextChat integrates with multiple LLM APIs including local models via Ollama, making it more versatile for developers who want to experiment with different models without being tied to one vendor's ecosystem.
