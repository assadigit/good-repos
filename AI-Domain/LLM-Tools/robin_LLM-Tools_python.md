# robin

> **TL;DR:** OSINT tool that uses LLMs to refine queries and filter dark web search results.

**`apurvsinghgautam/robin`** · ⭐ 5,799 · 🔧 Python

## What is it?
Robin is an AI-powered OSINT tool for dark web investigations. It uses large language models to refine search queries, filter results from dark web search engines, and generate investigation summaries. The project features a modular architecture separating search, scrape, and LLM workflows, supports multiple LLM providers (OpenAI, Claude, Gemini, Ollama, etc.), and includes a Streamlit-based web UI for interactive investigations.

## How does it work?
Robin employs a modular design with distinct components for search, scraping, and LLM processing. Users can select from various LLM providers via environment variables or configuration, enabling flexibility across OpenAI-compatible APIs and open-source models. The Streamlit interface allows real-time interaction with the tool, displaying query refinement steps, scraped results, and AI-generated summaries in a single dashboard.

## Why is it important? (Core Value)
Robin demonstrates how large language models can be embedded into specialized OSINT workflows, offering a template for building AI-enhanced investigative tools without relying on proprietary SaaS services. Its modular design and multi-model support showcase best practices for flexible LLM integration, relevant to your interest in self-hostable alternatives and developer tooling. Additionally, the project's open-source nature provides concrete examples of scraping pipelines and AI-driven data processing that could inform similar automation projects you're exploring.
