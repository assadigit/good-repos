# ollama

> **TL;DR:** Run Llama, Qwen and friends locally with a single command — the backbone of private LLM stacks.

**`ollama/ollama`** · ⭐ 140,232 · 🔧 Go

## What is it?
Get up and running with large language models locally — one command pulls and serves open models (Llama, Qwen, Mistral) with an OpenAI-compatible API.

## How does it work?
A Go server wraps llama.cpp with model management: pull, keep-warm, and REST endpoints for chat and embeddings. GPU acceleration is auto-detected.

## Why is it important? (Core Value)
The backbone of any private, offline LLM stack. GitCurator itself analyzes repos through a local Ollama model.

## Key Features & Technologies
- One-line model pulls
- OpenAI-compatible API
- Multi-GPU support
- Model library management
