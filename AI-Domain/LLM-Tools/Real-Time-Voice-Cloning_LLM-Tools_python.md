# Real-Time-Voice-Cloning

**`CorentinJ/Real-Time-Voice-Cloning`** · ⭐ 59,985 · 🔧 Python

## What is it?
Real-Time-Voice-Cloning is an implementation of SV2TTS (Transfer Learning from Speaker Verification to Multispeaker Text-To-Speech Synthesis) with a real-time vocoder. The project converts speaker verification models into text-to-speech synthesis through three stages: first creating a digital representation of a voice from a few seconds of audio, then using that representation as reference to generate speech given arbitrary text. It was developed for the author's master's thesis and includes a vocoder optimized for real-time use.

## How does it work?
The project is built with PyTorch and TensorFlow, implementing SV2TTS architecture with deep learning models trained on speaker verification data that are then transferred to multispeaker TTS synthesis. It uses transfer learning techniques where the first stage extracts a digital voice representation from audio samples, and subsequent stages use this representation as reference when generating speech from text prompts. The vocoder component is specifically designed to operate in real-time while maintaining quality.
