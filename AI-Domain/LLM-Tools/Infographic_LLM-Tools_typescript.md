# Infographic

> **TL;DR:** AntV's AI-assisted declarative engine for generating and rendering high-quality infographics from text or data.

**`antvis/Infographic`** · ⭐ 6,668 · 🔧 TypeScript

## What is it?
AntV Infographic is a declarative infographic visualization engine from AntV that turns structured information into polished infographics. It focuses on data storytelling and efficient presentation, using a purpose-built syntax to describe layout, content, and visual elements.

Its main features are quick rendering of high-quality infographics, flexible composition through declarative markup, and support for AI/LLM-assisted generation. It targets developers who need reproducible visual assets rather than one-off image outputs.

## How does it work?
The system separates infographic definition from rendering. Users or an LLM produce a declarative infographic specification that describes the narrative structure, sections, data points, and visual components.

The engine then interprets that syntax and renders it into a consistent, high-quality visual layout using AntV's visualization ecosystem and JavaScript/TypeScript tooling.

## Why is it important? (Core Value)
For your workflow as an AI-agent and developer-tools curator, this is useful as a concrete LLM-to-visual-output tool. It can be integrated into agent pipelines that generate reports, dashboards, or social posts: the agent extracts text/data, emits the infographic syntax, and Infographic renders deterministic, brand-consistent visuals.

Because it comes from AntV and ships as an npm package, it is easy to self-host or embed in Node/TypeScript services. It also gives you a reference for how to design LLM tools that produce structured visual artifacts instead of free-form images, which aligns with your interest in agent skills, developer productivity, and open-source alternatives to SaaS design/visualization products.

## Key Features & Technologies
- Declarative infographic syntax
- AI/LLM-assisted generation
- High-quality AntV rendering
- Data storytelling layout engine
- npm package @antv/infographic

## Difference from Others
Compared with chart libraries such as ECharts or D3, Infographic is not a general-purpose charting API; it models infographics as first-class objects with narrative sections and visual composition.

Compared with AI image generators, it produces editable, structured visual output that can be updated from data or regenerated by an LLM without relying on pixel-level image synthesis.
