# free-claude-code

**`Alishahryar1/free-claude-code`** · ⭐ 38,685 · 🔧 Python

## What is it?
Free Claude Code routes Anthropic Messages API traffic from Claude Code CLI/VSCode extensions and OpenAI Responses API traffic from Codex to any provider, enabling use of free/local models while maintaining client protocol stability. Works in terminal, VSCode, and Discord (voice supported). MIT licensed Python tool leveraging uv for dependencies, pytest for testing, ty for type checking, ruff for formatting, and loguru for logging.

## How does it work?
The project acts as a proxy layer between LLM clients (Claude Code CLI/VSCode extensions, Codex) and external API providers. It intercepts messages sent to Anthropic's Messages API or OpenAI's Responses API, forwards them to configured providers (free, paid, or local models), and returns responses back to the client without altering the original protocol. This allows users to switch between different models seamlessly.
