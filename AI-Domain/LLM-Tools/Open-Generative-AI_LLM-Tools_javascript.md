# Open-Generative-AI

> **TL;DR:** Self-hosted platform providing unrestricted access to 200+ AI models for image and video generation without content filters.

**`Anil-matcha/Open-Generative-AI`** · ⭐ 23,847 · 🔧 JavaScript

## What is it?
Open-Generative-AI is a self-hosted platform that aggregates 200+ AI models for generating images and videos, functioning as an unrestricted alternative to commercial platforms like Midjourney, Flux, Kling, Sora, and Veo. It provides a unified interface with no content filters, no subscriptions, and full control over your data through self-hosting.

## How does it work?
The project integrates with MuAPI, a unified API layer that exposes various generative models via JavaScript-based REST endpoints. Users can self-host the repository on any server, configuring API keys and model parameters through environment variables or config files. The platform combines multiple model providers into one interface, allowing you to generate content using whichever models you trust.

## Why is it important? (Core Value)
This project aligns directly with your interest in self-hosted alternatives to SaaS products. As someone curating GitHub projects for an Obsidian vault, Open-Generative-AI would fit well under 'Tools' or 'LLM-Tools'—providing access to multiple generative models without subscriptions. It supports your homelab infrastructure interests by being MIT-licensed and self-hostable, giving you full control over the models you run rather than relying on closed platforms. While not an agent framework, it's a practical tool for workflows requiring visual content generation with uncensored output.

## Key Features & Technologies
- Supports 200+ AI models (Flux, Midjourney, Kling, Sora, Veo)
- No content filters
- Self-hosted with MIT license
- JavaScript-based interface
- Integrates with MuAPI

## Difference from Others
Unlike closed platforms like Midjourney or Flux (which require paid subscriptions), Open-Generative-AI is open-source and self-hosted, eliminating recurring fees. It also aggregates multiple models under one interface, unlike individual API clients.
