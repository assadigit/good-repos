# sokuji

> **TL;DR:** Real-time speech translation using cloud AI models (OpenAI, Google Gemini) or fully offline on-device inference.

**`kizuna-ai-lab/sokuji`** · ⭐ 919 · 🔧 TypeScript

## What is it?
Sokuji is a real-time speech translation tool built by Kizuna AI Lab that bridges language barriers through AI-powered accessibility. It supports both cloud-based inference using providers like OpenAI, Google Gemini, Palabra.ai, Kizuna AI, and Volcengine, as well as fully offline on-device processing for complete privacy. The application is designed to work across Windows, macOS, Linux, Chrome, and Edge platforms, with multi-language support including English, Japanese, and Chinese.

The project emphasizes breaking down language limitations to foster genuine human connections, aligning with the Kizuna AI Lab's mission to use artificial intelligence for accessibility. Its open-source nature under the AGPL-3.0 license ensures transparency while allowing users to self-host or integrate it into existing workflows, making it suitable for developers and researchers interested in AI/LLM tooling and self-hosted alternatives to SaaS translation services.

## How does it work?
Sokuji operates as an Electron-based desktop application with a React frontend built in TypeScript. The core architecture integrates multiple AI models: cloud providers are accessed via their respective APIs (OpenAI, Google Gemini, etc.), while on-device inference leverages local models like Kizuna AI and Palabra.ai for privacy-focused processing. Audio input is processed through speech-to-text models, translated using language models, and then converted to speech output. The app supports both real-time streaming and batch processing modes, allowing users to choose between immediate translation or saving recordings for later review.

## Difference from Others
Compared to Whisper (which focuses on ASR only) or Google Translate API (cloud-only), Sokuji stands out by offering both cloud and on-device processing options with integrated translation via multiple LLM providers. Unlike Microsoft Translator SDK that requires backend integration, Sokuji is a self-contained Electron app that can run entirely offline using local models, providing flexibility for privacy-conscious users. The AGPL-3.0 license also distinguishes it from MIT/Apache-licensed alternatives, ensuring transparency but requiring derivative works to be similarly licensed.
