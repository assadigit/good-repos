# Flowise

> **TL;DR:** Visual drag-and-drop builder for creating LLM-powered AI agents and workflows using LangChain.

**`FlowiseAI/Flowise`** · ⭐ 55,378 · 🔧 TypeScript

## What is it?
Flowise is a low-code/no-code platform that enables users to build, deploy, and share AI agents visually through a drag-and-drop interface. It allows developers to design complex agent workflows by connecting nodes representing different components such as language models, vector stores, RAG pipelines, chatbots, and multi-agent systems. The tool abstracts away the complexity of writing LangChain code while still providing full control over the underlying logic.

## How does it work?
Flowise operates as a React/TypeScript web application that provides a node-based visual editor. Users select pre-built nodes (e.g., LLM chains, vector databases, retrieval methods) and connect them via edges to define data flow between components. The platform compiles these visual workflows into executable LangChain pipelines that run in the browser or can be exported as Node.js applications. It integrates with OpenAI's API for language models and supports various vector stores for RAG (Retrieval-Augmented Generation).

## Difference from Others
Unlike purely code-based LangChain implementations, Flowise provides a visual interface that lowers the barrier to entry for agent development. Compared to other low-code platforms like Dify or LangFlow, it has one of the largest active communities and most comprehensive node libraries. Its key differentiator is the balance between no-code accessibility and full developer control—you can build visually but still export production-ready Node.js code.
