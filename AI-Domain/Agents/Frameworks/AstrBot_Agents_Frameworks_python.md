# AstrBot

> **TL;DR:** Open-source AI agent framework that works across IM platforms (QQ, Discord, Telegram) with LLM integration.

**`AstrBotDevs/AstrBot`** · ⭐ 39,349 · 🔧 Python

## What is it?
AstrBot is an open-source AI agent assistant and development framework that serves as a self-hostable alternative to commercial chatbot platforms. It integrates multiple instant messaging platforms including QQ, Discord, and Telegram, supporting various large language models like OpenAI's GPT, Google Gemini, and Llama. The project emphasizes modularity through plugins and AI features.

## How does it work?
AstrBot operates as a Python-based framework that connects to multiple IM platform APIs (QQ Bot API, Discord Webhooks/Integrations, Telegram Bot API) and routes messages through configurable LLM backends. It uses Docker for containerized deployment, allowing self-hosting without reliance on cloud SaaS services. The architecture supports plugin-based extensibility, enabling users to add custom AI capabilities and integrations.

## Why is it important? (Core Value)
For your objectives around discovering AI agent frameworks and MCP servers, AstrBot is directly relevant as it supports the Model Context Protocol (MCP) and serves as a self-hostable alternative to SaaS chatbot platforms. Its multi-platform integration allows you to build centralized AI agents that operate across QQ, Discord, and Telegram simultaneously—valuable for automation workflows spanning multiple communication channels. The open-source nature enables full transparency into agent logic, making it suitable for learning agent architecture patterns and for private deployment where data sovereignty matters.

## Key Features & Technologies
- Multi-platform IM integration (QQ, Discord, Telegram)
- Multiple LLM backend support (OpenAI, Gemini, Llama)
- Docker-based self-hosting
- Model Context Protocol (MCP) support
- Plugin architecture for extensibility
- Python 3.12+ based development framework

## Difference from Others
Unlike single-platform AI chatbot bots or purely conversational agents, AstrBot distinguishes itself by being a unified multi-platform agent framework that centralizes LLM interactions across different messaging ecosystems. Its emphasis on Docker deployment and plugin modularity makes it more suitable for developers seeking to build custom agent systems rather than just deploy pre-built chatbots.
