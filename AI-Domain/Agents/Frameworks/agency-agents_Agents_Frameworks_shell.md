# agency-agents

**`msitarzewski/agency-agents`** · ⭐ 128,040 · 🔧 Shell

## What is it?
A framework for assembling specialized AI agents across Claude, Cursor, Gemini and more via a native desktop app. The project provides a curated roster of agent personas—from frontend wizards to Reddit community experts—each with defined workflows, personality traits, and proven deliverables.

## How does it work?
agency-agents is structured as a modular collection where each agent is implemented as an independent module or persona definition. The main repository likely contains configuration files, agent specifications, and integration adapters for various LLM platforms. Through the companion app (agency-agents-app), users can browse the full roster and install individual agents into their preferred IDE or coding assistant with a single click—no cloning or scripting required. Updates are managed automatically through the app.

## Why is it important? (Core Value)
This project directly serves your objective of discovering tools that improve development workflow by offering a ready-to-assemble suite of specialized AI agents rather than requiring you to build each one from scratch. As a self-hostable alternative to SaaS products, it aligns with your interest in homelab infrastructure—the native desktop app runs locally across macOS, Linux and Windows without depending on vendor lock-in. For your focus on AI/LLM tooling and automation, it provides an organized way to integrate multiple agent personas into your existing stack (Claude Code, Cursor, Codex, Gemini, Osaurus) while keeping control over the agents themselves.

## Difference from Others
Compared to other AI agent frameworks like LangChain or AutoGen, agency-agents focuses on providing a pre-curated collection of ready-to-use agent personas rather than offering generic orchestration primitives. It also distinguishes itself by packaging agents as installable modules for specific IDEs and coding assistants, which is different from most frameworks that expect you to wire them into your own application code. The companion app's ability to browse the full roster and auto-update without cloning or scripting is a unique convenience layer not commonly found in other agent tooling.
