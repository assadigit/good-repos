# pipecat

**`pipecat-ai/pipecat`** · ⭐ 13,227 · 🔧 Python

## What is it?
Pipecat is an open-source Python framework designed for building real-time voice and multimodal conversational AI agents. It enables developers to create single voice assistants or complex multi-agent systems where specialized agents can hand off tasks, fan out in parallel, and coordinate over a shared bus architecture. The framework orchestrates audio and video streams, AI services, various transport protocols, and conversation pipelines with built-in state management.

## How does it work?
Pipecat uses an async/await-based Python implementation to handle streaming data from voice inputs and AI model outputs. It provides abstractions for managing different transports (WebSocket, HTTP, etc.) and conversation state, allowing agents to maintain context across interactions. The shared bus architecture enables multiple agents to communicate and coordinate their actions locally or distributed across processes and machines.

For a software engineer focused on AI agents and developer tools, Pipecat directly addresses your objective of finding AI agent frameworks you can integrate into projects. ## Difference from Others
Pipecat distinguishes itself from similar projects by focusing specifically on real-time voice interactions rather than just text-based chatbots. The multi-agent system with handoff and parallel execution is more sophisticated than typical agent frameworks that only support single agents or simple chaining. It's built on Python rather than JavaScript/TypeScript, making it accessible to different developer communities, and it provides comprehensive orchestration of conversation state alongside the AI pipeline.
