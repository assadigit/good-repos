# stitch-skills

> **TL;DR:** Library of Agent Skills for Google Stitch MCP server, compatible with coding agents like Codex, Antigravity, Gemini CLI, Claude Code.

**`google-labs-code/stitch-skills`** · ⭐ 7,601 · 🔧 TypeScript

## What is it?
stitch-skills is a collection of agent skills and plugins designed specifically for Google Stitch, following the open Agent Skills standard. This library provides modular, installable capabilities that work seamlessly with various coding agents including Codex, Antigravity, Gemini CLI, Claude Code, and Cursor. Each skill follows the Agent Skills open standard specification, ensuring compatibility across different agent implementations.

## How does it work?
The project implements a plugin-based architecture where each skill is self-contained and can be installed independently via either CLI or UI marketplace interfaces. Sparse checkout support allows faster cloning by limiting the repository to specific paths (e.g., `.agents/plugins`, `plugins/stitch-design`, `plugins/stitch-build`). The skills integrate with the Stitch MCP server through standardized interfaces, enabling them to be discovered and invoked by any coding agent that supports the Agent Skills protocol.
