# autogen

**`microsoft/autogen`** · ⭐ 59,534 · 🔧 Python

## What is it?
AutoGen is a programming framework for building multi-agent AI applications that can operate autonomously or collaborate with humans. The project enables developers to create sophisticated agent systems where multiple AI models work together, each potentially having distinct capabilities and personas.

The framework supports various agent types including assistant agents, user proxies, and custom agents, allowing for flexible orchestration patterns. It provides built-in support for LLM integration and includes mechanisms for managing conversation states, tool usage, and cross-agent message passing.

## How does it work?
AutoGen operates through a modular architecture where agents are defined as classes with specific behaviors and capabilities. The framework provides an agent class that can be instantiated with configurable parameters including the underlying language model, system prompts, and allowed tools.

Agents communicate through a message passing system where responses from one agent can trigger actions in other agents or human operators. The framework handles turn-taking between different participants and manages the flow of conversations across multiple sessions. It includes built-in support for various LLM providers and provides hooks for custom tool integration.

## Why is it important? (Core Value)
AutoGen represents Microsoft's official framework for multi-agent AI applications, making it particularly valuable as a major tech company project that aligns with your interest in open-source projects from major companies. The framework solves the problem of orchestrating multiple AI agents to work together on complex tasks, which is fundamental to modern agent-based systems.

However, you should note that AutoGen is currently in maintenance mode—no new features will be added and it is community-managed going forward. This means you'll want to evaluate whether its functionality meets your needs before committing, and potentially explore the recommended Microsoft Agent Framework as a successor for new projects.

## Key Features & Technologies
- Python-based implementation
- LLM integration with multiple providers
- Multi-agent orchestration patterns
- Human-in-the-loop support via user proxy agents
- Tool usage and function calling
- Cross-agent message passing
- Conversation state management

## Difference from Others
Unlike general-purpose AI frameworks like LangChain, AutoGen is specifically designed around the multi-agent paradigm where multiple distinct agents collaborate. Compared to CrewAI which focuses on role-based agent teams, AutoGen provides more granular control over individual agent behavior and interaction patterns. The framework's strength lies in its Microsoft backing, though the maintenance mode status distinguishes it from actively developed alternatives.
