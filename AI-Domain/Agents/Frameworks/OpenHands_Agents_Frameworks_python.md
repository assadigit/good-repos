# OpenHands

**`OpenHands/OpenHands`** · ⭐ 79,639 · 🔧 Python

## What is it?
Self-hosted control center for AI coding agents (Claude Code, Codex, Gemini) that runs across local, remote, and cloud backends.

## How does it work?
OpenHands provides a unified platform to run multiple AI coding agents in a self-hosted environment. It integrates with various LLM providers (OpenAI, Anthropic, Google) through standard protocols like ACP, allowing users to configure agent backends locally or on remote servers. The CLI interface enables command-line control over agent workflows, while the npm package offers programmatic access for developers building custom integrations.

## Why is it important? (Core Value)
This project directly aligns with your objectives of discovering AI agent frameworks and self-hostable alternatives to SaaS products. OpenHands solves the problem of managing multiple coding agents in a single infrastructure, giving you full control over which models run where (local, cloud, or remote). As someone focused on developer tools and automation, it provides a centralized way to orchestrate agent workflows without relying solely on proprietary platforms like OpenAI's API. The self-hosted nature makes it ideal for building your own knowledge base of usable tools.

## Key Features & Technologies
- Self-hosted backend support
- Integration with multiple LLM providers (OpenAI, Anthropic, Google)
- CLI interface for agent control
- ACP-compatible agent protocol
- npm package for Node.js environments
- CI/CD pipeline for testing agents
- Modular architecture allowing different backends

## Difference from Others
Unlike LangChain or AutoGen which focus on general-purpose LLM orchestration, OpenHands is specifically designed as a self-hosted control center for coding agents. It emphasizes running multiple agent types (Claude Code, Codex, Gemini) in a unified environment rather than building single-agent applications. Compared to other developer tools, it provides deeper integration with agent backends and supports both local and cloud deployment options.
