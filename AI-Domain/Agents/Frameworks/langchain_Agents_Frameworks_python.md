# langchain

**`langchain-ai/langchain`** · ⭐ 141,107 · 🔧 Python

## What is it?
LangChain is an open-source framework for building LLM-powered agents and applications. It provides a modular architecture that lets developers chain together interoperable components like language models, vector stores, memory systems, and third-party integrations (e.g., Gmail API, Slack, databases) to simplify AI application development. The framework future-proofs decisions as the underlying technology evolves, making it easier to swap models or tools without rewriting entire applications.

## How does it work?
LangChain operates through a layered architecture: core abstractions define chains (sequences of calls to LLMs and tools), agents (autonomous decision-making systems), and memory (state management across interactions). It uses Python and TypeScript SDKs with Pydantic for type safety. The platform integrates with major models (OpenAI, Anthropic, Gemini) and supports Retrieval Augmented Generation (RAG) patterns. LangGraph is included for building graph-based agent workflows, enabling more complex multi-step reasoning.

## Difference from Others
LangChain differs from other agent frameworks like LangGraph-only solutions by providing a broader ecosystem of pre-built chains and integrations out of the box. While some alternatives focus on raw orchestration, LangChain emphasizes developer productivity through standardized patterns for memory, retrieval, and tool use. Compared to MCP servers, LangChain is higher-level — it's a framework rather than protocol implementation. Its strength is the balance between abstraction (making development easier) and flexibility (allowing custom components), positioning it as a comprehensive platform rather than a narrow utility.
