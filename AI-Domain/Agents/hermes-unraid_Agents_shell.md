# hermes-unraid

**`julesdg6/hermes-unraid`** · ⭐ 4 · 🔧 Shell

## What is it?
Self-hosted AI agent suite packaged for Unraid, combining Hermes Agent, Dashboard, and WebUI into a single container template.

## How does it work?
The project bundles three separate containers—Hermes Agent, Hermes Dashboard, and Hermes WebUI—into one Docker image. This eliminates the need to manage startup order and shared volumes that are required in the standard three-container setup. Installation is done via a Community App template on Unraid, making it straightforward for users already running Unraid.

## Why is it important? (Core Value)
For someone focused on self-hostable AI agents and homelab infrastructure, this project directly addresses the goal of finding alternatives to SaaS products. It reduces operational complexity by consolidating multiple services into one container, which aligns with the user's interest in automation and workflow orchestration. The Unraid-specific packaging means it can be deployed without additional setup steps, making it a practical addition to a personal knowledge base of developer tools.

## Key Features & Technologies
- Self-hosted
- Unraid-friendly
- Single container image
- Includes Hermes Agent/Dashboard/WebUI

## Difference from Others
Unlike the standard three-container Hermes setup that requires careful startup ordering and shared volume management, this project provides a single template for Unraid. It simplifies installation by packaging everything into one Community App, removing the need to coordinate multiple containers manually.
