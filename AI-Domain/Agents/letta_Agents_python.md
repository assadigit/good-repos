# letta

**`letta-ai/letta`** · ⭐ 23,669 · 🔧 Python

## What is it?
This project provides a platform for stateful AI agents with advanced memory that can learn and self-improve over time.\n\nIt includes a legacy API server (the Letta server) that powers the V1 SDKs, along with a CLI tool that runs agents locally in your terminal or desktop app. The platform supports modular skills and subagents, bundles pre-built components for memory management and continual learning, and is model-agnostic while recommending Anthropic, OpenAI, and zAI models for best performance. Active development has moved to the Letta Agent repo, and self-hosting an API server is now done via the App Server.

## How does it work?
The platform runs an API server that manages agent state, persists memory in a vector database, and exposes SDKs for client applications. Skills are modular components that can be swapped, and subagents handle specialized tasks like memory management. The CLI tool uses Node.js 22.19+ and communicates with the server via REST or similar protocols. It is model-agnostic but integrates with Anthropic, OpenAI, and zAI models for LLM calls.

Letta offers self-hostable AI agent capabilities that align with your interest in self-hosted alternatives to SaaS products and AI agent frameworks. Its SDKs let you integrate agents into applications, supporting automation and workflow orchestration, while modular skills/subagents provide memory management that can be extended. ## Difference from Others
Compared to LangGraph, AutoGen, or CrewAI, Letta focuses on stateful agents with advanced memory and continual learning, bundling pre-built skills/subagents for memory management. It also provides an SDK and CLI for local execution, whereas other frameworks are often provider-specific or lack built-in memory persistence. Additionally, Letta emphasizes self-hosting via the App Server, making it a more complete platform for running agents locally.
