# ai-agents-from-scratch

**`pguso/ai-agents-from-scratch`** · ⭐ 4,378 · 🔧 JavaScript

## What is it?
Educational repository teaching AI agent fundamentals using local LLMs and node-llama-cpp, covering function calling, memory, and ReAct patterns.

## How does it work?
Uses node-llama-cpp for local LLM inference within a JavaScript/TypeScript codebase. Each agent example implements patterns step-by-step—function calling via tool schemas, memory through structured state management, and ReAct reasoning loops with observation-action cycles. The repo provides runnable examples that show exactly how agents are constructed from basic components without framework abstractions.

## Why is it important? (Core Value)
This project directly supports your goal of building a self-hostable knowledge base of AI agent tools. By teaching first-principles agent construction with local LLMs, it provides the foundational understanding needed to design custom agents for your Obsidian vault under AI-Domain or Tools. The focus on node-llama-cpp aligns with your interest in homelab infrastructure and self-hosted alternatives to SaaS APIs. Additionally, the educational approach helps you understand agent architectures before integrating production frameworks into your workflow.

## Difference from Others
Unlike production frameworks like LangChain or AutoGen that abstract away internals and often rely on cloud APIs, this repo teaches you to build agents from first principles using local LLMs and node-llama-cpp. The companion website explicitly maps the learning path from raw LLM calls to full agent architectures, making it ideal for deep understanding before adopting frameworks. It also separates code, explanations, and concepts across GitHub and a dedicated site rather than bundling everything together.
