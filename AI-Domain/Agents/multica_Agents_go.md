# multica

> **TL;DR:** Open-source managed agents platform that assigns tasks to coding agents like teammates.

**`multica-ai/multica`** · ⭐ 39,250 · 🔧 Go

## What is it?
Multica is an open-source managed platform designed to turn coding agents into real teammates. It allows users to assign issues to agents just like assigning work to colleagues, enabling autonomous task execution, code writing, blocker reporting, and status updates without manual prompt copy-pasting. The platform supports self-hosting for full control over agent workflows and integrates with existing development environments.

Key features include task assignment through issue tracking, progress monitoring via status updates, and compound skills that combine multiple agents or tools for complex tasks. It provides a managed environment where agents can collaborate, report progress, and handle blockers independently, reducing the need for human intervention in agent management.

## How does it work?
Multica operates as a managed orchestration layer for coding agents, providing a platform that assigns tasks to agents through issue tracking or API calls. Agents pick up assigned work, write code, report blockers, and update statuses autonomously within the managed environment. The system likely uses a combination of agent runtimes, status tracking mechanisms, and skill composition logic to handle complex workflows. Self-hosting options allow deployment on user infrastructure, with documentation available for setting up the platform locally or on cloud services.
