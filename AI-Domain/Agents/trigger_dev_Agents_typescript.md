# trigger.dev

> **TL;DR:** Fully-managed AI agent and workflow orchestration platform with self-hosting support.

**`triggerdotdev/trigger.dev`** · ⭐ 16,043 · 🔧 TypeScript

## What is it?
trigger.dev is a fully-managed platform for building, deploying, and orchestrating AI agents and automated workflows. It provides an SDK that developers can integrate into their existing applications (particularly Next.js projects) to add background job processing, event-driven automation, and AI agent capabilities without managing infrastructure themselves.

## How does it work?
The platform operates as a serverless workflow engine where you define agents and workflows using TypeScript/JavaScript via the @trigger.dev/sdk. Workflows are triggered by events (webhooks, cron schedules, API calls) and executed on trigger.dev's distributed worker infrastructure. The SDK handles task scheduling, retry logic, rate limiting, and state management. For self-hosting deployments, the platform runs as a containerized service that can be deployed to any environment with compatible orchestration.

## Why is it important? (Core Value)
For this user, trigger.dev directly addresses several key objectives: it is an AI agent framework that integrates MCP (Model Context Protocol) servers into workflows, enabling LLM-powered agents to interact with tools and data sources. The self-hosting option aligns with the interest in self-hosted software alternatives to SaaS products. As a workflow orchestration tool, it provides production-grade scheduling, error handling, and observability for automation tasks—filling gaps that simple automation scripts cannot address at scale.

## Key Features & Technologies
- TypeScript/JavaScript SDK (@trigger.dev/sdk) for agent definition
- Fully-managed serverless execution infrastructure
- Self-hosting option with containerized deployment
- MCP (Model Context Protocol) server support
- Event-driven and cron-based workflow triggers
- Built-in retry logic, rate limiting, and error handling
- Next.js integration for frontend applications

## Difference from Others
Unlike general-purpose automation tools like Zapier or n8n which focus on no-code/low-code integrations, trigger.dev is developer-first with full TypeScript SDK support. Compared to other AI agent frameworks (LangChain, AutoGen), it specializes in production-grade workflow execution rather than just conversation orchestration. The self-hosting option differentiates it from purely SaaS alternatives like CrewAI's managed deployment or LangGraph Cloud.
