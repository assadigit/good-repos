# open_deep_research

> **TL;DR:** Fully configurable open-source deep research agent supporting multiple LLM providers, MCP servers, and search tools for autonomous information gathering.

**`langchain-ai/open_deep_research`** · ⭐ 12,386 · 🔧 Python

## What is it?
Open Deep Research is a configurable, fully open source deep research agent built by the LangChain team. It enables autonomous information gathering across many model providers, search tools, and MCP (Model Context Protocol) servers. The project positions itself as performing on par with many popular deep research agents, with recent benchmark results showing strong performance including support for GPT-5.

## How does it work?
The project is built as a Python package that orchestrates LLM calls through various providers via MCP servers. It integrates search tools to gather information and uses LangChain's agent framework components for workflow management. The architecture appears to be modular, allowing configuration of different model providers and search backends. Recent updates mention a free course on building open deep research with LangGraph, suggesting the core orchestration may use LangGraph nodes for stateful agent workflows.
