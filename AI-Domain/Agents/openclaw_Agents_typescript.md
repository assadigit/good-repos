# openclaw

> **TL;DR:** Personal AI assistant that runs on your own devices across any OS and platform.

**`openclaw/openclaw`** · ⭐ 382,035 · 🔧 TypeScript

## What is it?
OpenClaw is a personal AI assistant platform designed to run on your own devices rather than relying on external SaaS services. It provides an intelligent companion that answers you directly on the messaging channels you already use, whether through Discord, Slack, or other platforms. The system is built around a 'Gateway' control plane that orchestrates the assistant functionality across multiple endpoints.

## How does it work?
The architecture separates concerns between the Gateway (control plane) and the actual assistant (the product). OpenClaw supports running on various operating systems including macOS, iOS, and Android, with the ability to speak and listen for voice interactions. It includes a Canvas component that provides a live visual interface you can control. The system integrates with LLMs for conversational capabilities and handles multimodal content processing.

## Why is it important? (Core Value)
For someone focused on AI agents, developer tools, automation, and self-hostable alternatives to SaaS products like Claude or ChatGPT, OpenClaw directly addresses the desire for privacy and data ownership. It embodies the 'own-your-data' philosophy by running locally on your devices rather than sending conversations to external providers. The cross-platform support across macOS, iOS, and Android means it can integrate into various homelab setups and personal computing environments. As an open-source project under MIT licensing, it provides a credible, transparent foundation for building personalized AI workflows without vendor lock-in.

## Key Features & Technologies
- Runs locally on your own devices (macOS, iOS, Android)
- Gateway control plane architecture
- Canvas live UI rendering component
- Multimodal content processing capabilities
- Cross-platform OS support
- MIT open-source licensing
- Personal AI assistant functionality

## Difference from Others
Unlike commercial AI assistants that require subscriptions and send data to external servers, OpenClaw is designed as a self-hostable personal AI assistant. It differs from generic automation tools by focusing specifically on the AI agent experience rather than task orchestration. Compared to frameworks that help build agents (like LangChain or AutoGen), OpenClaw provides the actual assistant product itself with built-in voice capabilities and Canvas UI rather than just offering agent-building primitives.
