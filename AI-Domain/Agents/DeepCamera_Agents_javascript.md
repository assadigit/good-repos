# DeepCamera

**`SharpAI/DeepCamera`** · ⭐ 2,937 · 🔧 JavaScript

## What is it?
DeepCamera is an open-source AI camera surveillance platform that brings local LLM-powered intelligence to CCTV and security cameras. It provides a catalog of pluggable AI skills including VLM scene analysis, object detection, person re-identification, facial recognition, fall detection, and general CCTV monitoring. All inference runs locally on your hardware for maximum privacy, with models like Qwen, DeepSeek, SmolVLM, LLaVA, and YOLO26 that you can mix and match. The project builds on proven machine learning capabilities while extending them with modern AI techniques.

## How does it work?
The platform uses local model serving—powered by tools like llama-cpp—to run vision-language models entirely on your machine rather than relying on cloud APIs. Its architecture is modular around a skill catalog where each capability (object detection, face recognition, fall detection, etc.) is implemented as an independent module that can be enabled or disabled. Notifications and alerts flow through messaging platforms such as Telegram, Discord, or Slack, and the system integrates with Home Assistant via Raspberry Pi support for smart home automation.

## Why is it important? (Core Value)
This project directly aligns with your interests in self-hosted software, local-LLM tooling, and AI agents. It provides a concrete example of an autonomous agent that can guard your home, watch video streams, remember events, and alert you via Telegram or Discord—all running locally without sending footage to cloud services. As someone focused on discovering tools that improve development workflow and finding self-hostable alternatives to SaaS products, DeepCamera offers both privacy-preserving surveillance and a pluggable skills architecture you could potentially adapt or extend for your own homelab projects.

## Key Features & Technologies
- Local VLM inference (Qwen, DeepSeek, SmolVLM, LLaVA, YOLO26)
- Pluggable AI skills catalog
- Face recognition and person re-identification
- Fall detection and CCTV monitoring
- Telegram/Discord/Slack notification integration
- Home Assistant support on Raspberry Pi
- All inference runs locally for privacy

## Difference from Others
Most AI camera platforms rely on cloud APIs (OpenAI, Google, Anthropic) and lack privacy guarantees—DeepCamera is built specifically to run everything locally. It also offers pluggable AI skills rather than a fixed set of capabilities, giving flexibility that generic surveillance software doesn't provide. Compared to traditional CCTV solutions, it uses modern LLMs and VLMs for scene understanding instead of just conventional computer vision algorithms.
