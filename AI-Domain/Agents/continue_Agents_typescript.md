# continue

> **TL;DR:** Open-source coding agent with CLI, VS Code, and JetBrains IDE integration for AI-assisted development.

**`continuedev/continue`** · ⭐ 34,722 · 🔧 TypeScript

## What is it?
Continue is an open-source coding agent that integrates into multiple development environments including VS Code, JetBrains IDEs, and provides a standalone CLI. It offers AI-assisted code generation, documentation, refactoring, and other developer productivity features across supported programming languages.

The project includes both a VS Code extension (available on the marketplace) and a JetBrains plugin, along with a command-line interface for local usage. The repository is licensed under Apache-2.0, making it suitable for self-hosting in homelab or personal development environments without vendor lock-in.

## How does it work?
Continue operates as an AI-powered coding assistant that connects to various LLM backends (typically OpenAI-compatible endpoints) to provide intelligent code suggestions and completions. The VS Code extension integrates via the Language Server Protocol, while JetBrains plugins use their respective API interfaces. A CLI tool allows direct local execution without IDE dependencies.

The project underwent significant hardening in its final 2.0.0 release, which removed anonymous telemetry and authentication requirements, squashed bugs, and polished the user experience. This architecture prioritizes privacy-first operation and self-hostable deployment, aligning with open-source development tooling principles.

## Difference from Others
Continue stands out from other coding assistants by being fully open-source and self-hostable, unlike proprietary alternatives like GitHub Copilot or Cursor that require cloud APIs. The 2.0.0 release specifically addressed privacy concerns by removing telemetry entirely—a notable difference from most AI coding tools that still collect usage data. Additionally, its availability as a CLI (rather than IDE-only) makes it more flexible for local workflows compared to many agent frameworks that are primarily browser or API-based.
