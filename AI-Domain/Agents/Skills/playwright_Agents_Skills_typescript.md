# playwright

> **TL;DR:** Framework for web testing and automation across Chromium, Firefox, WebKit with a single API. Used by AI agents for navigation, interaction, and scraping.

**`microsoft/playwright`** · ⭐ 93,234 · 🔧 TypeScript

## What is it?
Playwright is a framework for web automation and testing that drives Chromium, Firefox, and WebKit browsers with a single unified API — in your tests, in your scripts, and as a tool for AI agents. It provides Playwright Test for end-to-end testing, Playwright CLI for coding agents (Claude Code, Copilot), and Playwright MCP for AI agents and LLM-driven automation.

## How does it work?
Playwright provides a unified API to control browser contexts across Chromium, Firefox, and WebKit. It uses native browser drivers to interact with pages, supporting multiple languages including JavaScript/TypeScript, Python, Java, C#, and more. Key features include auto-waiting, network interception, tracing, and headless/headed modes. For AI agents, it offers a CLI for coding agents (like Claude Code) and an MCP server for LLM-driven automation.

## Why is it important? (Core Value)
Playwright is a robust, officially maintained framework from Microsoft for web automation that can be self-hosted locally, aligning with your interest in self-hostable software rather than SaaS dependencies. It enables AI agents to navigate, interact, and scrape websites reliably with consistent behavior across browsers. The MCP server specifically addresses your desire for MCP servers you can integrate into your projects, while the CLI version supports coding agents. This gives you a credible, actively maintained tool from a major tech company that covers both automation and scraping needs.

## Difference from Others
Unlike Selenium or Cypress, Playwright is newer and supports Chromium, Firefox, and WebKit natively without requiring driver downloads. It introduces auto-waiting to reduce flaky tests and provides dedicated CLI/MCP interfaces for AI agent integration. Official Microsoft backing ensures long-term maintenance and enterprise-grade reliability.
