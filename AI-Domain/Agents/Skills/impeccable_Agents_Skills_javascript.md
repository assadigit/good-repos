# impeccable

**`pbakaus/impeccable`** · ⭐ 46,061 · 🔧 JavaScript

## What is it?
Design guidance and commands for AI coding agents to produce better frontend code.

## How does it work?
Impeccable installs as a CLI skill invoked via `/impeccable <command> <target>`. Running `/impeccable init` generates PRODUCT.md and DESIGN.md to capture brand voice, colors, components, and anti-references. A shared vocabulary of 23 commands (polish, audit, critique, distill, animate, etc.) lets AI agents request design actions. The CLI and browser extension enforce 46 deterministic detector rules that scan generated code for common SaaS-template tells (Inter fonts, purple-to-blue gradients, nested cards) without calling any LLM or requiring an API key.

## Why is it important? (Core Value)
Impeccable solves the 'generic design' problem that plagues AI coding agents: every model trained on the same SaaS templates produces identical tells—Inter for everything, purple-to-blue gradients, cards nested in cards. By providing deterministic detector rules and a shared vocabulary of commands, it gives AI agents the ability to critique, polish, and iterate on frontend designs without relying on opaque LLM calls. For you, this is exactly the kind of agent skill you're curating: a self-hosted, no-API-key alternative to Anthropic's frontend-design skill, which fits your interest in AI/LLM tooling and developer productivity. The 46 deterministic rules run locally, making it compatible with your homelab/self-hosted ethos, and the CLI design makes it easy to integrate into your Obsidian vault as a reusable note on agent capabilities.

## Key Features & Technologies
- CLI commands (23 design actions)
- Deterministic detector rules
- PRODUCT.md/DESIGN.md setup flow
- Live browser iteration
- No LLM/API key needed for rules
- Browser extension support
