# awesome-ux-skills

**`tommyjepsen/awesome-ux-skills`** · ⭐ 64 · 🔧 Shell

## What is it?
awesome-ux-skills is a curated collection of UX and AI product design skills specifically designed to enhance Claude Code and similar AI coding assistants. The repository contains structured skill modules organized into categories such as UX Research & Strategy, UI Analysis & Improvement, and Design Review capabilities.

The project provides a modular installation system where each skill can be added independently. Skills include research methods (ux-research-methods), persona generation (ux-personas), empathy mapping (empathy-mapping), journey mapping (journey-mapping), storyboard creation (ux-storyboard), the double diamond framework (double-diamond), general design review, accessibility auditing, and UX heuristics review. These skills enable Claude to automatically apply appropriate frameworks when handling design-related questions.

Installation is straightforward via a shell script that clones the repository and runs an install.sh command, with options to force-reinstall or update existing skills.

## How does it work?
The project operates as a collection of discrete skill modules stored in the repository, each representing a specific UX capability. When installed, these skills are made available to Claude Code through its MCP (Model Context Protocol) server mechanism. The install.sh script likely sets up environment variables, registers tools with Claude's context system, and configures the appropriate framework associations.

Each skill module is self-contained and follows the MCP specification for tool registration, allowing Claude to discover and invoke them when relevant prompts are detected. The modular architecture means skills can be added or removed without affecting others, making it easy to customize the UX capabilities available to an AI assistant.
