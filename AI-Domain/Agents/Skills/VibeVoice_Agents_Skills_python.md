# VibeVoice

**`microsoft/VibeVoice`** · ⭐ 49,955 · 🔧 Python

## What is it?
VibeVoice is an open-source frontier voice AI project from Microsoft that provides cutting-edge text-to-speech (TTS) and automatic speech recognition (ASR) capabilities. It leverages state-of-the-art deep learning models and is released as part of the Hugging Face Transformers ecosystem, making it accessible to developers for both research and production use.

Key features include streaming TTS functionality demonstrated in Colab notebooks, an interactive ASR playground built with Gradio, and publicly available models alongside arXiv research reports detailing its architecture and performance.

## How does it work?
VibeVoice is built on the Hugging Face Transformers ecosystem, integrating large language models and audio processing pipelines to deliver high-fidelity speech synthesis and recognition. The project includes a demo Colab notebook showcasing streaming TTS capabilities and a Gradio-based ASR playground for interactive experimentation. Research reports published on arXiv detail both the TTS and ASR components, indicating a comprehensive system that likely follows a transformer-based architecture similar to Whisper for ASR and FlowTTS-style diffusion models for TTS.
