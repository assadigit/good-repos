# marketing-skills

> **TL;DR:** Markdown skill library for AI agents covering SEO, content, pages, ads & marketing strategies. Works with Cursor, Claude Code, OpenClaw.

**`kostja94/marketing-skills`** · ⭐ 704 · 🔧 N/A

## What is it?
Marketing-skills is an open-source markdown library providing over 160 specialized skills for AI agents working on marketing and growth tasks. Each skill is a self-contained markdown document covering specific domains like SEO optimization, content creation, page templates, paid advertising strategies, social media channels, influencer outreach, and various marketing tactics. The project includes 40+ pre-built page types that agents can reference when generating structured outputs.

## How does it work?
The library follows a flat, CLI-based architecture where skills are installed via the `npx skills add` command, which fetches markdown files directly from the repository. Each skill is a self-contained markdown document describing the task, required context, and expected output format. Agents consume these by reading the markdown files in their working directory (e.g., `.cursor/`, `.claude/`) after copying project context templates.

## Why is it important? (Core Value)
This project directly aligns with your interest in AI/LLM tooling by providing a self-hostable, open-source library of marketing and SEO skills for AI agents. It solves the problem of lacking structured skill libraries for agents working on content, SEO, and paid ads—areas critical for growth-marketing workflows. Unlike proprietary SaaS solutions, it offers full control over data and no vendor lock-in.

## Key Features & Technologies
- Markdown skill library
- Works with Cursor/Claude/OpenClaw/Lovable
- CLI install via npx skills add
- Flat layout (no template dependencies)
- Includes project-context.md template
- SEO & marketing coverage

## Difference from Others
Unlike general-purpose agent frameworks like LangChain or AutoGen, this project is domain-specific for marketing and SEO tasks, offering 160+ ready-to-use skills. It also differs from other skill libraries by being explicitly designed for Cursor, Claude Code, OpenClaw, and Lovable—making it a strong choice if you're already using these tools.
