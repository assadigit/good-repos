# claude-obsidian

> **TL;DR:** AI-powered knowledge graph organizes Obsidian notes from any source via Claude Code.

**`AgriciDaniel/claude-obsidian`** · ⭐ 8,749 · 🔧 Python

## What is it?
This project creates a self-organizing AI second brain that integrates directly with Obsidian and Claude Code. By dropping any content—documents, web pages, or files—Claude reads, links, and automatically places it into a unified knowledge graph built from plain Markdown notes. It serves as an open-source alternative to Notion for personal knowledge management (PKM).

The system is built around the Karpathy LLM Wiki pattern, using Agent Skills compatibility to enable powerful AI capabilities within Obsidian. Notes are not just stored but connected through semantic relationships, forming a living, evolving knowledge base that compounding over time.

## How does it work?
At its core, this tool uses Claude Code as an AI agent that processes dropped content through the Obsidian plugin system. When you drop any source material, Claude reads it via the Claude Code integration, then automatically creates or updates Markdown notes in your Obsidian vault. The self-organizing aspect comes from Claude's ability to extract entities, concepts, and relationships from the content, then link them to existing notes based on semantic similarity.

The knowledge graph emerges through Obsidian's linking system—each note can reference others via [[links]], and Claude ensures these connections reflect the actual content relationships. The project leverages the Agent Skills framework for tool invocation, allowing Claude to call Obsidian APIs and manage vault operations. All of this runs locally within your Obsidian environment, requiring only the Claude Code plugin and an Obsidian vault.

## Why is it important? (Core Value)
This project addresses the growing need for self-hosted, AI-driven knowledge management that doesn't rely on SaaS platforms. For someone building a personal knowledge base with Obsidian, it provides an open-source alternative to Notion while adding AI-powered organization—exactly what the user is seeking in self-hosted software and homelab infrastructure.

The value extends beyond note-taking: it turns Obsidian into a dynamic second brain that continuously grows as you drop content. For a researcher or developer interested in AI agents, this offers a practical way to integrate LLM capabilities directly into their workflow—something the user explicitly wants to discover. It also provides a self-hosted solution to data ownership concerns, aligning with their interest in open-source and privacy-focused tools.
