# Anthropic-Cybersecurity-Skills

> **TL;DR:** 817 structured cybersecurity skills for AI agents mapped to MITRE ATT&CK, NIST CSF, and more.

**`mukul975/Anthropic-Cybersecurity-Skills`** · ⭐ 24,758 · 🔧 Python

## What is it?
This project provides the largest open-source library of cybersecurity skills specifically designed for AI agents. It contains 817 structured skills covering 29 security domains, mapped to six major frameworks including MITRE ATT&CK, NIST CSF 2.0, MITRE ATLAS, D3FEND, NIST AI RMF, and MITRE F3 (Fight Fraud). The library adheres to the agentskills.io standard, ensuring compatibility with Claude Code, GitHub Copilot, Codex CLI, Cursor, Gemini CLI, and over 20 other platforms. All skills are released under the Apache 2.0 license for unrestricted use.

The skills are organized into domains such as incident response, penetration testing, cloud security, malware analysis, OSINT, threat intelligence, and more, enabling AI agents to perform complex cybersecurity tasks with standardized, verifiable actions. This structured approach makes it easy to integrate security capabilities into agent workflows while maintaining auditability across multiple frameworks.

## How does it work?
The project stores skills in structured data files (likely JSON/YAML) with metadata linking each skill to its framework mappings and compatible platforms. This design supports both programmatic access via APIs or CLI tools and manual browsing through the README and markdown files.
