# skills

> **TL;DR:** Claude Code skills package implementing 10 entrepreneurial guidance commands from The Minimalist Entrepreneur book.

**`slavingia/skills`** · ⭐ 9,418 · 🔧 N/A

## What is it?
This is a Claude Code plugin marketplace package containing skill definitions based on Sahil Lavingia's book 'The Minimalist Entrepreneur'. When installed via the Claude Code plugin marketplace, it automatically fetches the repository and registers all 10 skills as slash commands that Claude Code can invoke during conversations.

The skills cover key entrepreneurial activities: finding communities for business ideas, validating concepts before coding, creating MVPs with appropriate scope, processizing value delivery by hand first, acquiring initial customers, setting pricing strategies, developing marketing plans at scale, and growing sustainably. Each skill includes both the command definition and the guidance content from the book.

The package is designed to be easily integrated into Claude Code workflows, allowing users to access structured entrepreneurial advice through natural language commands rather than reading the book manually.

## How does it work?
The repository contains skill definitions that register with Claude Code's plugin marketplace system. Each skill is defined as a code artifact (likely Python or JavaScript) that provides a `/command-name` slash interface and associated prompts. The package includes installation instructions for both the marketplace method (which auto-fetches and registers) and a local clone approach where the repo is placed in ~/.claude/plugins/skills.

When a user invokes any of the skill commands in Claude Code, the registered plugin handles the interaction by providing the relevant guidance from The Minimalist Entrepreneur. The architecture follows Claude Code's plugin model, where skills are self-contained modules that can be discovered and invoked via the slash-command interface.
