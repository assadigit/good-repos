# skills

## What is it?
This repository hosts Anthropic's implementation of Claude Skills, a system enabling dynamic loading of specialized capabilities. Each skill is packaged in its own folder containing a SKILL.md file that documents usage and includes any necessary scripts or resources. The collection spans creative, technical, and enterprise workflows, demonstrating the breadth possible with the skills framework.

For more information, check out: What are skills?, Using skills in Claude, How to create custom skills, and Equipping agents for the real world with Agent Skills.

## How does it work?
Each skill resides in its own directory containing a SKILL.md file that documents usage and may include scripts or other resources. Claude loads these dynamically at runtime, likely via its function-calling mechanism or a custom tool that reads the SKILL.md files from the repository. The architecture mirrors the Agent Skills standard, with each skill defining its own context and execution steps.
