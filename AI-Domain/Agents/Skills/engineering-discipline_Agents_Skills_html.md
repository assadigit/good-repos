# engineering-discipline

> **TL;DR:** AI agent skill that provides structured reasoning and verification for engineering tasks across multiple coding agents.

**`tmdgusya/engineering-discipline`** · ⭐ 123 · 🔧 HTML

## What is it?
Engineering discipline skills for AI coding agents. Works with Claude Code, Gemini CLI, OpenCode, Codex, and Cursor to handle tasks from vague request through verified implementation.

The system chains together multiple skills: clarification (resolve ambiguity, explore codebase), complexity assessment with auto-routing, various plan-crafting and run-plan workflows, review-work verification, plus specialized skills like karpathy (implementation guardrails), clean-ai-slop (post-generation cleanup), simplify (code quality pass), systematic-debugging (reproduce-first bug fixing), and rob-pike (measurement-driven optimization).

## How does it work?
The architecture uses a skills-chain approach where each capability builds on previous verification steps. User requests first go through clarification to resolve ambiguity and explore the codebase. A complexity assessment auto-routes simple tasks (score 5-8) through plan-crafting → run-plan → review-work, while complex tasks (score 10-15) trigger milestone-planning with adversarial critics and multi-day orchestrator checkpoints.

Each skill integrates with the underlying AI agent, providing guardrails during implementation, post-generation cleanup, code quality passes, systematic debugging workflows, and measurement-driven optimization—all designed to work across multiple agent platforms including Claude Code, Gemini CLI, OpenCode, Codex, and Cursor.
