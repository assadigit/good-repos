# agent-rules-books

> **TL;DR:** Distilled software engineering book principles as AGENTS.md rules for Codex, Cursor & Claude Code AI coding agents.

**`ciembor/agent-rules-books`** · ⭐ 2,128 · 🔧 N/A

## What is it?
This repository provides ready-to-use rule sets inspired by classic software engineering books about refactoring, architecture, DDD and code quality. Each rule set is released in three tool-agnostic Markdown versions (mini, medium, full) and includes editor-specific setup instructions for Codex, Cursor and Claude Code via USAGE.md. The project covers always-on vs on-demand usage patterns, skills, scoped rules, MCP or RAG patterns, and the preferred setup for each editor.

## How does it work?
The repository is organized as a collection of markdown files grouped by agent type (Codex, Cursor, Claude Code) with subdirectories for different rule categories (refactoring, DDD, code quality). Each rule set includes both general tool-agnostic versions and editor-specific configurations. Integration involves copying the AGENTS.md file into the respective agent's project root, following guidelines in USAGE.md for always-on vs on-demand usage, MCP/RAG patterns, and scoped rules.
