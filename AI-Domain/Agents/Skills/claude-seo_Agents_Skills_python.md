# claude-seo

> **TL;DR:** Open-source Claude Code SEO skill that runs 25 sub-skills and 18 agents for technical, content, schema, GEO, local, and e-commerce audits.

**`AgriciDaniel/claude-seo`** · ⭐ 16,988 · 🔧 Python

## What is it?
Claude SEO is an open-source SEO analysis plugin for Claude Code. It packages a universal SEO workflow as a reusable agent skill, running 25 sub-skills and 18 specialist agents in parallel across technical SEO, content quality, Schema.org markup, AI search optimization, local SEO, e-commerce, international SEO, backlinks, maps intelligence, semantic clustering, and reporting.

Each audit is designed to produce a prioritized action plan with testable recommendations grounded in primary-source guidance from Google. The project also supports optional external data sources through DataForSEO, Firecrawl, and Banana extensions, making it useful for deeper audits when live SEO or web data is needed.

## How does it work?
The project operates as a Claude Code skill/plugin rather than a standalone SaaS dashboard. When invoked inside Claude Code, it orchestrates multiple SEO-focused sub-skills and specialist agents that evaluate different parts of a site or content system in parallel. These components cover technical crawlability, on-page optimization, E-E-A-T signals, structured data, AI search visibility, local and international targeting, e-commerce relevance, backlink context, and reporting.

The workflow can incorporate optional extensions such as DataForSEO, Firecrawl, and Banana to pull external SEO, crawling, or data-enrichment signals when available. The final output is a prioritized recommendation set with actionable next steps, and the project supports PDF/Excel reporting for sharing audit results.

## Why is it important? (Core Value)
For a software engineer and researcher focused on AI agents, developer tools, and automation, this project is valuable as a concrete example of how to package complex domain workflows as Claude Code skills. It shows how sub-skills and specialist sub-agents can be decomposed around a real business problem—in this case SEO—while remaining open source and CLI-integrated rather than locked into a proprietary dashboard.

It also aligns with interests in LLM tooling, agent skill design, marketing automation, and self-hostable or membership-free workflows. The public MIT-licensed version can be used directly as an SEO audit capability inside Claude Code or as a reference architecture for building similar multi-agent skills for other domains.

## Difference from Others
Compared with traditional SEO SaaS tools or standalone crawlers, Claude SEO is not primarily a metrics dashboard; it is an agent-native skill that turns SEO analysis into an orchestrated Claude Code workflow. It decomposes the audit into many specialist sub-skills and agents, which makes it easier to reason about specific SEO problems rather than receiving one monolithic score.

Compared with generic LLM prompt collections or single-agent SEO assistants, this project stands out because it packages a structured multi-agent architecture, optional data integrations, and production-oriented reporting. Compared with MCP-style tool servers, it is more opinionated: it encodes an end-to-end SEO methodology instead of only exposing raw tools.
