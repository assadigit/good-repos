# wigolo

**`KnockOutEZ/wigolo`** · ⭐ 80 · 🔧 TypeScript

## What is it?
wigolo runs on your machine as an MCP server and gives an AI coding agent one durable surface for everything web-related — search, fetch, crawl, extract, cache, find-similar, research, and autonomous gather loops. The core tools need no API keys, nothing it touches leaves ~/.wigolo/, and there's no bill that grows with how much your agent thinks.

## How does it work?
It operates as an MCP server implementing the Model Context Protocol, providing tools that perform web search, fetch content, crawl sites, extract data, cache results locally, find similar pages, conduct research, and support autonomous gather loops. All state persists in ~/.wigolo/ without cloud dependencies, enabling privacy-first operation with zero per-query costs.
