# skills

## What is it?
Skills are portable instruction sets that teach AI agents how to use NVIDIA software optimally, including CUDA-X libraries, AI Blueprints, and platform tools. This repository is a catalog: skills are maintained in their respective product repos, and mirrored here daily via an automated sync pipeline. Skills are being added continuously, so check back for updates.

We are building this infrastructure in the open, and contributions are welcome. See the [Roadmap](#roadmap) for what is planned next.

## How does it work?
Skills are defined as portable instruction sets, likely using a schema like Agent Skills Spec (linked in README). The repository mirrors these skills daily via an automated sync pipeline, which probably runs on GitHub Actions or similar CI/CD infrastructure. Since skills are maintained in their respective product repos, this repo aggregates them into a single location for easy consumption by agents.

## Why is it important? (Core Value)
For a software engineer focused on AI agents, this repository provides an official, NVIDIA-verified catalog of skills that can be integrated into any agent framework or MCP server. It solves the problem of vendor-specific knowledge being scattered across product repos; here it is centralized and versioned. The open-source nature means you can audit the specs, contribute improvements, and keep your agents up-to-date with NVIDIA's evolving tooling.
