# andrej-karpathy-skills

**`multica-ai/andrej-karpathy-skills`** · ⭐ 188,481 · 🔧 N/A

## What is it?
This repository provides a single CLAUDE.md file designed to improve Claude Code's behavior by addressing common pitfalls identified by Andrej Karpathy. It translates his observations on LLM coding issues into four actionable principles: Think Before Coding, Simplicity First, Surgical Changes, and Goal-Driven Execution. By embedding these guidelines directly in the prompt context, the file nudges the model to avoid overcomplication, manage confusion, surface inconsistencies, and make surgical edits rather than orthogonal changes.

The file is self-contained and requires no external dependencies; it simply reads the CLAUDE.md content during a coding session. It includes both English and Chinese documentation (README.zh.md) for broader accessibility. The repository has accumulated significant community interest, with over 188k stars and nearly 20k forks, indicating strong adoption among developers who rely on Claude Code.

Overall, the project serves as a practical resource for enhancing the quality of AI-assisted coding, ensuring that models produce clearer, more maintainable code while respecting user intent and avoiding unnecessary bloat.

## How does it work?
The core artifact is a markdown file (CLAUDE.md) placed in a repository that Claude Code reads as part of its prompt context. When a user runs a coding task, the model incorporates the content of this file into its reasoning process, applying the four guiding principles to its output generation. The file itself contains concise bullet points and tables that outline the problems (wrong assumptions, overcomplication, surgical changes needed) and the corresponding solutions (Think Before Coding, Simplicity First, etc.). No code execution or external services are involved; it is purely a static guideline.

Because the file is markdown, it can be edited and versioned like any other source file. The repository also hosts a README that explains the provenance (Andrej Karpathy's observations) and provides links to the Chinese translation. This design makes it easy for users to integrate into their own development environments or share with teams.
