# microsoft-security-skills

> **TL;DR:** Curated Microsoft security skills library for AI agents using Defender, Sentinel, Entra, Purview, Intune, Security Copilot.

**`vinayaklatthe/microsoft-security-skills`** · ⭐ 151 · 🔧 JavaScript

## What is it?
Microsoft Security Skills Plugin is a curated knowledge base that packages security expertise into structured skills specifically designed for AI agents. It covers the major Microsoft security product families including Azure Defender, Sentinel (SIEM), Entra ID (formerly Azure AD), Purview (governance), Intune (endpoint management), and Security Copilot. The repository currently contains 88 individual skills that have been validated across two LLM models.

## How does it work?
The plugin provides a structured data format (likely JSON or similar schema) containing security knowledge about Microsoft products. Agents can query these skills to inform their decision-making about which controls apply, what validations are needed before policies go live, and which investigation paths to follow. The README indicates it was validated across multiple LLM hosts including Copilot Studio, Claude, Cursor, Codex, and Gemini models, suggesting the data is designed to be consumed via function calls or natural language prompts.
