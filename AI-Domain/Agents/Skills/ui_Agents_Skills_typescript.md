# ui

> **TL;DR:** A framework-agnostic design language + Claude Code skill for dense, AMOLED-black agent UIs.

**`pacifio/ui`** · ⭐ 148 · 🔧 TypeScript

## What is it?
Atlas is a framework-agnostic design language — not a CSS framework you bolt on — that provides a dense, AMOLED-black visual vocabulary for dashboards, chat surfaces, autonomous workflow tools, landing pages, and mobile apps. It comes as a Claude Code skill (markdown rules + one reference CSS file) that teaches any coding agent the Atlas aesthetic, tokens, and composition recipes.

The reference implementation lives in colors_and_type.css with 180+ tokens and 50+ .atlas-* classes; it works as plain HTML and translates cleanly to other stacks. A live kitchen-sink site at ui.pacifio.dev demonstrates components, foundations, patterns, mockups, and get-started guides.

## How does it work?
Atlas operates via a Claude Code skill that injects markdown-based design rules into any agent workflow. The skill reads the reference CSS file (colors_and_type.css) and applies its token set and .atlas-* classes to generated HTML. Because it is framework-agnostic, you can copy the CSS into React, Vue, or vanilla HTML projects without modification. The live site serves as a documentation hub for components, foundations, patterns, mockups, and get-started guides.

## Why is it important? (Core Value)
Atlas solves the visual inconsistency that plagues autonomous agent interfaces by providing a single, self-hostable design language. For a researcher building AI agent workflows, this means dashboards and chat surfaces can adopt a professional look without depending on third-party UI kits. The Claude Code skill lets agents automatically apply the Atlas aesthetic when generating UI code, reducing boilerplate and ensuring token-level consistency across tools.

Specifically for your objectives: it improves developer workflow by offering a reusable design system you can integrate into your homelab projects; it provides an agent skill that aligns with your interest in AI/LLM tooling and MCP servers; and as a self-hostable CSS file, it fits perfectly with your goal of identifying self-hostable alternatives to SaaS products for your personal knowledge base.

## Difference from Others
Unlike shadcn/ui or Tailwind CSS, which are framework-specific component libraries, Atlas is a design language that works across any stack. Its Claude Code skill integrates directly with LLM agents, whereas other UI kits require manual adoption of their classes. This makes Atlas the first agent-aware UI system that also provides a human-readable reference file.
