# skills

> **TL;DR:** A collection of AI agent skills for building polished interfaces, covering UI polish, typography, color, accessibility, layout, and writing.

**`jakubkrehel/skills`** · ⭐ 2,703 · 🔧 N/A

## What is it?
Skills is a curated repository containing specialized capabilities that AI agents can invoke to assist with various aspects of interface construction. The project organizes these skills as modular components, each documented in its own SKILL.md file. These modules address different dimensions of interface quality: UI polish (better-ui), typography (better-typography), color handling in the OKLCH space (better-colors), accessibility compliance (better-accessibility), layout structure (better-layout), and UX writing (better-writing). The project also includes better-interface, a meta-skill that coordinates all other skills for comprehensive interface reviews.

## How does it work?
The repository is structured as a collection of independent skill modules, each implemented as a standalone component with dedicated documentation. Agents interact with these skills through function calls or similar invocation mechanisms defined in each SKILL.md file. The modular design allows selective usage—agents can invoke only the relevant skills for their specific tasks rather than requiring full UI kits. This architecture mirrors patterns seen in agent tool registries where capabilities are exposed as callable functions with clear documentation of inputs, outputs, and usage contexts.
