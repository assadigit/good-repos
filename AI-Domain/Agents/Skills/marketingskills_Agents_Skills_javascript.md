# marketingskills

> **TL;DR:** Marketing skills for AI agents: CRO, copywriting, SEO, analytics. Works with Claude Code, OpenAI Codex, Cursor via Agent Skills spec.

**`coreyhaines31/marketingskills`** · ⭐ 41,221 · 🔧 JavaScript

## What is it?
Marketing Skills for AI Agents is a curated collection of markdown-based skills designed to equip AI coding assistants with marketing domain expertise. These skills cover conversion rate optimization (CRO), copywriting, search engine optimization (SEO), analytics, and growth engineering—areas where technical marketers often need assistance but lack built-in capabilities in most agent frameworks.

The project is built for technical marketers and founders who want AI agents to handle real-world marketing tasks. It integrates with Claude Code, OpenAI Codex, Cursor, Windsurf, and any agent supporting the Agent Skills spec (https://agentskills.io). Each skill is a markdown file containing structured prompts, instructions, or data that an agent can invoke when performing marketing-related work.

Contributions are welcomed via pull requests, making this an open-source resource that evolves with the community. Companion resources include Corey Haines' Coding for Marketers guide and links to his Conversion Factory agency, Swipe Files newsletter, AI Marketing Training course, and Magister—an autonomous AI agent that leverages these skills as its CMO.

## How does it work?
Each skill is implemented as a markdown file that defines the context, instructions, and data an AI agent needs to perform a specific marketing task. These files are structured to be consumed by agents that support the Agent Skills spec, which provides a standard interface for passing skills to LLM-powered coding assistants. The project does not implement its own runtime or orchestration layer; instead it provides a library of reusable skill definitions that can be imported into any compatible agent environment.

Because the skills are markdown-based, they are human-readable and easy to audit, extend, or translate into other formats. This design choice keeps the repository lightweight while ensuring that agents can reliably invoke the right marketing capabilities when prompted with appropriate context.
