# video-shotcraft

> **TL;DR:** AI video skill for Claude Code & Codex that generates cinematic product videos via Remotion with shot recipes and motion previews.

**`Vincentwei1021/video-shotcraft`** · ⭐ 7,004 · 🔧 TypeScript

## What is it?
video-shotcraft is an agent skill package that extends AI coding agents—specifically Claude Code and Codex—with the ability to produce cinematic product and promotional videos. Rather than being a standalone video editor or generation service, it plugs into existing coding agents as a structured capability module, giving them a curated vocabulary of professional video compositions they can reference when writing code.

The skill ships with 152 shot recipe cards (predefined camera angles, framing, and transition patterns), 209 motion previews displayed in a live web gallery, and a production-ready Remotion template that agents can scaffold from. The entire system is built on Remotion, a React-based framework for programmatic video creation in TypeScript, meaning every frame is defined as declarative code rather than generated by a diffusion model.

The project positions itself squarely in the emerging 'agent skills' category: it is not an agent runtime or framework, but a domain-specific capability layer that agents load to gain expertise in a particular creative workflow.

## How does it work?
The skill is structured around Remotion, which renders video as React components where each frame is a function of time. Agents consume the shot recipe cards as reference patterns—each card defines a camera movement, subject framing, and transition style—and combine them to compose full sequences. The 209 motion previews serve as visual ground truth so agents (and human reviewers) can verify that generated code matches the intended look. A production-ready template provides the project scaffolding (component structure, timeline configuration, export settings) so an agent can go from prompt to renderable video without assembling the Remotion pipeline from scratch.

As an agent skill, the package is formatted to be loaded by Claude Code or Codex as instructions, reference material, and code templates. The agent reads the recipe cards, selects appropriate shots for a given brief, writes Remotion component code, and produces a deterministic, reproducible video file—no GPU inference or external video API calls required.

## Difference from Others
Most AI video tools are either standalone SaaS generators (Runway, Pika) or generic prompt-to-video pipelines. video-shotcraft is neither: it is a skill layer for existing coding agents, not a video engine. Compared to other agent skills (which are often thin prompt files), this one ships with a rich structured library—recipe cards, motion previews, and a working template—giving the agent real compositional guidance rather than freeform generation. The Remotion foundation makes output deterministic and reproducible, a sharp contrast to stochastic video-diffusion models. Among agent-skill projects, it stands out for its concrete domain depth and the production-ready code scaffold that lets an agent go from brief to renderable video in one pass.
