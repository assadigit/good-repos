# hallmark

> **TL;DR:** Anti-AI-slop design skill for Claude Code, Cursor, Codex with 20 themes and 4 verbs.

**`Nutlope/hallmark`** · ⭐ 14,957 · 🔧 CSS

## What is it?
Hallmark is a design skill for AI coding assistants (Claude Code, Cursor, Codex) that generates UI code which refuses to look AI-generated. It picks a macrostructure for a given brief, applies one of twenty distinct themes, runs fifty-seven slop-test gates plus a pre-emit self-critique, and then hands back results that are structurally different from each other. The skill offers four verbs: default (build new UI), audit (score existing code), redesign (rebuild with a different fingerprint), and study (extract design DNA from screenshots or URLs).

Each generated page is shaped by its brief; Hallmark refuses the on-distribution defaults every LLM was trained into, so two pages for two different briefs feel like different sites rather than colour-swaps of the same template. Optionally it emits a portable design.md file that can be handed off to other AI tools or stored in a personal knowledge base.

The tool is built by Together AI and is designed to integrate with the major coding assistants, providing a macrostructure-first approach rather than template swapping.

## How does it work?
Hallmark likely uses a prompt-based approach to select macrostructures and apply theme rule-sets. It probably runs a series of internal checks (the slop-test gates) that evaluate the generated code against anti-patterns, then performs a self-critique before emitting output. The four verbs correspond to different modes: default builds new UI, audit runs a scoring pass, redesign discards structure and rebuilds, study extracts design DNA and optionally outputs a portable markdown file.

## Why is it important? (Core Value)
Hallmark directly supports the user's goal of discovering tools that improve development workflow. As a skill for Claude Code, Cursor, and Codex, it can be invoked alongside other agent capabilities to produce higher-quality UI code that avoids AI slop. The audit verb enables the user to score existing code against anti-patterns, while the redesign verb lets them rebuild with a different fingerprint without losing copy or brand. The study verb extracts design DNA from screenshots or URLs, which can be useful for research or documentation. Because it emits a portable design.md file, it can be integrated into the user's Obsidian vault or used as a handoff artifact for other AI tools.

It also offers audit and redesign modes that operate on existing code rather than only generating new UI. The study verb extracts design DNA from any screenshot or URL, producing a portable markdown handoff, which is not present in most other LLM UI tools.
