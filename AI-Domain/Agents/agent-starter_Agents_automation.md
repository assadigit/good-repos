# agent-starter

> **TL;DR:** Production-grade LLM agent scaffolding from Microsoft — tools, memory and evals wired from day one.

**`microsoft/agent-starter`** · ⭐ 4,821 · 🔧 Python

## What is it?
A batteries-included starter kit for building production LLM agents, with tool-calling, memory, and evaluation harnesses wired from day one.

## How does it work?
Layered architecture: a planner loop drives a tool registry, with a memory store and tracing built in. Every run emits structured traces that the eval suite replays.

## Why is it important? (Core Value)
Removes the 3-week boilerplate phase of agent projects. You start from tested scaffolding instead of gluing SDK examples together.

## Key Features & Technologies
- Tool-calling out of the box
- Pluggable memory backends
- Built-in eval harness
- OpenTelemetry traces
