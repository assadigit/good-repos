# LibreCode

> **TL;DR:** AI-powered code editor with reverse engineering toolkit, runs Ollama locally.

**`re4/LibreCode`** · ⭐ 20,904 · 🔧 C#

## What is it?
LibreCode is a free, open-source AI-powered code editor built from the ground up with .NET 10 and Avalonia UI. It runs natively on Windows, Linux, and macOS without Electron or web views, just fast native rendering. The project pairs a full-featured code editor with a local AI assistant powered by Ollama, a built-in terminal, a model marketplace, and a serious reverse engineering toolkit for both .NET assemblies and WebAssembly binaries.

## How does it work?
The editor is built using .NET 10 with Avalonia UI for cross-platform native rendering. The AI assistant runs locally via Ollama, allowing users to use any model they have installed without sending code to the cloud. For reverse engineering, the project integrates specialized tools including decompiler, IL/WAT/x86-64 disassembly, hex editor, PE/ELF inspectors, step-through debuggers, live CDP debugging, Harmony patch generation, OLLVM deobfuscation, and cross-module stealth/anti-debug analysis.

## Why is it important? (Core Value)
LibreCode addresses the privacy and dependency issues plaguing cloud-based AI editors by keeping all processing local—your code never leaves your machine, runs against any Ollama model you have installed, and ships with no telemetry, accounts, or subscriptions. For the user, this project represents an excellent self-hostable alternative to SaaS products like Cursor, aligning perfectly with their objective to discover self-hostable alternatives. The integrated reverse engineering toolkit adds unique value beyond standard editors, making it particularly useful for a software engineer interested in developer productivity tools and AI/LLM tooling. It's both a practical code editor and a specialized hacking environment.

## Key Features & Technologies
- .NET 10 with Avalonia UI for cross-platform native rendering
- Ollama integration for local AI assistance without cloud API
- Reverse engineering toolkit for .NET assemblies and WebAssembly binaries
- Live browser debugging over Chrome DevTools Protocol (CDP)
- 25+ language syntax highlighting via TextMate grammars
- Built-in terminal and model marketplace
- No telemetry, accounts, or subscriptions

## Difference from Others
LibreCode differs from VS Code + Ollama setups because it's a single, unified application combining editing, AI, and reversing toolkits rather than requiring separate extensions and external LLM clients. Cursor is closed-source and relies on cloud APIs, making LibreCode the open-source alternative with 100% local AI processing. Other open-source editors like VS Code or Vim typically lack integrated reverse engineering toolkits and live debugging capabilities built directly into the editor.
