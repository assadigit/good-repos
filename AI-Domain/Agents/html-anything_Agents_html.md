# html-anything

> **TL;DR:** Local AI agent editor that auto-detects 9 coding-agent CLIs to generate HTML docs across 9 surfaces (magazine, deck, poster, etc.) with zero API key.

**`nexu-io/html-anything`** · ⭐ 7,540 · 🔧 HTML

## What is it?
HTML Anything is an agentic HTML editor that lets local AI agents generate documentation and content directly as HTML rather than markdown. It auto-detects 9 coding-agent CLIs (Claude Code, Cursor Agent, Codex, Gemini CLI, GitHub Copilot CLI, OpenCode, Qwen Coder, Aider, IBM Bob) from your PATH and uses them to apply one of 75 composable skill templates across 9 deliverable surfaces: magazine articles, keynote decks, résumés, posters, Xiaohongshu cards, tweet cards, web prototypes, data reports, and Hyperframes videos. The tool runs entirely local-first with zero API key dependency, provides sandboxed preview mode to review generated HTML before exporting, and offers one-click export to WeChat, X (Twitter), Zhihu, or download as .html / .png files.

## How does it work?
The project operates in a local-first architecture with no external API calls required. Upon launch, it scans your system PATH for available coding-agent CLI executables and automatically selects the strongest one based on tool capabilities. It then loads a configuration of 75 composable skill templates that define how to transform markdown drafts into various HTML output formats (magazine layouts, slide decks, social media cards, etc.). Each skill template is designed to be modular and can be chained together for complex deliverables. The editor provides a sandboxed preview mode where you can view the generated HTML in the browser before committing. Export is handled via one-click actions that push the final HTML or PNG directly to your configured social accounts (WeChat, X, Zhihu) or download the file locally.
