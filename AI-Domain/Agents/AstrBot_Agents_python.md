# AstrBot

> **TL;DR:** Self-hosted AI agent framework integrating Telegram, QQ, Discord with multiple LLMs and MCP support.

**`AstrBotDevs/AstrBot`** · ⭐ 39,349 · 🔧 Python

## What is it?
AstrBot is a comprehensive AI agent assistant and development framework that integrates numerous instant messaging platforms (Telegram, QQ, Discord) with various large language models. It serves as an open-source alternative to commercial chatbot platforms like OpenClaw, providing developers and users with the ability to self-host their own intelligent bot infrastructure.

## How does it work?
AstrBot operates as a multi-platform messaging bot framework built in Python 3.12+. It connects to various IM APIs (Telegram Bot API, QQ Bot frameworks, Discord Webhooks) to receive user messages, processes them through configurable LLM backends (OpenAI, Gemini, Llama), and returns AI-generated responses. The system supports MCP (Model Context Protocol) integration for tool-use capabilities and can be deployed via Docker containers.

## Why is it important? (Core Value)
For a software engineer focused on AI agents and developer tools, AstrBot directly addresses the objective of finding AI agent frameworks that can be self-hosted as alternatives to SaaS products.
