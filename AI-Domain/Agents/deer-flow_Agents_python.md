# deer-flow

**`bytedance/deer-flow`** · ⭐ 76,332 · 🔧 Python

## What is it?
DeerFlow is an open-source AI agent harness built by ByteDance that orchestrates multiple sub-agents, persistent memory, and sandboxed execution environments to tackle long-horizon tasks spanning minutes to hours. It combines extensible skill modules with a message gateway for inter-agent communication, enabling complex workflows such as research, coding, and content creation. The project has been completely rewritten in version 2.0, which shares no code with the original 1.x branch but offers a more modern, flexible architecture.

## How does it work?
DeerFlow operates as a hierarchical agent system where a central harness coordinates specialized sub-agents that each focus on particular tasks (e.g., data gathering, code generation). These sub-agents share a common memory store that persists across steps and can be queried via the message gateway. Code execution is sandboxed to ensure safety, while skill modules are pluggable components that extend functionality without modifying core logic.

## Why is it important? (Core Value)
For a researcher and software engineer building a personal knowledge base of AI agents, DeerFlow offers a self-hostable, open-source foundation for orchestrating multi-agent workflows without relying on proprietary SaaS solutions. Its modular skill system aligns with your interest in AI/LLM tooling and MCP servers, allowing you to integrate custom capabilities into your own projects. Additionally, its origin from ByteDance (a major tech company) adds credibility, and the MIT license ensures you can adopt it freely in your homelab or development environment.

## Key Features & Technologies
- Python 3.12+ backend
- Node.js 22+ support
- LangGraph workflow orchestration
- Modular skill system with message gateway
- Persistent memory store
- Sandboxed code execution environments
- MIT open-source license

## Difference from Others
Unlike isolated agent libraries (e.g., LangChain alone) or single-purpose tools, DeerFlow provides a full harness that coordinates multiple agents with shared state and sandboxing. It also differs from older agent frameworks by being a ground-up rewrite in 2.0, offering more modern architecture and better extensibility while retaining compatibility with LangGraph.
