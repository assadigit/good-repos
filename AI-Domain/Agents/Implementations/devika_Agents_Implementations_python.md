# devika

> **TL;DR:** First open-source Agentic Software Engineer capable of coding from natural language instructions.

**`stitionai/devika`** · ⭐ 19,538 · 🔧 Python

## What is it?
Devika is an experimental AI software engineer that can understand high-level human instructions, decompose them into actionable steps, research relevant information, and write code to achieve the given objective. It aims to serve as an AI pair programmer that can take on complex coding tasks with minimal human guidance, potentially revolutionizing how we build software.

## How does it work?
Devika utilizes large language models for understanding instructions and generating code, planning and reasoning algorithms to break down tasks into sub-steps, and web browsing abilities to gather information needed for the task. The architecture likely involves an orchestration layer that coordinates between these components, with LLM-based planning modules that decide which tool or action to take next.

## Why is it important? (Core Value)
For a software engineer focused on AI agents and self-hostable alternatives to SaaS products, Devika represents exactly the kind of open-source project you want in your knowledge base. It's an early-stage implementation (currently experimental) but gives you something concrete to explore rather than just another closed SaaS product. You can contribute to its development, integrate it into your own tools, and use it as a basis for building more specialized agents. Given your interest in automation and developer productivity, Devika could help automate coding tasks, reduce manual work, and provide a customizable agent you can adapt to your specific workflow needs.

- LLM-based reasoning and planning

## Difference from Others
Compared to Devin (the SaaS product Devika is designed as an alternative to), Devika is fully open-source and self-hostable, giving you control over data and deployment. Unlike Cursor or Copilot which integrate into existing IDEs, Devika appears to be a standalone agent that can work independently. Other open-source coding agents often lack the full agentic capabilities (planning + browsing + code execution) that Devika aims to combine.
