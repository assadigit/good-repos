# ragflow

**`infiniflow/ragflow`** · ⭐ 84,418 · 🔧 Go

## What is it?
Open-source RAG engine combining retrieval-augmented generation with AI agent capabilities for enhanced LLM context.

## How does it work?
Uses a modular architecture: documents are parsed and chunked into embeddings stored in a vector database (ChromaDB). Retrieval pipelines match queries to relevant chunks, which are fed into an agent orchestration layer handling multi-step reasoning and tool use. Supports multiple LLMs through standard API integrations.

## Why is it important? (Core Value)
For you as a software engineer focused on AI agents and homelab infrastructure, ragflow offers a self-hostable RAG engine with built-in agent capabilities—perfect for building privacy-preserving workflows without relying on SaaS. Its open-source nature aligns with your interest in self-hosted alternatives, giving you full control over data and customization while providing robust context layers for LLMs.

## Difference from Others
While other RAG engines like LangChain's RAG are more generic frameworks, ragflow integrates advanced agent capabilities directly into its RAG framework. This makes it particularly suited for custom workflows requiring both retrieval and autonomous decision-making, offering greater flexibility than commercial solutions that often lack deep agent features or self-hostability.
