# osint-d2

> **TL;DR:** Agentic OSINT toolkit for autonomous identity triangulation, cognitive profiling, and breach analysis across 30+ platforms via CLI.

**`Doble-2/osint-d2`** · ⭐ 211 · 🔧 Python

## What is it?
OSINT-D2 is an advanced open-source intelligence platform that transforms usernames and emails into structured identity dossiers. It combines agentic AI with enterprise-grade ScrapingAnt proxy infrastructure to deliver intelligence-grade identity correlation, cognitive profiling, and breach analysis — all from a single CLI command.

The project leverages DeepSeek, Groq, and OpenRouter for AI processing, uses Poetry for dependency management, and is built as a CLI-first tool using Typer. It automates OSINT investigations by orchestrating function calls to scrape data from 30+ platforms while maintaining open-source transparency under the MIT license.

## How does it work?
The toolkit operates through an agentic AI architecture that autonomously triangulates identities from usernames and emails, leveraging ScrapingAnt's enterprise-grade proxy infrastructure to bypass rate limits and anti-scraping measures. It uses function calling to orchestrate scraping tasks across multiple platforms, then applies cognitive profiling algorithms to synthesize the gathered data into structured identity dossiers.

The CLI-first design (powered by Typer) allows users to run investigations via terminal commands, making it suitable for automation pipelines and security tooling. Its Python 3.11+ requirement ensures compatibility with modern async scraping libraries and AI SDKs.

## Why is it important? (Core Value)
OSINT-D2 is important because it automates identity intelligence tasks that are typically manual, error-prone, or require expensive SaaS subscriptions. By providing agentic AI capabilities directly in the CLI, it enables developers and security professionals to integrate OSINT workflows into their tooling without needing separate scraping services. The MIT license makes it self-hostable, aligning with the user's interest in homelab infrastructure and open-source alternatives.

For a researcher focused on AI agents and developer tools, this project offers a concrete example of modern agentic patterns applied to OSINT — something that directly supports their objectives of discovering useful frameworks and learning new scraping approaches. It also demonstrates how ScrapingAnt proxies can be combined with LLM-based analysis for intelligence-grade correlation.

## Key Features & Technologies
- Python 3.11+ with Poetry dependency management
- Agentic AI powered by DeepSeek, Groq, and OpenRouter
- ScrapingAnt enterprise-grade proxy infrastructure
- CLI-first design using Typer
- Identity correlation and cognitive profiling algorithms
- Breach analysis capabilities
- 30+ platform support across 5 languages

## Difference from Others
OSINT-D2 distinguishes itself from traditional OSINT tools like theharvester, Maltego, or SpiderFoot through its agentic AI architecture. While those tools rely on rule-based scraping and manual correlation steps, this project uses autonomous agents with function calling to orchestrate investigations. It also incorporates ScrapingAnt proxies rather than public proxy pools, and presents results via CLI instead of GUIs or dashboards — making it more suitable for integration into developer workflows.
