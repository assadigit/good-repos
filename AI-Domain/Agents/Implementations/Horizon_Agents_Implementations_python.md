# Horizon

**`Thysrael/Horizon`** · ⭐ 7,874 · 🔧 Python

## What is it?
Horizon is a self-hosted AI-powered news aggregator that curates daily briefings in English and Chinese using LLMs, with optional MCP tool use, webhook notifications, and OpenClaw scraping.

## How does it work?
The project likely ingests news from various sources (RSS feeds, APIs, web scraping via OpenClaw), processes articles with an LLM to extract or summarize key points, optionally uses MCP for tool use (e.g., fetching additional data), generates a brief, and sends notifications through Feishu Bot or webhook triggers. Written in Python, it follows a pipeline architecture typical of news aggregators.

## Why is it important? (Core Value)
For users focused on self-hosted AI tools, Horizon offers a practical example of an LLM-driven news radar that reduces reliance on SaaS products. It aligns with interests in AI/LLM tooling (agents, MCP) and developer productivity by automating daily news curation. The dual-language output (English & Chinese) adds value for multilingual users.
