# logocreator

**`Nutlope/logocreator`** · ⭐ 7,193 · 🔧 TypeScript

## What is it?
Self-hosted AI logo generator using Flux on Together AI, with Next.js and built-in authentication.

## How does it work?
The app is a Next.js frontend built with TypeScript that calls Together AI's Flux Pro 1.1 model via API to generate logos from text prompts. UI components come from Shadcn, styled with Tailwind CSS. Authentication is handled by Clerk, and Upstash Redis provides rate limiting. Analytics are tracked via Plausible.

## Why is it important? (Core Value)
This project directly serves your interests in self-hostable alternatives to SaaS products (it can be deployed locally), open-source projects from major tech companies (Together AI is a prominent AI infrastructure provider), and developer productivity tools.
