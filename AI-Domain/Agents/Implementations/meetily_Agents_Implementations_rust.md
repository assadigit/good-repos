# meetily

> **TL;DR:** Self-hosted, privacy-first AI meeting assistant with Whisper/Parakeet transcription and Ollama summarization. 100% local.

**`Zackriya-Solutions/meetily`** · ⭐ 16,081 · 🔧 Rust

## What is it?
Meetily is a privacy-first AI meeting assistant designed for macOS and Windows that provides live speech-to-text transcription, speaker diarization, and session summarization entirely on local hardware. The project positions itself as a self-hosted alternative to commercial SaaS products like Otter.ai and Fireflies.ai, with no cloud dependency required for processing.

## How does it work?
The application uses Whisper or Parakeet for speech-to-text conversion, Sortformer for speaker diarization, and Ollama for generating meeting summaries. All processing runs locally on the user's machine using a Rust backend, ensuring complete data privacy without any cloud uploads. The system includes live transcription capabilities for real-time meetings and post-meeting processing for recording-based sessions.

## Why is it important? (Core Value)
Meetily addresses the growing demand for privacy-focused AI tools by keeping all meeting data local rather than sending audio to cloud services. For a self-hosted, open-source AI meeting assistant, it provides essential transcription and summarization capabilities that would otherwise require paid subscriptions to services like Otter.ai or Fireflies.ai. The Rust implementation ensures efficient local processing, while the MIT license makes it freely redistributable.

## Key Features & Technologies
- Rust backend
- Whisper/Parakeet speech-to-text

- Ollama integration
- Live transcription
- Self-hosted

## Difference from Others
Unlike commercial meeting note takers that require cloud uploads and subscriptions, Meetily processes audio entirely locally with no data leaving the machine. It also differs from other open-source transcription tools by combining Whisper/Parakeet with Sortformer for diarization and Ollama for summarization in a single privacy-focused package.
