## What is it?
goose is an extensible, open-source AI agent that runs natively on your machine via a desktop app (macOS, Linux, Windows), CLI, and API. It goes beyond code suggestions by allowing you to install, execute, edit, and test with any LLM. The project is licensed under Apache-2.0 and hosted by the Agentic AI Foundation (AAIF) at the Linux Foundation, with an active Discord community.

## How does it work?
goose is architected as a modular agent framework that integrates language models with tool-use capabilities. It likely uses MCP (Model Context Protocol) for standardizing interactions between the agent and external tools/servers. The desktop app probably runs a local backend service, while the CLI provides programmatic access. Extensibility means you can plug in custom LLMs, tools, or workflows without modifying core code. This aligns with its description as "extensible" and its focus on AI agents.
