# browser-use

> **TL;DR:** AI browser agent that automates online tasks using Playwright and LLMs.

**`browser-use/browser-use`** · ⭐ 103,122 · 🔧 Python

## What is it?
Browser-Use is a Python-based AI agent framework designed to make websites accessible for autonomous agents. It combines large language models with browser automation capabilities to perform complex, multi-step tasks like logging into services, filling forms, scraping data, and interacting with UI elements across different websites.

The project leverages Playwright under the hood for reliable browser control and integrates LLM reasoning to interpret user instructions and plan actions.

## How does it work?
The architecture separates high-level agent logic from low-level browser operations. User prompts are processed by an LLM which generates a structured action plan, then Playwright executes steps like navigating to URLs, clicking elements, typing text, or taking screenshots.

Vision models may be used to understand page content. The system likely maintains state across interactions and provides APIs for chaining tasks.

## Why is it important? (Core Value)
This project is significant as it advances the frontier of LLM tooling by enabling agents to directly interact with web interfaces in a reliable way.

For developers seeking automation tools, Browser-Use offers a self-contained, open-source solution that can be integrated into custom workflows or deployed locally, aligning with interests in self-hostable software and homelab infrastructure. It also provides a practical example of combining vision and language models for UI understanding, which is critical for real-world agent applications.

## Key Features & Technologies
- Built on Playwright
- LLM-powered agent orchestration
- Multi-step task handling
- Python-based implementation
- Open-source with community demos
- Vision model integration

## Difference from Others
Compared to generic scraping tools or Selenium-based agents, Browser-Use emphasizes LLM-driven reasoning over simple keyword matching. It likely offers better state management and structured action planning than ad-hoc scripts. The Playwright foundation provides more modern browser automation support than older libraries.
