# open-interpreter

> **TL;DR:** Lightweight coding agent for open models enabling terminal-based LLM interaction.

**`openinterpreter/open-interpreter`** · ⭐ 64,290 · 🔧 Rust

## What is it?
Open Interpreter is an AI agent that enables direct interaction with large language models through your terminal. It supports various open-source models including Deepseek, Kimi, and Qwen, making it accessible without relying on proprietary APIs or expensive cloud services. The project provides a streamlined way to run coding agents locally rather than as SaaS offerings.

## How does it work?
The project uses Rust as its implementation language, offering performance benefits and native integration with terminal environments. It interfaces with LLM APIs to send prompts and receive code execution outputs directly in the terminal. The architecture includes a Rust-native zcode harness specifically for GLM-5.2, handling model-specific nuances. Installation is simplified through curl-based scripts for macOS/Linux and PowerShell scripts for Windows.
