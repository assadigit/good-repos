# jan

**`janhq/jan`** · ⭐ 43,426 · 🔧 TypeScript

## What is it?
Jan is an open-source alternative to ChatGPT that runs 100% offline on your computer, giving you full control and privacy over AI interactions. Built with Tauri and llama.cpp, it lets you use various LLM models directly on your machine without sending data to cloud APIs.

The project provides a polished desktop experience with support for multiple LLM backends (Ollama, llama.cpp, etc.), easy installation via Microsoft Store or GitHub releases, and full offline capability. It's actively maintained with 43,000+ stars on GitHub and includes documentation for getting started.

## How does it work?
Jan is architected as a desktop application using Tauri, which combines a web frontend with a native Rust backend. It integrates with llama.cpp to run LLM models locally, allowing you to choose different model backends and configure them in the settings. The architecture ensures all data stays on your machine—no telemetry or cloud API calls by default.

The installation process supports multiple paths: Microsoft Store for Windows users, GitHub releases for direct downloads, and pip-based setup for developers who want to build from source.

## Difference from Others
Unlike ChatGPT, Jan offers full offline capability and privacy. Compared to other open-source LLM interfaces like LM Studio, Jan provides a more polished Tauri-based desktop experience, though LM Studio also runs locally-first. Against agent frameworks such as LangChain or AutoGen, Jan is not an agent framework but rather a consumer-facing AI chat application that runs local models—distinct from cloud-based chatbots which send data to APIs.
