# html-video

> **TL;DR:** Converts HTML/CSS/data to MP4 videos using pluggable render engines and AI soundtrack.

**`nexu-io/html-video`** · ⭐ 3,812 · 🔧 HTML

## What is it?
html-video is a self-hosted tool that converts HTML, CSS, and structured data into fully animated MP4 videos. It allows AI coding agents to describe a video or paste an article/GitHub link, then renders the result locally on your machine with pluggable render engines, 21 curated templates, and optional AI soundtrack generation.

The project uses Apache-2.0 licensing, avoiding per-render fees and vendor lock-in, making it ideal for open-source workflows.

## How does it work?
The system operates as an AI agent loop: a coding agent receives a prompt or content link, generates HTML/CSS/data, and passes it to a pluggable render engine (e.g., hyperframes, ffmpeg) that produces MP4 frames. Templates provide styling presets, while the AI soundtrack module adds music/narration. All rendering happens locally on your laptop with no external dependencies beyond the chosen engine.
