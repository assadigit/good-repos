# council-of-high-intelligence

> **TL;DR:** 18 AI personas deliberate your hardest decisions across multiple LLM providers.

**`0xNyk/council-of-high-intelligence`** · ⭐ 3,377 · 🔧 Shell

## What is it?
Council of High Intelligence deploys an 18-member council of distinct AI personas to deliberate on complex questions through multi-round structured discussion. Each member has a unique background—philosopher, technologist, ethicist, scientist, writer, strategist, futurist, poet, detective, mathematician, historian, journalist, biologist, psychologist, legal expert, designer, and two additional specialists—with distinct knowledge bases, biases, and reasoning styles that prevent groupthink and provide comprehensive perspectives. The council operates in three deliberation modes: Debate Mode for open-ended discussion, Consensus Mode with structured argumentation and voting, and Report Mode delivering detailed analysis. Installation is as simple as installing a Claude Code plugin via the /council command or Codex skill.

The project emphasizes confidence-weighted verdicts rather than simple majority rules, allowing nuanced outcomes that reflect each persona's certainty levels. Multi-provider auto-routing enables flexible model usage across different LLM APIs (Claude, Gemini, Ollama, OpenAI, etc.). The deliberation protocol is designed to be rigorous and reproducible, with structured rounds of argument exchange before reaching conclusions. This makes it particularly valuable for software engineers and researchers who need diverse, well-reasoned perspectives on technical or ethical decisions in their work.

## How does it work?
Council of High Intelligence is implemented as a Claude Code plugin built with Python (pip requirements include requests, aiohttp, json, colorama). It deploys 18 distinct AI personas, each with their own knowledge base and reasoning style. The plugin routes requests across multiple LLM providers automatically, enabling flexible model usage. Deliberation occurs through structured multi-round discussions that follow a defined protocol, with confidence-weighted outcomes rather than simple majority voting. Installation involves adding the plugin via the /council command or Codex skill.

## Difference from Others
Unlike general-purpose agent frameworks (AutoGen, CrewAI, LangChain) or simple multi-agent chatbots, Council of High Intelligence deploys a fixed set of 18 personas with distinct backgrounds rather than dynamically creating agents on demand. Its deliberation protocol is more structured—using Debate, Consensus, and Report modes—and includes confidence-weighted verdicts that reflect each persona's certainty levels rather than just majority rules. This makes it better suited for rigorous decision-making tasks where diverse perspectives are essential, though it is primarily a Claude Code plugin rather than a standalone service.
