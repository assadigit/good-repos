# activepieces

> **TL;DR:** Open-source Zapier alternative with built-in AI agents, ~400 MCP servers, and a type-safe pieces framework for workflow automation.

**`activepieces/activepieces`** · ⭐ 23,829 · 🔧 TypeScript

## What is it?
Activepieces is an open-source workflow automation platform that serves as a self-hostable alternative to Zapier. It combines traditional no-code workflow orchestration with native AI agent capabilities, supporting approximately 400 Model Context Protocol (MCP) servers out of the box. The platform uses a TypeScript-based 'Pieces' framework where each reusable component is type-safe and can be connected into complex automation flows.

## How does it work?
Activepieces operates on a node-based architecture where users connect pre-built or custom 'pieces' (integrations/actions) together to form workflows. Each piece is written in TypeScript, making the entire system type-safe and extensible. The platform supports both visual configuration through its UI and programmatic extension via SDKs. It integrates with MCP (Model Context Protocol) to enable AI agents to interact with tools and services contextually, allowing LLM-powered automation beyond simple trigger-action chains.

## Why is it important? (Core Value)
For a software engineer and researcher focused on AI agents, developer tools, and self-hosting, Activepieces is highly valuable as it directly addresses multiple objectives: (1) It provides ~400 ready-to-use MCP servers for AI agent integration into projects; (2) It offers a self-hostable workflow automation platform eliminating vendor lock-in from SaaS tools like Zapier; (3) The type-safe Pieces framework serves as an extensible foundation for building custom agent capabilities. It bridges the gap between traditional workflow automation and modern AI agent orchestration, making it ideal for integrating AI agents into production systems without relying on proprietary platforms.

## Key Features & Technologies
- ~400 built-in MCP servers for AI agents
- Type-safe Pieces framework in TypeScript
- Self-hostable open-source platform (MIT license)
- No-code/low-code workflow builder UI
- Extensible SDKs for custom piece development
- Zapier/n8n alternative with native AI agent support
- Supports both traditional triggers and LLM-driven workflows

## Difference from Others
While n8n and Make.com offer self-hostable or SaaS-based workflow automation, Activepieces distinguishes itself by being built from the ground up around AI agents and MCP integration. Unlike Zapier (proprietary) or Make.com (SaaS-first), Activepieces is fully open-source with a MIT license, enabling complete control over data, hosting, and customization. Its ~400 MCP servers out-of-the-box provide immediate access to LLM-capable tool integrations that other platforms lack natively.
