# bolt.new

> **TL;DR:** AI-powered web dev agent running full-stack apps in-browser via StackBlitz WebContainers.

**`stackblitz/bolt.new`** · ⭐ 16,444 · 🔧 TypeScript

## What is it?
Bolt.new is an AI-powered web development agent that allows you to prompt, run, edit, and deploy full-stack applications directly from your browser—no local setup required. It integrates cutting-edge AI models with an in-browser development environment powered by StackBlitz's WebContainers, enabling installation and execution of npm tools and libraries (like Vite, Next.js), running Node.js servers, interacting with third-party APIs, deploying to production from chat, and sharing work via a URL.

Unlike traditional dev environments where the AI can only assist in code generation, Bolt.new gives AI models complete control over the entire environment including the filesystem, node server, package manager, terminal, and browser console. This empowers AI agents to handle the entire app lifecycle—from creation to deployment.

## How does it work?
Bolt.new leverages StackBlitz WebContainers as its foundation, providing a runtime environment that runs entirely in the browser. The architecture integrates AI models with this environment, granting them full control over filesystem operations, Node.js server execution, npm package management, terminal commands, and browser console interactions. This allows the AI to install npm tools and libraries (like Vite, Next.js), run Node.js servers, interact with third-party APIs, deploy applications to production environments directly from chat, and share the resulting work via a URL.
