# claudian

> **TL;DR:** Obsidian plugin that embeds Claude Code, Codex, Opencode, Pi AI coding agents directly into your vault as a working directory.

**`YishenTu/claudian`** · ⭐ 14,137 · 🔧 TypeScript

## What is it?
Claudian is an Obsidian plugin that brings AI coding agent capabilities directly into your personal knowledge base. It transforms your Obsidian vault into the agent's working environment, enabling seamless file read/write operations, search functionality, bash execution, and multi-step workflows—all operating out of the box without requiring external tool configuration.

## How does it work?
The plugin operates through Obsidian's sidebar chat interface, accessible via the ribbon icon or command palette. When you select text or place a cursor and trigger with a hotkey, the agent performs inline editing with word-level diff previews. The system uses slash commands ($ and /) for reusable prompt templates and Skills scoped at both user and vault levels. Type @ to mention specific entities—the agent will then work with those files, subagents, MCP servers, or external directories.

## Why is it important? (Core Value)
For a software engineer and researcher focused on AI agents, developer tools, and automation, Claudian represents a significant self-hosted alternative to SaaS-based agent platforms. Instead of paying for Claude Code subscriptions or configuring external IDE integrations, you run the agents locally within your existing Obsidian workflow. This directly addresses your objectives: improving development workflow through integrated AI assistance, finding self-hostable alternatives to SaaS products, and discovering new approaches to automation. The Plan Mode feature adds safety by requiring agent approval before major changes, which is valuable for research work where auditability matters.

## Key Features & Technologies
- Inline text editing with diff previews
- Slash commands and Skills from user/vault scopes
- @mention system for targeting files and subagents
- Plan Mode requiring approval before implementation
- MCP server integration for external tools
- Vault becomes agent working directory
- Obsidian plugin architecture

## Difference from Others
Unlike Claude Code (standalone CLI tool), Codex (requires external IDE like VS Code with extensions), or Opencode (standalone agent system), Claudian is the only option that integrates directly into Obsidian. This means your AI collaborator lives in the same ecosystem as your notes and projects, eliminating context switching between tools. The mention system also differs from standard agent interfaces by allowing you to explicitly target vault files, subagents, or MCP servers through natural language.
